# Адресация

При работе с изображениями в OpenCV важно понимать, как происходит адресация пикселей. 

- Ось X направлена слева направо.
- Ось Y направлена сверху вниз.
- Координата (0, 0) соответствует верхнему левому углу изображения

В OpenCV изображения хранятся в виде массивов Numpy, где каждая ячейка массива представляет собой пиксель изображения.  При обращении к элементам массива **NumPy** сначала указывается координата по оси Y (строка), а затем координата по оси X (столбец).  

Однако, во всех функциях OpenCV координаты будут использоваться в привычном формате - сначала X, потом Y

![Цветные пиксели](indexing.png)

```python
import cv2
import numpy as np

# Чтение изображения
image = cv2.imread('pixel3x3.png')

# Получение цвета пикселя в координате (1, 2)
pixel_color = image[1, 2]
print(pixel_color)  # Выводит: [255, 0, 0] (синий пиксель)
```
