Паттерн Фабричный метод применяется, когда мы хотим, чтобы подклассы выбирали, какой класс инстанциировать, когда запрашивается объект. Это полезно само по себе, но можно пойти дальше и использовать в случае, когда класс заранее неизвестен (например, зависит от информации, прочитанной из файла или введенных пользователем данных).

- **Определяет интерфейс** для создания объекта, но оставляет подклассам решение, какой конкретный класс инстанцировать (создать объект какого класса).
- Позволяет **перенести ответственность** за создание объектов на наследников.
- Даёт гибкость: можно создавать объекты, заранее не зная их конкретных типов (например, выбирая их по входным данным).

### Отличие от обычного конструктора

- Обычный конструктор (`__init__`) всегда создаёт конкретный класс.
- Фабричный метод может выбирать, какой объект создать, основываясь на внешних условиях.

В ООП часто делают фабричный метод как метод класса (или абстрактного класса), который потом переопределяют в наследниках. Здесь **animal_factory** — фабричный метод, который решает, какой объект вернуть.

```python
class Animal:
    def speak(self):
        pass

class Dog(Animal):
    def speak(self):
        return "Гав!"

class Cat(Animal):
    def speak(self):
        return "Мяу!"

def animal_factory(kind):
    if kind == "dog":
        return Dog()
    elif kind == "cat":
        return Cat()
    else:
        raise ValueError("Unknown animal")

a = animal_factory("cat")
print(a.speak())  # Мяу!
```

Пример с локализацией

- **EnglishLocalizer** — просто возвращает то же сообщение.
- **GreekLocalizer** — возвращает перевод, если он есть, иначе оригинал.

```python
class GreekLocalizer:
    def __init__(self):
        self.translations = {"dog": "σκύλος", "cat": "γάτα"}

    def localize(self, msg):
        return self.translations.get(msg, msg)

class EnglishLocalizer:
    def localize(self, msg):
        return msg

# Фабричный метод - по названию языка возвращает нужный класс-локализатор
def get_localizer(language="English"):
    localizers = {
        "English": EnglishLocalizer,
        "Greek": GreekLocalizer,
    }
    return localizers[language]()

e = get_localizer("English")
g = get_localizer("Greek")

for msg in "dog parrot cat bear".split():
    print(e.localize(msg), g.localize(msg))

# Вывод:
# dog σκύλος
# parrot parrot
# cat γάτα
# bear bear
```

Использование:

- Позволяет **скрыть детали создания** объектов от клиентского кода.
- Упрощает расширение: можно добавлять новые типы объектов, не трогая основной код (достаточно расширить фабрику).
- Динамически определяет, какой класс создавать — удобно для плагинов, языков, форматов, разных UI.
