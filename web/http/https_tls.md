# HTTPS и TLS

**HTTPS** — HTTP внутри защищённого TLS-соединения. TLS обеспечивает:

- конфиденциальность — содержимое шифруется;
- целостность — изменение данных обнаруживается;
- аутентификацию сервера — сертификат связывает домен с публичным ключом.

## Проверка сертификата

Клиент проверяет срок действия сертификата, соответствие доменному имени и цепочку доверия до известного центра сертификации. Отключение проверки сертификата допустимо только для краткой локальной диагностики.

## TLS termination

Часто TLS завершается на NGINX или балансировщике, после чего запрос передаётся приложению. Внутренний участок сети тоже следует шифровать, если он проходит через недоверенную среду или этого требует модель угроз.

## Базовые меры

- перенаправлять HTTP на HTTPS;
- использовать актуальные версии TLS и регулярно обновлять сервер;
- автоматизировать выпуск и продление сертификатов;
- включать HSTS только после проверки, что домен и нужные поддомены стабильно доступны по HTTPS;
- не передавать секреты в URL;
- помечать сессионные cookies как `Secure`, `HttpOnly` и подходящим `SameSite`.
