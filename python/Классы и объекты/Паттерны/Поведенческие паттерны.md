Предмет поведенческих паттернов - способ решения задачи. То есть они имеют дело с алгоритмами и взаимодействиями объектов. Эти паттерны предлагают действенные способы обдумывания и организации вычислений. Для некоторых из них имеется прямая поддержка в синтаксисе Python.

Для чего:

- Определяют, **как объекты обмениваются сообщениями**, реагируют на события и сотрудничают для выполнения задач. 
- Помогают сделать коммуникацию между объектами гибкой, расширяемой и удобной для изменений.
- Позволяют строить цепочки обработчиков, системы уведомлений, гибко заменять алгоритмы и т.д.

## Самые известные поведенческие паттерны (GoF):

1. **Observer (Наблюдатель):**  
    Автоматически оповещает все зависимые объекты об изменениях состояния (например, подписка на новости).
2. **Strategy (Стратегия):**  
    Позволяет динамически подменять алгоритм работы, не изменяя клиентский код (например, разные способы сортировки).
3. **Command (Команда):**  
    Инкапсулирует запрос в объект, позволяя запускать, откладывать и отменять команды (например, история действий “отмена/повтор”).
4. **State (Состояние):**  
    Объект меняет своё поведение в зависимости от внутреннего состояния (например, автомат с напитками).
5. **Iterator (Итератор):**  
    Последовательный доступ ко всем элементам коллекции без раскрытия её внутреннего устройства.
6. **Mediator (Посредник):**  
    Упрощает взаимодействие множества объектов, концентрируя коммуникацию в одном месте.
7. **Chain of Responsibility (Цепочка обязанностей):**  
    Передаёт запрос по цепочке обработчиков, пока кто-то не обработает (например, фильтры сообщений).
8. **Template Method (Шаблонный метод):**  
    Определяет общий алгоритм, детали которого реализуются в подклассах.
9. **Visitor (Посетитель):**  
    Позволяет добавлять новые операции к объектам, не изменяя их классы.
10. **Memento (Хранитель):**  
    Позволяет сохранять и восстанавливать внутреннее состояние объекта без раскрытия деталей.
