# Логгирование

DEBUG — подробная отладка. Используется только во время разработки, чтобы видеть внутренние процессы программы (например, SQL‑запросы, параметры функций).

INFO — ключевые шаги работы программы. Применяется для фиксации нормального хода работы: запуск приложения, успешное выполнение задачи, вход пользователя.

WARNING — потенциальные проблемы. Например, устаревший API, медленный отклик сервиса, нехватка ресурсов. Программа продолжает работать, но требует внимания.

ERROR — сбой, но программа работает дальше. Ошибка при сохранении файла, невозможность подключиться к сервису, но приложение не падает.

CRITICAL — аварийное завершение. Ситуации, когда программа не может продолжить работу: падение базы данных, критическая ошибка конфигурации.
