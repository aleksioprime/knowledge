**Функции** — это один из ключевых инструментов структурирования и повторного использования кода в Python. Функция — это именованный блок кода, который может принимать входные данные (аргументы), выполнять вычисления и возвращать результат.

### Объявление функции

Функция в Python объявляется с помощью ключевого слова `def`, за которым следует имя функции, круглые скобки с параметрами (может быть пустыми) и двоеточие. Тело функции отделяется отступом.

**Пример базовой функции:**

```python
def greet():
    print("Hello, world!")

greet()  # Вывод: Hello, world!
```
### Аргументы функции

Функция может принимать значения (аргументы):

```python
def square(x):
    return x * x

print(square(5))  # 25
```

Можно определять функции с несколькими аргументами:

```python
def add(a, b):
    return a + b

print(add(2, 3))  # 5
```
### Возвращаемое значение

Для возврата результата используется ключевое слово `return`. Если return не указан, функция возвращает `None`.

```python
def double(x):
    return x * 2

result = double(10)
print(result)  # 20
```

### Вызов функций

```python
def func():
    print('Im a function')

func
#=> function __main__.func>
func()
#=> Im a function
```

- `func` — это **ссылка на функцию** (функция как объект, ещё не вызвана).
- `func()` — это **вызов функции** (функция выполняется прямо сейчас, и результат этого выполнения подставляется в код).

func — это представляющий функцию объект, который можно назначить переменной или передать другой функции. Функция func() с круглыми скобками вызывает функцию и возвращает результат.
