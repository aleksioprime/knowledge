В Python нет обязательной функции `main`, как, например, в C или Java. Но очень часто программисты используют функцию с именем `main()` для организации входной точки программы.

```python
def main():
    print("Hello, world!")

if __name__ == "__main__":
    main()
```

`__main__` указывает на область видимости, где будет выполняться код. Если запустить Python-файл прямо, то значением `__name__` будет `__main__`. Если же его запустить в качестве модуля, то значением будет уже не `__main__`, а название модуля.

Это значит, что строка выше вернет `True` только в том случае, если программа будет запущена прямо. Если же ссылаться на файл как на модуль, то содержимое конструкции if не будет выполнено.
### Для чего используют функцию main?

- Для структурирования кода: вся логика запуска программы помещается в одну функцию.
- Для того чтобы код можно было **импортировать как модуль** без его автоматического выполнения.
- Для повышения читаемости и масштабируемости кода.

```python
# utils.py
def main():
    print("Some main code")

def helper():
    print("Helper function")

if __name__ == "__main__":
    main()
```
