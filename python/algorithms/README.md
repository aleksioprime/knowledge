# Алгоритмы и структуры данных

Базовые алгоритмы (сортировки, поиск), сложность по времени и памяти (Big-O), классические структуры данных (массивы, связные списки, стеки, очереди, деревья, графы, хеш-таблицы) и подходы к решению задач.

Нотация O большое (Big O Notation) — это математический способ описания асимптотического поведения функций. Big O описывает поведение функции при n → ∞. Обычно рассматривается наихудший случай (worst case). Константы и «младшие» члены функции игнорируются.

Мы смотрим, как алгоритм ведёт себя при больших входных данных (→ ∞). Это позволяет понять, какой алгоритм работает быстрее, помогает оценить поведение на больших данных и выбрать наиболее эффективный алгоритм для задачи.
