# System Design

Раздел про проектирование систем: подходы к построению масштабируемых и надёжных приложений, паттерны архитектуры, типичные задачи системного дизайна на собеседованиях.

Темы для проработки:
- **Принципы**: SOLID, DRY, KISS, YAGNI
- **Архитектурные стили**: монолит, микросервисы, SOA, event-driven, serverless
- **Паттерны проектирования** (GoF) и DDD
- **CAP-теорема**, **PACELC**
- **Масштабирование**: vertical vs horizontal, sharding, replication
- **Кэширование**: стратегии (cache-aside, write-through, write-behind), invalidation
- **Очереди и event-streaming**
- **Согласованность данных**: strong, eventual, causal, BASE vs ACID
- **Distributed transactions**: 2PC, Saga, Outbox pattern
- **Идемпотентность и retry**
- **Rate limiting**, **Circuit breaker**, **Bulkhead**
- **Типовые задачи**: спроектировать URL shortener, Twitter feed, чат, очередь задач
