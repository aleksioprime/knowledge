**Хешируемый объект** — это объект, который: 

- **Может быть ключом в словаре (`dict`) или элементом множества (`set`)**  
- **Неизменяемый (или ведёт себя как неизменяемый)**  
- **Имеет корректные методы `__hash__()` и `__eq__()`**

Чтобы класс был **хешируемым**, он должен:

1. **Определять `__hash__()`** (возвращает хеш-значение объекта).
2. **Определять `__eq__()`** (чтобы сравнивать объекты).
3. **Быть неизменяемым** (или вести себя как неизменяемый).

```python
class Person:
    def __init__(self, name, age):
        self.name = name
        self.age = age

    def __eq__(self, other):
        if not isinstance(other, Person):
            return False
        return (self.name, self.age) == (other.name, other.age)

    def __hash__(self):
        return hash((self.name, self.age))  # Используем кортеж для хеша

# Создаём объекты
p1 = Person("Alice", 30)
p2 = Person("Alice", 30)
p3 = Person("Bob", 25)

# Проверяем равенство
print(p1 == p2)  # True (так как name и age одинаковые)
print(p1 == p3)  # False

# Используем в множестве (set) и словаре (dict)
people_set = {p1, p2, p3}
print(len(people_set))  # 2 (p1 и p2 считаются одинаковыми)

people_dict = {p1: "Developer", p3: "Designer"}
print(people_dict[p2])  # "Developer" (так как p1 == p2)
```

- **`__eq__()`** сравнивает объекты по `name` и `age`.
- **`__hash__()`** использует `hash((name, age))`, так как кортежи **уже хешируемые**.
- **Класс неизменяемый** — после создания `name` и `age` **не меняются**.
