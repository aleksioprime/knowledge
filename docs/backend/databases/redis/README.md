# Redis

**Redis** — хранилище «ключ → значение» в оперативной памяти. Отвечает за доли миллисекунды и выполняет каждую команду атомарно, поэтому его используют для кэша, сессий, счётчиков, ограничения частоты запросов, блокировок и простых очередей.

## Содержание

1. [Основы](basics.md) — ключи и срок жизни, строки, хэши, списки, множества, рейтинги, `pipeline`, асинхронный клиент
2. [Пять типовых сценариев](scenarios.md) — кэш, счётчики просмотров, rate limiting, распределённая блокировка, очередь
3. [Redis в FastAPI](fastapi.md) — кэш статистики с инвалидацией и ограничение попыток входа в «Задачнике»
