# Базы данных и хранилища

Раздел охватывает реляционные и NoSQL базы данных, поисковые движки, объектные хранилища, кэширование и оркестрацию пайплайнов обработки данных.

## Содержание

- [SQL](sql/README.md) — язык запросов и справочник для собеседований
- [PostgreSQL](postgres/README.md) — реляционная СУБД
- [SQLAlchemy](sqlalchemy/README.md) — ORM/Core для Python
- [Alembic](alembic/README.md) — миграции для SQLAlchemy
- [MongoDB](mongodb/README.md) — документоориентированная NoSQL БД
- [Redis](redis/README.md) — in-memory key-value store
- [ClickHouse](clickhouse/README.md) — колоночная аналитическая СУБД
- [Elasticsearch](elasticsearch/README.md) — поисковый движок и аналитика
- [S3](s3/README.md) — объектное хранилище
- [Airflow](airflow/README.md) — оркестратор пайплайнов данных
