# Django

**Django** — высокоуровневый Python-фреймворк по принципу «batteries included». Из коробки: ORM, миграции, админка, формы, аутентификация, шаблонизатор, middleware и система роутинга. Подходит для классических серверных приложений и REST API (через DRF).

Ключевые концепции:
- MTV (Model — Template — View) — аналог MVC
- Django ORM с миграциями
- Django REST Framework для построения API
- Сигналы, middleware, management-команды

## Содержание

- ORM — `orm/` (примеры и заметки по работе с ORM)
- Project — `project/` (структура проекта, настройки, типовые рецепты)

> Заметки и примеры будут добавляться по мере проработки темы.
