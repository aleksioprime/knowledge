Паттерн Фасад служит для того, чтобы предоставить упрощенный унифицированный интерфейс к подсистеме, чей истинный интерфейс слишком сложен или написан на таком низком уровне, что работать с ним неудобно. Фасад определяет интерфейс более высокого уровня, который упрощает использование подсистемы.

В стандартной библиотеке Python имеется несколько модулей для работы с сжатыми файлами - gzip, tar+gzip, zip. Все они имеют разные интерфейсы. Если мы хотим иметь один унифицированный интерфейс для работы с архивами, мы можем воспользоваться паттерном Фасад.

Паттерны Фасад и Адаптер на первый взгляд кажутся похожими. Разница в том, что Фасад надстраивает простой интерфейс поверх сложного, а Адаптер надстраивает унифицированный интерфейс над каким-то другим (необязательно сложным). Оба эти паттерна можно использовать совместно. Например определить интерфейс для работы с архивными файлами, написать Адаптер для каждого формата и надстроить поверх них фасад, чтобы пользователям не нужно было беспокоиться о том, какой конкретно формат файла используется.

```python
# Сложные детали — внутренние компоненты компьютера

class CPU:
    """Модель процессора."""
    def freeze(self):
        print("Freezing processor.")  # Подготовить процессор (например, остановить выполнение)

    def jump(self, position):
        print("Jumping to:", position)  # Перейти к определённому месту (например, загрузчик)

    def execute(self):
        print("Executing.")  # Начать выполнение программы

class Memory:
    """Модель оперативной памяти."""
    def load(self, position, data):
        print(f"Loading from {position} data: '{data}'.")

class SolidStateDrive:
    """Модель SSD."""
    def read(self, lba, size):
        # lba — адрес блока данных, size — размер
        return f"Some data from sector {lba} with size {size}"

# Фасад: объединяет все детали в один простой интерфейс
class ComputerFacade:
    """
    Упрощённый интерфейс для работы с компьютером.
    Пользователь не должен знать, как управлять процессором, памятью и SSD по отдельности.
    """
    def __init__(self):
        self.cpu = CPU()
        self.memory = Memory()
        self.ssd = SolidStateDrive()

    def start(self):
        # Вот как выглядит запуск сложной системы "одной кнопкой"
        self.cpu.freeze()
        self.memory.load("0x00", self.ssd.read("100", "1024"))
        self.cpu.jump("0x00")
        self.cpu.execute()

# ======= Использование паттерна Facade =======
def main():
    computer = ComputerFacade()
    computer.start()
    # Вывод:
    # Freezing processor.
    # Loading from 0x00 data: 'Some data from sector 100 with size 1024'.
    # Jumping to: 0x00
    # Executing.

if __name__ == "__main__":
    main()

```

- У нас есть сложная система (CPU, Memory, SSD) — много классов, у каждого своя логика и методы.
- Мы объединяем их через **ComputerFacade**.
- Теперь вместо кучи действий с разными объектами пользователь вызывает только `computer_facade.start()` — **и всё работает!**

Применение:
- **Работа с внешними библиотеками**: когда внешний код слишком сложный или низкоуровневый — делаем фасад, чтобы упростить интеграцию.
- **Организация старта сложных систем** (игровой движок, сервер, обработка данных).
- **Интерфейсы для пользователей**: чтобы скрыть внутреннюю "кухню" и упростить использование.
