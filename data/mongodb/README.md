# MongoDB

**MongoDB** — документоориентированная NoSQL база данных. Хранит данные в формате BSON (бинарный JSON), не требует жёсткой схемы и хорошо горизонтально масштабируется через шардирование.

Ключевые концепции:
- Database → Collection → Document
- Гибкая schema-less структура
- Индексы (single, compound, multikey, geospatial, text)
- Aggregation framework (pipelines)
- Репликация (Replica Set) и шардирование

Драйверы для Python: `pymongo` (sync), `motor` (async), `beanie`/`mongoengine` (ODM).
