## Установка Docker

Обновление списка пакетов:

```sh
apt update
```

Обновление установленных пакетов:

```sh
apt upgrade -y
```

Проверка необходимости перезагрузки после обновления:

```sh
ls /var/run/reboot-required
```

Если файл `reboot-required` существует, то необходимо перезагрузить сервер:

```sh
reboot
```

Установка дополнительных пакетов, которые позволят менеджеру пакетов APT использовать HTTPS:

```sh
apt install apt-transport-https ca-certificates curl software-properties-common -y
```

Добавление систему ключа GPG для официального репозитория Docker:

```sh
curl -fsSL https://download.docker.com/linux/ubuntu/gpg | gpg --dearmor -o /usr/share/keyrings/docker-archive-keyring.gpg
```

Добавление репозитория Docker в источники пакетов APT:

```sh
echo "deb [arch=$(dpkg --print-architecture) signed-by=/usr/share/keyrings/docker-archive-keyring.gpg] https://download.docker.com/linux/ubuntu $(lsb_release -cs) stable" | tee /etc/apt/sources.list.d/docker.list > /dev/null
```

Повторное обновление списка пакетов, чтобы в него добавились пакеты из репозитория Docker:

```sh
apt update
```

Установка Docker:

```sh
apt install docker-ce docker-ce-cli containerd.io docker-compose-plugin -y
```

Проверка статуса службы `docker`:

```sh
systemctl status docker
```

Завершаем просмотр нажатием клавиши `q`.

## Перенос и настройка проекта

Переход в папку проекта:

```sh
cd /home
```

Клонируем проект с GitHub в директорию `/home`:

```sh
git clone https://github.com/Permin0ff/fastapi_ecommerce_docker.git
```

Переходим в директорию проекта:

```sh
cd fastapi_ecommerce_docker
```

Создание файла `.dockerignore`, это необходимо чтоб директория `.git` не попала в содержимое образа:

```bash
vi .dockerignore
```

Со следующим содержимым:

```
.git
.gitignore
docker-compose*
```

Не забываем сохранить файл(Нажимаем `Esc` и вводим `:wq`, нажимаем `Enter`. Если по каким-то причинам не нужно сохранять изменения в редактируемом файле вводим `:q!`. А если редактор использовался только для просмотра содержимого файла то тогда для выхода используем `:q`).

Зафиксируем изменения в репозитории:

```sh
git add .dockerignore
git commit -am "Create .dockerignore file"
```

Переход в директорию `nginx`:

```sh
cd nginx
```

Редактирование файла конфигурации NGINX - `fastapi_ecommerce.conf`:

```sh
vi fastapi_ecommerce.conf
```

Изменим значение `server_name` на имя имя вашего домена:

```nginx
    server_name имя_вашего_домена;
```

**Примечание**: Чтобы перевести текстовый редактор `vi` в режим редактирования, нажмите клавишу `i` или `Insert`. Не забываем сохранить файл(Нажимаем `Esc` и вводим `:wq`, нажимаем `Enter`. Если по каким-то причинам не нужно сохранять изменения в редактируемом файле вводим `:q!`. А если редактор использовался только для просмотра содержимого файла то тогда для выхода используем `:q`).

Зафиксируем изменения в репозитории:

```sh
git commit -am "Add domain name to fastapi_ecommerce.conf"
```

## Запуск Docker контейнеров

Перейдём в директорию проекта и запустим процесс создания образов, выполним:

```sh
cd ..
docker compose -f docker-compose.prod.yml build
```

Создадим и запустим контейнеры:

```sh
docker compose -f docker-compose.prod.yml up -d
```
  
Затем выполним миграции:

```sh
docker compose -f docker-compose.prod.yml exec web alembic upgrade head
```

##  Получение SSL-сертификата от Let's Encrypt

Для настройки подключения по HTTPS необходим SSL-сертификат, их выпуском занимаются центры сертификации, эта услуга платная, цены начинаются от 1-2т.р. и более за сертификат на одно доменное имя на один год.

Альтернативой платным сертификатам, может стать бесплатные сертификаты от центра сертификации **[Let's Encrypt](https://letsencrypt.org/ru/about/)**.

Автоматизированное получение и продление сертификатов от **Let's Encrypt** осуществляется с помощью **[Certbot](https://certbot.eff.org/pages/about)**, но в данном случае будет использоваться его одноимённый образ.

Отредактируем файл `docker-compose.prod.yml`:

```sh
vi docker-compose.prod.yml
```

В секции `nginx`, в `volumes` добавим:

```yaml
    volumes:
      - ./certbot/conf:/etc/letsencrypt
      - ./certbot/www:/var/www/certbot
```

И откроем `443` порт для HTTPS:

```yaml
      - 443:443
```

  
Теперь добавим новую секцию `certbot`:

```yaml
  certbot:
    image: certbot/certbot
    volumes:
      - ./certbot/conf:/etc/letsencrypt
      - ./certbot/www:/var/www/certbot
    command: certonly --webroot --webroot-path=/var/www/certbot/ --email ваш@email --agree-tos --no-eff-email -d имя_вашего_домена
    depends_on:
      - nginx
```

**Примечание**: в команде `certonly` обязательно укажите ваш **email** и **имя вашего домена**, это необходимо для получения сертификата!

Зафиксируем изменения в репозитории:

```sh
git commit -am "Add certbot to docker-compose.prod.yml"
```

Создадим файл `.gitignore`, он необходим чтоб директория `certbot`, с сертификатами и прочим, не попала в репозиторий:

```sh
vi .gitignore
```

Со следующей строкой:

```sh
certbot
```

Зафиксируем изменения в репозитории:

```sh
git add .gitignore
git commit -am "Create .gitignore file"
```

Создадим директории для `certbot`:

```bash
mkdir -p certbot/conf
mkdir certbot/www
```

Перейдём в директорию `nginx` и отредактируем файл конфигурации `fastapi_ecommerce.conf`:

```sh
cd nginx
vi fastapi_ecommerce.conf
```

Добавим в файл конфигурации `fastapi_ecommerce.conf` следующие строки:

```nginx
    location /.well-known/acme-challenge/ {
        root /var/www/certbot;
    }
```

Зафиксируем изменения в репозитории:

```sh
git commit -am "Add certbot to fastapi_ecommerce.conf"
```

Вернёмся в директорию проекта и пересоберём образы:

```sh
cd ..
docker compose -f docker-compose.prod.yml build
```

Создадим и запустим контейнеры:

```sh
docker compose -f docker-compose.prod.yml up -d
```

Контейнеры запустились, теперь проверим наличие сертификатов, просмотрим содержимое директории `certbot/conf/live`:

```sh
ls -la certbot/conf/live
```

В ней должна быть директория с именем вашего домена, просмотрим её содержимое:

```sh
ls -la certbot/conf/live/имя_вашего_домена
```

## Настройка HTTPS

Сначала остановим и удалим контейнеры:

```sh
docker compose -f docker-compose.prod.yml down
```

Затем перейдём в директорию `nginx` и отредактируем его конфиг:

```sh
cd nginx
vi fastapi_ecommerce.conf
```

Изменим его содержимое на следующее:

```nginx
upstream fastapi_ecommerce {
    server web:8000;
}

server {
    listen 80;
    server_name ваше_доменное_имя;

    location /.well-known/acme-challenge/ {
        root /var/www/certbot;
    }

    location / {
        return 301 https://$host$request_uri;
    }
}

server {
    listen 443 ssl http2;
    server_name ваше_доменное_имя;

    ssl_certificate /etc/letsencrypt/live/ваше_доменное_имя/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/ваше_доменное_имя/privkey.pem;

    client_max_body_size 20M;
    charset utf-8;

    gzip on;
    gzip_min_length 1000;
    gzip_vary on;
    gzip_proxied expired no-cache no-store private auth;
    gzip_types   text/plain text/css application/json application/x-javascript text/xml application/xml application/xml+rss text/javascript application/javascript;

    location / {
        proxy_set_header X-Forwarded-Proto https;
        proxy_set_header X-Url-Scheme $scheme;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header Host $http_host;
        proxy_redirect off;
        proxy_pass http://fastapi_ecommerce;
    }

}
```
  
**Примечание**: обязательно замените строку `ваше_доменное_имя` в `server_name`, в `ssl_certificate` и в `ssl_certificate_key`, на имя вашего домена!

Зафиксируем изменения в репозитории:

```sh
git commit -am "Add HTTPS support to fastapi_ecommerce.conf"
```

Перейдём в директорию проекта, пересоберём образы:

```sh
cd ..
docker compose -f docker-compose.prod.yml build
```

Создадим и запустим контейнеры:

```bash
docker compose -f docker-compose.prod.yml up -d
```
