# Postman

**Postman** — десктоп- и веб-инструмент для ручного и автоматизированного тестирования HTTP API. Удобен для разработки, отладки и документирования API.

Перед работой с инструментом полезно изучить [структуру HTTP-запросов и ответов](../../web/http/request_response.md).

Возможности:
- Коллекции запросов и переменные окружения
- Pre-request скрипты и тесты на JavaScript (Chai)
- Mock-серверы
- Автоматическая генерация документации
- CI-интеграция через **Newman** (CLI-раннер коллекций)
- Командная работа через workspaces
