# Celery

**Celery** — распределённая система выполнения фоновых задач для Python. Позволяет вынести из основного процесса приложения долгие или периодические операции (отправка email, генерация отчётов, обработка медиа) в отдельных воркеров.

Архитектура:
- **Producer** — приложение, отправляющее задачи
- **Broker** — транспорт сообщений (Redis, RabbitMQ)
- **Worker** — процесс, выполняющий задачи
- **Result backend** — хранилище результатов (Redis, БД)

Основные возможности:
- Отложенные и периодические задачи (Celery Beat)
- Цепочки, группы и chord-задачи
- Retry с настраиваемой стратегией
- Распределённое выполнение между воркерами
