# MongoDB

**MongoDB** — документоориентированная база данных. Каждая запись — документ в формате BSON (двоичный JSON), в котором прямо внутри могут лежать списки и вложенные объекты. Строгой схемы нет: документы одной коллекции могут иметь разные поля.

Драйверы для Python: `pymongo` (синхронный, а с версии 4.13 — и асинхронный `AsyncMongoClient`), ODM-библиотеки `beanie` и `mongoengine`.
