Под сериализацией понимается процесс перевода какой-либо структуры данных в последовательность битов.

Десериализация является обратной операцией и восстанавливает структуры данных из последовательности битов.

```python
import json

# Сериализация (преобразование объекта в строку)
data = {'name': 'Alice', 'age': 25}
json_str = json.dumps(data)  # '{"name": "Alice", "age": 25}'

# Десериализация (обратно из строки в объект)
data_again = json.loads(json_str)  # {'name': 'Alice', 'age': 25}

```

**Пиклинг** (от англ. _pickling_) — это термин в Python, который означает процесс сериализации объекта с помощью стандартного модуля `pickle`. То есть **"запиклить" объект** — это превратить его в поток байтов, который потом можно сохранить на диск, передать по сети и т.д.

**Анпиклинг** (_unpickling_) — это десериализация: восстановление объекта из байтов.

```python
import pickle

data = {'a': 1, 'b': [2, 3, 4]}

# Пиклинг (сериализация)
with open('data.pkl', 'wb') as f:
    pickle.dump(data, f)

# Антипиклинг (десериализация)
with open('data.pkl', 'rb') as f:
    loaded_data = pickle.load(f)
```

### Для чего используют пиклинг?

- Сохранение объектов Python "как есть" между сессиями.
- Быстрое кэширование данных, сложных структур, моделей машинного обучения и др.
- Передача объектов между процессами на одном сервере.

**Важно:**  
Не используйте pickle для загрузки данных из недоверенных источников! Через pickle можно выполнить вредоносный код при десериализации.

Что можно сериализовать

- None, True и False
- числовые типы
- строковые и байтовые типы
- кортежи, списки, множества и словари, состоящие только из сериализуемых объектов
- функции (в том числе встроенные) верхнего уровня, объявленные с def (верхнего уровня = с нулевым отступом)
- классы верхнего уровня
- объекты классов, для которых __dict__ или результат __getstate()__ является сериализуемым.

Обратите внимание, что сериализация функций выполняется по имени, а не по значению. Т.е. библиотека сохраняет **только имя функции с именем модуля, где она определена**. Тоже самое справедливо и для классов

**Сравнение с JSON.**

Существуют фундаментальные различия между протоколами `Pickle` и `JSON`:

- `JSON` - это текстовый формат сериализации, а `pickle` - это двоичный формат сериализации;
- `JSON` читается человеком, а `pickle` - нет;
- `JSON` широко используется за пределами экосистемы Python, в то время как `Pickle` зависит от Python;
