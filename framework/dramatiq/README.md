# Dramatiq

**Dramatiq** — современная Python-библиотека для фоновой обработки задач, альтернатива Celery. Делает ставку на простоту, надёжность и предсказуемое поведение.

Особенности:
- Простой API без лишней магии
- Гарантированная доставка (at-least-once)
- Встроенные middleware (retry, rate-limit, age-limit)
- Поддержка RabbitMQ и Redis как брокеров
- Меньше нагрузка на брокер по сравнению с Celery
