# NGINX

**NGINX** — веб-сервер и reverse proxy. Он принимает клиентские соединения, может завершать TLS, отдавать статические файлы, кешировать ответы и распределять запросы между приложениями.

```text
клиент ──HTTPS──> NGINX ──HTTP/HTTPS──> приложение
                       ├───────────────> приложение
                       └───────────────> статика
```

## Типовые сценарии

- reverse proxy перед Uvicorn, Gunicorn или Node.js;
- балансировка нагрузки между несколькими экземплярами приложения;
- раздача статики и файлов;
- TLS termination;
- кеширование и сжатие ответов;
- ограничение частоты запросов и числа соединений;
- проксирование WebSocket и SSE.

## Проверка изменений

```sh
sudo nginx -t
sudo systemctl reload nginx
```

Сначала проверяйте синтаксис, затем выполняйте `reload`: при корректной конфигурации рабочие процессы обновятся без резкого разрыва обслуживаемых соединений.
