**Поиск** — одна из базовых задач в программировании, заключающаяся в определении, содержится ли искомое значение (элемент) в заданной структуре данных, и если содержится, то на какой позиции. Алгоритмы поиска используются при работе со списками, строками, массивами, словарями и другими коллекциями.

Существует несколько основных подходов к поиску, которые различаются по эффективности и применимым структурам данных.
### Линейный поиск

**Линейный поиск** (англ. linear search, последовательный перебор) — самый простой и универсальный способ поиска элемента в коллекции.  

Принцип работы: перебирает элементы один за другим, сравнивая каждый с искомым значением, пока не найдёт совпадение или не переберёт все элементы.

**Пример:**

```python
def linear_search(arr, target):
    for index, value in enumerate(arr):
        if value == target:
            return index  # найдено, вернуть индекс
    return -1  # не найдено

numbers = [3, 7, 1, 9, 5]
print(linear_search(numbers, 9))  # 3
```

- **Время работы:** O(n), где n — длина массива.
- **Плюсы:** подходит для неотсортированных и любых структур данных.
- **Минусы:** медленно на больших объёмах данных.

### Бинарный поиск

**Бинарный поиск** (англ. binary search) — эффективный алгоритм поиска элемента в **отсортированном** массиве.  

Принцип работы:

1. Сравнивает искомый элемент с серединой массива.
2. Если элемент меньше середины — поиск продолжается в левой части, если больше — в правой.
3. Повторяет деление до нахождения элемента или завершения поиска.

**Пример:**

```python
def binary_search(arr, target):
    left, right = 0, len(arr) - 1
    while left <= right:
        mid = (left + right) // 2
        if arr[mid] == target:
            return mid
        elif arr[mid] < target:
            left = mid + 1
        else:
            right = mid - 1
    return -1

numbers = [1, 3, 5, 7, 9, 11]
print(binary_search(numbers, 7))  # 3
```

- **Время работы:** O(log n)
- **Плюсы:** очень быстро на больших отсортированных данных.
- **Минусы:** требует, чтобы данные были заранее отсортированы.
### Поиск подстроки

Поиск подстроки — задача определения, содержится ли одна строка внутри другой.

**Простейший способ** — использовать оператор `in`:

```python
text = "hello world"
print("world" in text)  # True
```

**Для поиска позиции**:

```python
print(text.find("world"))  # 6 (позиция первого символа подстроки)
```

Для более сложных случаев применяются алгоритмы Кнута-Морриса-Пратта, Бойера-Мура и другие.

### Поиск по словарю и множеству

- В **словарях** (`dict`) и **множествах** (`set`) поиск элемента осуществляется очень быстро за счёт хеширования — обычно за время O(1).
    
- Проверка наличия ключа:

```python
d = {"a": 1, "b": 2}
print("b" in d)  # True
```

- В множестве:

```python
s = {1, 2, 3}
print(2 in s)  # True
```


**Полезно знать:**  
В Python встроенные структуры данных реализуют эффективный поиск, и зачастую достаточно использовать оператор `in`. Однако для собеседований важно знать и уметь реализовывать базовые алгоритмы поиска вручную.


## Примеры задач

### 1. **Поиск первого вхождения элемента в списке**

**Задача:**  
Найти индекс первого вхождения заданного элемента в списке. Если не найден — вернуть -1.

```python
def find_first(nums, target):
    for i, x in enumerate(nums):
        if x == target:
            return i
    return -1

# Пример:
nums = [5, 3, 7, 3, 2]
print(find_first(nums, 3))  # 1
print(find_first(nums, 10)) # -1
```
### 2. **Поиск всех индексов элемента в списке**

**Задача:**  
Найти все индексы, где встречается элемент.

```python
def find_all(nums, target):
    return [i for i, x in enumerate(nums) if x == target]

# Пример:
nums = [3, 7, 3, 2, 3]
print(find_all(nums, 3))  # [0, 2, 4]
```
### 3. **Поиск минимального/максимального элемента и его индекса**

```python
nums = [5, 2, 9, 1, 7]
# Минимальное значение и индекс
min_val = min(nums)
min_idx = nums.index(min_val)
print(min_val, min_idx)  # 1 3

# Максимальное значение и индекс
max_val = max(nums)
max_idx = nums.index(max_val)
print(max_val, max_idx)  # 9 2
```
### 4. **Поиск подстроки в строке**

```python
s = "abracadabra"
substr = "cad"
print(s.find(substr))  # 4 (индекс первого вхождения)
print(substr in s)     # True
```
### 5. **Бинарный поиск в отсортированном массиве**

```python
def binary_search(arr, target):
    left, right = 0, len(arr)-1
    while left <= right:
        mid = (left + right) // 2
        if arr[mid] == target:

        elif arr[mid] < target:

nums = [1, 3, 4, 7, 8, 10]
```

### 6. **Поиск элемента в двумерном массиве**

**Задача:**  
Дан двумерный список (матрица), нужно найти координаты элемента.

```python
def find_in_matrix(matrix, target):
    for i, row in enumerate(matrix):
        for j, val in enumerate(row):
            if val == target:
                return (i, j)
    return None

# Пример:
matrix = [
    [1, 2, 3],
    [4, 5, 6],
    [7, 8, 9]
]
print(find_in_matrix(matrix, 5))  # (1, 1)
print(find_in_matrix(matrix, 10)) # None
```
### 7. **Поиск числа, встречающегося один раз (остальные по два раза)**

**Задача:**  
В списке, где все элементы встречаются по два раза, кроме одного, найти этот единственный элемент.

```python
def find_unique(nums):
    result = 0
    for num in nums:
        result ^= num
    return result

# Пример:
nums = [2, 3, 2, 4, 4]
print(find_unique(nums))  # 3
```
### 8. **Поиск пары с заданной суммой**

**Задача:**  
Дан список и целевое число. Нужно найти, есть ли пара элементов, сумма которых равна целевому числу.

```python
def has_pair_with_sum(nums, target):
    seen = set()
    for num in nums:
        if target - num in seen:
            return True
        seen.add(num)
    return False

# Пример:
nums = [1, 2, 4, 7]
print(has_pair_with_sum(nums, 6))  # True (2+4)
print(has_pair_with_sum(nums, 10)) # False
```
### 9. **Поиск дубликатов в списке**

```python
def has_duplicates(nums):
    return len(set(nums)) < len(nums)

nums = [1, 2, 3, 2]
print(has_duplicates(nums))  # True
```

```python
d = {'a': 1, 'b': 2, 'c': 3}
val = 2
key = next((k for k, v in d.items() if v == val), None)
```
