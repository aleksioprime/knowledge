# Интегралы

Интеграл нужен, когда известна скорость изменения, а узнать надо накопленный итог: по скорости — пройденный путь, по плотности распределения — вероятность попасть в интервал, по ROC-кривой — метрику AUC. Это обратная операция к производной и одновременно площадь под графиком функции.

## Минимальный пример

Площадь под `f(x) = x²` от 0 до 3 по формуле равна `3³/3 = 9`. Если первообразной нет или функция задана кодом, площадь считают приближённо: разбивают отрезок на узкие прямоугольники и складывают их.

```python run
import math

def integrate(f, a, b, n=1000):
    h = (b - a) / n
    return sum(f(a + (i + 0.5) * h) for i in range(n)) * h   # середины отрезков

print(round(integrate(lambda x: x ** 2, 0, 3), 4))   # 9.0
print(round(integrate(math.sin, 0, math.pi), 4))     # 2.0

def density(x):                                      # плотность нормального распределения
    return math.exp(-x ** 2 / 2) / math.sqrt(2 * math.pi)

print(round(integrate(density, -1, 1), 3))           # 0.683 — вероятность попасть в [-σ, σ]
```

## Как это работает

### Идея простыми словами

Интеграл — это **обратная операция к производной** и **площадь под графиком функции**.

Две стороны одной медали:
- Производная: «скорость изменения функции».
- Интеграл: «накопленная сумма», «площадь под кривой».

Возвращаясь к аналогии с машиной:
- если `s(t)` — путь, `s'(t) = v(t)` — скорость (производная);
- наоборот, зная скорость, можно проинтегрировать её и получить пройденный путь.

### Неопределённый интеграл

Неопределённый интеграл — это функция, производная которой равна подынтегральной функции.

```
∫ f(x) dx = F(x) + C        где  F'(x) = f(x)
```

`+ C` (константа интегрирования) добавляется потому, что производная константы равна 0 — значит, без дополнительной информации мы не знаем точное значение.

### Определённый интеграл

```
∫ от a до b f(x) dx
```

Это **площадь под графиком** функции `f(x)` на отрезке `[a, b]` (с учётом знака — то, что под осью, идёт со знаком «−»).

```
       y = f(x)
        ▲
        │     ___
        │    /   \
        │   /     \____
        │  /  площадь \
        │_/____________\_______▶ x
            a           b
```

### Формула Ньютона — Лейбница

Связывает определённый и неопределённый интегралы:

```
∫ от a до b f(x) dx = F(b) - F(a)
```

где `F` — любая первообразная (функция, чья производная равна `f`).

Пример. Найти площадь под `f(x) = x²` от 0 до 3.

Первообразная: `F(x) = x³/3`.
```
∫₀³ x² dx = F(3) - F(0) = 27/3 - 0 = 9
```

### Основные интегралы (зеркало производных)

```
∫ 0 dx       = C
∫ 1 dx       = x + C
∫ x^n dx     = x^(n+1) / (n+1) + C     (n ≠ -1)
∫ 1/x dx     = ln|x| + C
∫ e^x dx     = e^x + C
∫ a^x dx     = a^x / ln(a) + C
∫ sin x dx   = -cos x + C
∫ cos x dx   = sin x + C
```

Сравни с производными — они «обратны» друг другу.

### Свойства

```
∫ k · f(x) dx       = k · ∫ f(x) dx              ← константа выносится
∫ (f(x) ± g(x)) dx  = ∫ f(x) dx ± ∫ g(x) dx      ← интеграл суммы — сумма интегралов
∫ от a до b         = -∫ от b до a               ← смена пределов = смена знака
∫ от a до a         = 0
```

### Примеры

```
∫ 3x² dx              = x³ + C

∫ (2x + 5) dx         = x² + 5x + C

∫₀¹ x dx              = x²/2 │₀¹ = 1/2 - 0 = 0.5   (площадь треугольника!)

∫₁² 1/x dx            = ln|x| │₁² = ln 2 - ln 1 = ln 2 ≈ 0.693
```

### Численное интегрирование

Если первообразная не выражается формулой, считаем приближённо. Самый простой способ — **метод прямоугольников**: отрезок делится на `n` частей, на каждой функция считается постоянной. В минимальном примере высота берётся в середине отрезка — так ошибка заметно меньше, чем по левому краю.

Более точные методы:
- **Метод трапеций** — соседние точки соединяются отрезком.
- **Метод Симпсона** — через три точки проводится парабола, ещё точнее.

```python run
import math

def trapezoid(f, a, b, n=1000):
    h = (b - a) / n
    edges = f(a) + f(b)
    inner = sum(f(a + i * h) for i in range(1, n))
    return (edges / 2 + inner) * h

print(round(trapezoid(lambda x: x ** 2, 0, 3), 4))   # 9.0
print(round(trapezoid(math.exp, 0, 1), 4))           # 1.7183 — e - 1
```

В `scipy` всё это уже есть:
```python
from scipy.integrate import quad
quad(lambda x: x**2, 0, 3)   # (9.0, оценка погрешности)
```

### Где это используется в IT

**1. Вероятности и статистика**

Площадь под кривой плотности распределения = вероятность.
```
P(a ≤ X ≤ b) = ∫ от a до b p(x) dx
```

Например, для нормального распределения площадь под кривой в интервале `[μ - σ, μ + σ]` равна 68 % — это и посчитал минимальный пример.

**2. Машинное обучение**

- метрика AUC (Area Under Curve) — буквально площадь под ROC-кривой;
- ожидание непрерывной случайной величины:
  ```
  E[X] = ∫ x · p(x) dx
  ```
- байесовские модели и нормализующие потоки (normalizing flows) активно используют интегралы.

**3. Графика, физика, симуляции**

Любое «накопление» по времени или пространству: пройденный путь, заряд, объём жидкости, освещённость.

**4. Анализ алгоритмов**

Анализ среднего случая для случайных алгоритмов часто сводится к интегралам (хотя обычно используются дискретные суммы).

### Связь производной и интеграла (главная теорема анализа)

Простыми словами:

> Если сначала взять производную функции, а потом проинтегрировать её — получится та же функция (с точностью до константы). И наоборот.

```
d/dx ( ∫ f(x) dx ) = f(x)
∫ f'(x) dx       = f(x) + C
```

Это фундамент всего математического анализа.

## Частые ошибки

- Забыли `+ C` в неопределённом интеграле → при решении уравнения теряется семейство решений, и ответ не сходится с начальным условием → всегда дописывать константу и находить её из условия.
- Формула `x^(n+1)/(n+1)` применена к `1/x` → деление на ноль при `n = -1` → для `1/x` первообразная `ln|x|`.
- Пределы интегрирования перепутаны местами → площадь получилась отрицательной → помнить, что `∫ от b до a = -∫ от a до b`.
- Площадь под осью `x` сложена с площадью над ней как положительная → интеграл `sin` от 0 до `2π` равен нулю, а не 4 → если нужна геометрическая площадь, интегрировать `|f(x)|` или считать куски по отдельности.
- Слишком мало прямоугольников в численном методе → `integrate(math.sin, 0, math.pi, n=4)` даёт 2.05 вместо 2.0 → увеличивать `n` или брать метод Симпсона; при `n` в миллионах начинает накапливаться ошибка сложения `float`, тогда помогает `math.fsum`.

## Когда не использовать

Если данные дискретные — список платежей, замеры раз в секунду, таблица из базы, — интеграл превращается в обычную сумму: `sum(values) * step` или `itertools.accumulate` для накопленных итогов. Писать численное интегрирование здесь незачем.

Самодельный метод прямоугольников годится для учебных задач и быстрой проверки. Если нужна точность или функция с особенностями (разрывы, бесконечные пределы, резкие пики), берите `scipy.integrate.quad`: он сам выбирает шаг и возвращает оценку погрешности. Символьную первообразную выдаёт `sympy.integrate`.
