# API Gateway

**API Gateway** — единая точка входа (front door) для клиентов в микросервисную систему. Принимает HTTP-запросы, маршрутизирует их на нужный сервис, агрегирует ответы и решает кросс-сервисные задачи.

Типовые функции:
- Маршрутизация запросов и path-based routing
- Аутентификация и авторизация (JWT, OAuth2)
- Rate limiting и throttling
- Логирование, метрики, трассировка
- Кэширование ответов
- Преобразование протоколов (REST ↔ gRPC, GraphQL)
- SSL termination

Популярные решения: Kong, Traefik, NGINX, Envoy, AWS API Gateway, KrakenD.
