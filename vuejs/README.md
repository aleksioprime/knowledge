# Vue.js

**Vue.js** — прогрессивный JavaScript-фреймворк для построения пользовательских интерфейсов и SPA. Использует компонентный подход, реактивность данных и встроенные инструменты для роутинга (Vue Router) и управления состоянием (Pinia/Vuex).
