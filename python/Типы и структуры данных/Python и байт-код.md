Python является интерпретируемым языком программирования. Это означает, что исходный код Python не преобразуется в машинный код перед его выполнением, как в случае с компилируемыми языками, такими как C или Java. Вместо этого интерпретатор Python читает и выполняет исходный код на лету, строка за строкой. Однако стоит отметить, что Python использует промежуточный байт-код, что немного усложняет вопрос. Когда вы запускаете Python-программу, интерпретатор сначала компилирует исходный код в байт-код (если он еще не был скомпилирован), который затем исполняется. Но в конечном итоге, основное выполнение кода происходит через интерпретацию, что делает Python интерпретируемым языком.

Байт-код — это **промежуточный код**, который Python **генерирует** перед выполнением программы. Он представляет собой **компактные инструкции**, понятные интерпретатору Python.

Когда ты запускаешь `.py` файл, Python **не выполняет код сразу**, а проходит несколько этапов:

1. **Парсер** — читает код и проверяет синтаксис.  
2. **Компилятор** — превращает код в **байт-код** (файл `.pyc`).  
3. **Интерпретатор (виртуальная машина Python, PVM)** — выполняет байт-код построчно.

 **Зачем нужен байт-код?**

1. **Оптимизация выполнения**  
	Python не интерпретирует код **построчно**, а сначала **переводит его в более быстрый байт-код**.
2. **Кеширование (файлы `.pyc`)**  
	Python автоматически сохраняет байт-код в файлы `__pycache__/module.cpython-XX.pyc`, чтобы не компилировать код заново при следующем запуске.
3. **Универсальность**  
	Байт-код Python **не привязан к операционной системе** — он исполняется в любой среде с установленным интерпретатором Python.

Программа Python:

```python
import dis

def example():
    x = 10
    y = x + 5
    print(y)

dis.dis(example)
```

Байт-код:

```
  4           0 LOAD_CONST               1 (10)
              2 STORE_FAST               0 (x)

  5           4 LOAD_FAST                0 (x)
              6 LOAD_CONST               2 (5)
              8 BINARY_ADD
             10 STORE_FAST               1 (y)

  6          12 LOAD_GLOBAL              0 (print)
             14 LOAD_FAST                1 (y)
             16 CALL_FUNCTION            1
             18 POP_TOP
             20 RETURN_VALUE
```

Каждая строка байт-кода состоит из 4 частей:

1. **Номер строки в исходном коде (если есть)**
2. **Адрес в байт-коде** (в байтах)
3. **Инструкция (opcode)** — операция, которую выполняет Python
4. **Аргумент инструкции** (если есть)
