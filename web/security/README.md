# Веб-безопасность

Безопасность веб-приложения строится слоями: браузерные ограничения, проверка входных данных, разграничение доступа, безопасная конфигурация прокси, шифрование и мониторинг. Одна мера не заменяет остальные.

## Содержание

- [Атаки на браузер и пользователя](browser_attacks.md) — XSS, CSRF, CORS и clickjacking
- [Атаки на сервер и HTTP-инфраструктуру](server_attacks.md) — SSRF, traversal, smuggling и отказ в обслуживании
- [Защитные HTTP-заголовки](security_headers.md)

## Общий принцип

1. Считать весь внешний ввод недоверенным.
2. Проверять аутентификацию и полномочия на сервере для каждой операции.
3. Кодировать данные в соответствии с контекстом вывода.
4. Ограничивать размер, скорость и время обработки запросов.
5. Не раскрывать внутренние ошибки, пути, ключи и служебные заголовки.
6. Обновлять зависимости и вести журналы значимых событий.

Этот раздел — обзор и учебный конспект, а не полный стандарт защиты конкретной системы.
