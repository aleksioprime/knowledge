# OpenCV

**OpenCV** (Open Source Computer Vision Library) — крупнейшая open-source библиотека для компьютерного зрения и обработки изображений. Изначально разработана в Intel. Предоставляет инструменты для работы с изображениями и видео: детектирование объектов, распознавание лиц, анализ движения, фильтрация, морфология, преобразования цвета и геометрии.

Установка:

```sh
pip install opencv-contrib-python
```
