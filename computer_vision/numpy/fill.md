# Создание массива Numpy

```python
array = np.array(list(map(int,input().split())))
```

Функция `np.array()` из библиотеки NumPy преобразует список чисел в массив NumPy. Массив NumPy предоставляет дополнительные возможности для работы с числами, такие как быстрые математические операции, срезы, функции для статистического анализа и многое другое. Cписок `[1, 2, 3, 4, 5]` будет преобразован в массив NumPy `array([1, 2, 3, 4, 5])`.

В данном примере функция `map()` применяется к каждому элементу списка, созданного методом `.split()`. В данном случае, `map()` применяет функцию `int` к каждому элементу списка строк, преобразуя его в целое число. Если список строк `['1', '2', '3', '4', '5']`, `map(int, input().split())` вернет итератор, который будет содержать числа `[1, 2, 3, 4, 5]`. Функция `list()` преобразует итератор, возвращаемый `map()`, в список чисел

### Создание массива из нулей заданной формы

`np.zeros(shape)`

```python
import numpy as np

# Массив из нулей размером 2x3
zeros = np.zeros((2, 3))
print("Массив из нулей:\n", zeros)
```

Функция `np.zeros` принимает кортеж, задающий форму массива. В данном примере создается двумерный массив размером 2x3, заполненный нулями.
### Создание массива из единиц заданной формы

`np.ones(shape)`

```python
import numpy as np

# Массив из единиц размером 2x3
ones = np.ones((2, 3))
print("Массив из единиц:\n", ones)
```

Функция `np.ones` также принимает кортеж, задающий форму массива. В данном примере создается двумерный массив размером 2x3, заполненный единицами.
### Создание массива с равномерно распределенными значениями в заданном интервале

`np.arange(start, stop, step)`

```python
import numpy as np

# Массив от 0 до 9
arange = np.arange(10)
print("Массив от 0 до 9:", arange)
```

Функция `np.arange` создает одномерный массив с последовательностью чисел от `start` до `stop` (не включая `stop`) с шагом `step`. В данном примере создается массив чисел от 0 до 9 с шагом 1. Также, как и в операторе range() в Python, **`start`** и `**step**` могут быть пропущены, в этом случае:  `start = 0`, `step = 1`

### Создание массива с заданным количеством чисел, равномерно распределенных между `start` и `stop`

`np.linspace(start, stop, num)`

```python
import numpy as np

# Массив из 5 чисел от 0 до 1
linspace = np.linspace(0, 1, 5)
print("Массив из 5 чисел от 0 до 1:", linspace)
```

Функция `np.linspace` создает одномерный массив, содержащий `num` чисел, равномерно распределенных между `start` и `stop`. В данном примере создается массив из 5 чисел, равномерно распределенных от 0 до 1.
