# Pet-проекты

Учебные мини-сервисы, на которых отрабатываются реальные навыки: проектирование API, работа с БД, контейнеризация, тестирование, деплой.

## Содержание

- [Задачник](tasker/README.md) — сквозной учебный API для списка задач: на нём показаны темы из базы знаний
- [Онлайн-кинотеатр](movies/README.md) — бэкенд из нескольких сервисов: каталог и поиск, авторизация, оценки, аналитика событий, подписки и рассылки
- [Сокращатель ссылок](shortener/README.md) — сервис коротких ссылок: FastAPI, PostgreSQL, кэш и счётчики в Redis
