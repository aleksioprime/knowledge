`range()` — это встроенная функция в Python, которая **создаёт последовательность чисел**. Она возвращает **итерируемый объект**, а не список (что делает её более эффективной по памяти).  `range()` **отличается** тем, что это **ленивый генератор** (lazy iterator), который не хранит все элементы в памяти.

 **Синтаксис `range()`**

`range(start, stop, step)`

- **`start`** (необязательно) — с какого числа начать (по умолчанию `0`).
- **`stop`** (обязательно) — до какого числа (не включительно).
- **`step`** (необязательно) — шаг последовательности (по умолчанию `1`).

range объекты не являются итераторами

**range** является итеративным, мы можем получить итератор из него:

```python
iter(range(3)) # <range_iterator object at 0x7f043a0a7f90>
```

Но сами объекты range не являются итераторами. Мы не можем вызвать next для объекта range:

```vbnet
next(range(3))

Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
TypeError: 'range' object is not an iterator
```

И в отличие от итератора, мы можем перебрать объект range сколько угодно

```python
numbers = range(3)
tuple(numbers) # (0, 1, 2)
tuple(numbers) # (0, 1, 2)
```

В отличие от объектов zip, enumerate или generator объекты range не являются итераторами.
