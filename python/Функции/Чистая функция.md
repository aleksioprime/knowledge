**Чистая функция** (pure function) — это функция, которая всегда при одинаковых входных данных возвращает одинаковый результат и не оказывает никаких побочных эффектов на внешнее состояние программы.
### Основные признаки чистой функции:

1. **Детерминированность:**  
   Чистая функция для одних и тех же аргументов всегда возвращает один и тот же результат.
2. **Отсутствие побочных эффектов:**  
   Функция не изменяет внешние переменные, не модифицирует переданные ей объекты, не выполняет ввод/вывод (не пишет и не читает файлы, не выводит данные на экран, не изменяет глобальные переменные и т.п.).
### Примеры чистых функций:

```python
def add(a, b):
    return a + b

def square(x):
    return x * x
```

Вызов `add(2, 3)` всегда вернёт 5 и ничего больше не изменит.
### Примеры нечистых функций (с побочными эффектами):

```python
counter = 0

def increment():
    global counter
    counter += 1
    return counter

def print_hello():
    print("Hello!")  # вывод на экран — побочный эффект
```

Здесь результат зависит не только от аргументов, но и от внешних переменных, или функция что-то меняет вне себя.
### Зачем нужны чистые функции

- Легко тестировать, предсказывать результат
- Легко применять параллельно (нет конфликтов за ресурсы)
- Проще понимать и анализировать код
- Основа функционального программирования
### Важно

- Чистая функция не должна модифицировать изменяемые объекты, переданные ей в качестве аргументов
- В Python большинство стандартных функций для вычислений — чистые (например, `abs`, `sum`, `sorted`)
