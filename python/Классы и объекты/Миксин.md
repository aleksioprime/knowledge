**Миксин** — это специальный вспомогательный класс в объектно-ориентированном программировании, который добавляет дополнительные методы или свойства к другим классам через множественное наследование.  
Главная цель миксина — добавить определённый набор функций к различным классам, не превращая его в полноценного родителя по смыслу.

**Основные свойства миксинов:**
- Обычно небольшие и самостоятельные (single responsibility).
- Не предназначены для самостоятельного создания экземпляров.
- Используются только для "примешивания" поведения к другим классам.
- В имени часто содержат слово `Mixin`

Применение:
- **Повторное использование кода.** Если есть несколько классов, которым нужно добавить одно и то же поведение (например, логирование, сериализация, сравнение), не нужно копировать код.
- **Избегать глубокой иерархии.** Не приходится создавать сложную иерархию классов для каждого сочетания свойств.
- **Разделение ответственности.** Миксины обычно решают одну задачу, что упрощает поддержку и тестирование кода.

```python
import datetime

class NowMixin:
    @staticmethod
    def now():
        return datetime.datetime.utcnow()

class User(NowMixin):
    def __init__(self, name):
        self.name = name

user = User("Ivan")
print(user.now())  # Выведет текущее UTC время
```

```python
from django.views.generic import View

class LoginRequiredMixin:
    def dispatch(self, request, *args, **kwargs):
        if not request.user.is_authenticated:
            return redirect('login')
        return super().dispatch(request, *args, **kwargs)

class MyView(LoginRequiredMixin, View):
    # Вьюшка доступна только для авторизованных пользователей
    pass
```
