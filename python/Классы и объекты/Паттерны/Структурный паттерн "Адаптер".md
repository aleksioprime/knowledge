Паттерн Адаптер описывает технику адаптации интерфейса. Задача состоит в том, чтобы один класс мог воспользоваться другим - с несовместимым интерфейсом - без внесения каких-либо изменений в оба класса. Это полезно, например, когда требуется воспользоваться не подлежащим изменению классом в контексте, на который он не был расчитан.

Адаптер обеспечивает совместную работу классов с несовместимыми интерфейсами, которая без него была бы невозможна.

Он как "переходник" между розеткой и вилкой: если у тебя есть объект с неудобным (несовместимым) методом, адаптер превращает его в тот интерфейс, который тебе нужен.

Это нужно, когда:

- Ты не можешь (или не хочешь) изменять исходные классы (например, это сторонняя библиотека).
- Но тебе нужно, чтобы все объекты поддерживали **один и тот же интерфейс** (например, метод `make_noise()`).
- Адаптер позволяет вызывать нужные методы на разных объектах **одинаково**.

```python
# Старый интерфейс — EuropeanSocket (европейская розетка)
class EuropeanSocket:
    def voltage(self):
        return 220

    def live(self):
        return 1

    def neutral(self):
        return -1

    def earth(self):
        return 0

# Клиент ожидает работать с интерфейсом USASocket (американская розетка)
class USASocket:
    def voltage(self):
        return 110

    def live(self):
        return 1

    def neutral(self):
        return 0

# Устройство (например, американский прибор), который хочет работать с USASocket
class AmericanDevice:
    def __init__(self, socket):
        self.socket = socket

    def power_on(self):
        v = self.socket.voltage()
        if v > 120:
            print("Device burned out! Voltage too high.")
        else:
            print("Device is running on voltage", v)

# Теперь задача: подключить AmericanDevice к EuropeanSocket
# Для этого создаём адаптер

class EuropeanToUSAdapter(USASocket):
    """
    Адаптер. Наследует интерфейс, который ожидает клиент (USASocket),
    а внутри использует европейскую розетку.
    """
    def __init__(self, euro_socket):
        self.euro_socket = euro_socket

    def voltage(self):
        # Адаптируем 220V к 110V (условно, например, с помощью понижающего трансформатора)
        return 110

    def live(self):
        return self.euro_socket.live()

    def neutral(self):
        # Подменяем нейтраль: в Европе это -1, а в США — 0
        return 0

# =========== Использование паттерна Adapter ===========

def main():
    # У нас есть европейская розетка
    euro_socket = EuropeanSocket()

    # Мы подключаем к ней адаптер
    adapter = EuropeanToUSAdapter(euro_socket)

    # Теперь можно воткнуть американское устройство через адаптер
    device = AmericanDevice(adapter)
    device.power_on()  # Device is running on voltage 110

if __name__ == "__main__":
    main()
```


- **EuropeanSocket** — "старый" класс (существующая розетка с другим интерфейсом).
- **USASocket** — "нужный" интерфейс, который ждёт новый код (клиент).
- **EuropeanToUSAdapter** — оборачивает европейскую розетку и переводит интерфейс под американский стандарт.
- **AmericanDevice** — работает только с USASocket, но с помощью адаптера может работать и с европейской розеткой.

Пример:

```python
class Dog:
    def __init__(self):
        self.name = "Dog"

    def bark(self):
        return "woof!"  # Собака лает

class Cat:
    def __init__(self):
        self.name = "Cat"

    def meow(self):
        return "meow!"  # Кот мяукает

class Human:
    def __init__(self):
        self.name = "Human"

    def speak(self):
        return "'hello'"  # Человек говорит

class Car:
    def __init__(self):
        self.name = "Car"

    def make_noise(self, octane_level):
        return "vroom" + "!" * octane_level  # Машина издает звук двигателя с разным количеством "!"

class Adapter:
    """
    Адаптер: оборачивает объект и предоставляет нужные методы
    (например, make_noise), перенаправляя их к подходящим методам
    исходного объекта.
    """
    def __init__(self, obj, **adapted_methods):
        self.obj = obj  # Сохраняем оригинальный объект
        # Добавляем новые методы, адаптированные под нужный интерфейс
        self.__dict__.update(adapted_methods)

    def __getattr__(self, attr):
        """
        Все вызовы методов и атрибутов, которых нет в Adapter,
        автоматически перенаправляются на исходный объект.
        """
        return getattr(self.obj, attr)

    def original_dict(self):
        """Вернуть словарь исходного объекта."""
        return self.obj.__dict__

# ========== Пример использования паттерна Adapter ==========

def main():
    objects = []

    # Оборачиваем собаку: теперь у неё есть метод make_noise (будет вызывать bark)
    dog = Dog()
    objects.append(Adapter(dog, make_noise=dog.bark))

    # Оборачиваем кота: теперь у него есть метод make_noise (будет вызывать meow)
    cat = Cat()
    objects.append(Adapter(cat, make_noise=cat.meow))

    # Оборачиваем человека: make_noise теперь вызывает speak
    human = Human()
    objects.append(Adapter(human, make_noise=human.speak))

    # Оборачиваем машину: make_noise будет вызывать make_noise(3)
    car = Car()
    objects.append(Adapter(car, make_noise=lambda: car.make_noise(3)))

    # Теперь можем одинаково вызывать make_noise у всех объектов!
    for obj in objects:
        # obj.name перенаправится на исходный объект через __getattr__
        print(f"A {obj.name} goes {obj.make_noise()}")

if __name__ == "__main__":
    main()
```

- **Adapter** — это универсальная "обёртка", которая позволяет задать нужные методы (например, `make_noise`) для любого объекта.
- Теперь мы можем работать со всеми разными классами (собака, кот, человек, машина) через один и тот же интерфейс (`make_noise`), не изменяя их исходный код.
- В цикле вызывается одинаковый код для всех объектов — это главная идея паттерна Adapter!
