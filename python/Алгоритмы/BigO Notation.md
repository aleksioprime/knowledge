**Big O Notation (нотация "О-большое")** — это стандартный способ оценки производительности (времени работы и потребления памяти) алгоритмов. Она показывает, как быстро (или медленно) растёт время выполнения или используемая память по мере увеличения размера входных данных.  

Big O часто называют **асимптотической сложностью**.
## Зачем нужна Big O Notation?

- Позволяет сравнивать эффективность алгоритмов независимо от конкретных реализаций и компьютеров.
- Помогает предсказывать поведение программы на больших объёмах данных.
- Является основой для анализа производительности кода и выбора оптимальных решений.
## Основные типы сложности

|Обозначение|Название|Пример|
|---|---|---|
|O(1)|Константная|Доступ по индексу в списке|
|O(log n)|Логарифмическая|Бинарный поиск|
|O(n)|Линейная|Линейный поиск|
|O(n log n)|Линейно-логарифмическая|Быстрая сортировка, merge sort|
|O(n²)|Квадратичная|Два вложенных цикла|
|O(2ⁿ), O(n!)|Экспоненциальная/факториал|Решение всех перестановок|

## Примеры на Python

### O(1) — Константная сложность

Время выполнения не зависит от размера данных.

```python
# Получение элемента по индексу — всегда одинаково быстро
lst = [10, 20, 30, 40]
print(lst[2])  # O(1)
```
### O(n) — Линейная сложность

Время выполнения прямо пропорционально количеству элементов.

```python
# Суммирование всех элементов
def total_sum(lst):
    s = 0
    for x in lst:
        s += x
    return s
# O(n)
```
### O(log n) — Логарифмическая сложность

Алгоритм быстро "сужает" диапазон поиска.

```python
# Бинарный поиск в отсортированном массиве
def binary_search(arr, target):
    left, right = 0, len(arr)-1
    while left <= right:
        mid = (left + right) // 2
        if arr[mid] == target:
            return mid
        elif arr[mid] < target:
            left = mid + 1
        else:
            right = mid - 1
    return -1
# O(log n)
```
### O(n²) — Квадратичная сложность

Два вложенных цикла: время работы пропорционально квадрату размера данных.

```python
# Проверка на дубликаты — наивный способ
def has_duplicates(lst):
    for i in range(len(lst)):
        for j in range(i+1, len(lst)):
            if lst[i] == lst[j]:
                return True
    return False
# O(n^2)
```
### O(n log n) — Линейно-логарифмическая сложность

Типична для эффективных алгоритмов сортировки.

```python
lst = [5, 2, 9, 1]
lst.sort()  # Встроенная сортировка Timsort — O(n log n)
```
## Пример таблицы с Big O для базовых операций Python

|Операция|Сложность|
|---|---|
|Список: lst[i]|O(1)|
|Список: lst.append(x)|O(1) (амортиз.)|
|Список: lst.insert(0,x)|O(n)|
|Поиск в списке|O(n)|
|Словарь: d[key]|O(1)|
|Проверка ключа в dict|O(1)|
|Итерация по dict|O(n)|
|Множество: s.add(x)|O(1)|
|Множество: x in s|O(1)|

## Полезные советы

- Константная (O(1)) и логарифмическая (O(log n)) — самые быстрые.
- Линейная (O(n)) и линейно-логарифмическая (O(n log n)) — подходят для больших данных.
- Квадратичная и экспоненциальная (O(n²), O(2ⁿ)) — избегайте на больших данных.
- Всегда стремитесь выбирать и реализовывать алгоритмы с меньшей асимптотической сложностью.
