Есть 5 кейсов использования подчеркивая в Python:

Для хранения значения последнего выражения в REPL (интерактивном режиме Python-консоли)

Игнорирования значения:

```python
for _ in range(3):
    print("Hello")
```

Для определения специального значения функции или переменной
- одинарное в начале или конце названия (для **внутренних переменных и методов**)

```python
class Person:
    def __init__(self, name):
        self._name = name  # "Приватная" переменная

p = Person("Alice")
print(p._name)  # ⚠️ Можно обратиться, но не стоит
```

- двойное в начале (для сильного сокрытия (name mangling))

```python
class Person:
    def __init__(self, name):
        self.__name = name  # "Скрытая" переменная

p = Person("Bob")
print(p.__name)  # ❌ Ошибка: AttributeError
print(dir(p))    # Но переменная спрятана как _Person__name
print(p._Person__name)  # ✅ Можно так обратиться
```

- двойное в начале и конце (**специальные (магические) методы** Python)

```python
class Example:
    def __str__(self):
        return "Я магический метод!"

obj = Example()
print(obj)  # 🔥 Автоматически вызовется __str__
```

Для использования в качестве функции локализации

```python
import gettext

gettext.bindtextdomain("messages", "locale")
gettext.textdomain("messages")
_ = gettext.gettext  # Подключаем функцию _() как переводчик

print(_("Hello, world!"))  # Переведёт строку на нужный язык
```

Для разделения символов числа (1_00 == 100)

```python
num1 = 1_000_000  # Тоже самое, что 1000000
num2 = 10_00  # Тоже самое, что 1000
print(num1, num2)  # 1000000 1000
```
