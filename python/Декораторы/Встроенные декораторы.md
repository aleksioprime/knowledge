**Встроенные декораторы Python** — это специальные функции, которые входят в стандартную библиотеку языка и могут использоваться для изменения поведения функций и методов без явного написания собственного декоратора.  
Встроенные декораторы делают код более удобочитаемым, позволяют реализовать паттерны ООП, кэширование, работу с абстракциями и многое другое.
### Основные встроенные декораторы Python

#### 1. **@property**

- Превращает метод класса в свойство, доступное как обычный атрибут.
- Позволяет реализовать геттеры, сеттеры и делитеры.

```python
class Circle:
    def __init__(self, r):
        self._r = r

    @property
    def radius(self):
        return self._r

    @radius.setter
    def radius(self, value):
        self._r = value

c = Circle(5)
print(c.radius)     # 5
c.radius = 10
print(c.radius)     # 10
```

---

#### 2. **@staticmethod**

- Объявляет метод класса статическим, то есть не получающим ни ссылку на экземпляр (`self`), ни на класс (`cls`).
- Используется для функций, связанных с классом, но не зависящих от состояния экземпляра или класса.

```python
class Math:
    @staticmethod
    def add(a, b):
        return a + b

print(Math.add(2, 3))  # 5
```
#### 3. **@classmethod**

- Объявляет метод класса, который вместо `self` получает первым аргументом сам класс (`cls`).
- Часто используется для альтернативных конструкторов.

```python
class Person:
    def __init__(self, name):
        self.name = name

    @classmethod
    def from_string(cls, string):
        name = string.title()
        return cls(name)

p = Person.from_string("ivan")
print(p.name)  # Ivan
```
#### 4. **@lru_cache**

- Кэширует результаты вызова функции (см. отдельную статью выше).
- Позволяет ускорить повторяющиеся вычисления.

```python
from functools import lru_cache

@lru_cache(maxsize=64)
def fib(n):
    if n < 2:
        return n
    return fib(n-1) + fib(n-2)
```
#### 5. **@dataclass** (Python 3.7+)

- Автоматически создаёт методы инициализации, сравнения, представления для класса с данными.
- Позволяет легко создавать "контейнеры" для данных.

```python
from dataclasses import dataclass

@dataclass
class Point:
    x: int
    y: int

p = Point(1, 2)
print(p)  # Point(x=1, y=2)
```

#### 6. **@abstractmethod** и другие декораторы из `abc`

- Используются для создания абстрактных классов и методов.
- Заставляют наследников реализовывать указанные методы.

```python
from abc import ABC, abstractmethod

class Animal(ABC):
    @abstractmethod
    def voice(self):
        pass
```
#### 7. **@wraps** (из functools)

- Используется при создании своих декораторов для копирования имени и документации оборачиваемой функции.

```python
from functools import wraps

def my_decorator(func):
    @wraps(func)
    def wrapper(*args, **kwargs):
        return func(*args, **kwargs)
    return wrapper
```

## Когда использовать встроенные декораторы?

- Для реализации геттеров/сеттеров — `@property`
- Для методов, не зависящих от экземпляра — `@staticmethod`
- Для методов, работающих с классом — `@classmethod`
- Для кэширования — `@lru_cache`
- Для описания классов данных — `@dataclass`
- Для абстракций и интерфейсов — `@abstractmethod`
- Для написания своих декораторов — `@wraps`
