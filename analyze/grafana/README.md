# Grafana

**Grafana** — open-source платформа для визуализации метрик, логов и трассировок. Поддерживает множество источников данных: Prometheus, Loki, InfluxDB, PostgreSQL, Elasticsearch, ClickHouse и др.

Возможности:
- Кастомные дашборды и панели (graph, gauge, table, heatmap)
- Variables (выбор окружения, инстанса, периода)
- Alerting (нативный или через интеграцию с Alertmanager)
- Annotations — отметки событий на графиках
- Шаблоны дашбордов с Grafana.com
- Provisioning через YAML/JSON (Infrastructure as Code)

Типичный стек: **Prometheus + Grafana** (метрики), **Loki + Grafana** (логи), **Tempo + Grafana** (трассировки).
