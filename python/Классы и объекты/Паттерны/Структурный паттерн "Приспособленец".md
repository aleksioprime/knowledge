Приспособленец предназначен для обработки большого числа сравнительно небольших объектов, когда многие из этих объектов являются дубликатами. Реализация паттерна предполагает, что каждый уникальный объект представлется всего один раз и именно этот экземпляр отдается на запрос. В Python легко реализуется через словарь.

В Python подход к реализации приспособленцев естественный - благодаря наличию ссылок на объекты. Например, если бы у нас был длинный список строк, в котором много дубликатов, то, сохраняя ссылки на объекты (то есть переменные), а не литеральные строки, мы бы могли существенно сэкономить память

```python
import weakref

class Card:
    """Приспособленец: хранит только уникальные экземпляры карт."""
    # Слабое хранилище для уникальных объектов (пул)
    _pool = weakref.WeakValueDictionary()

    def __new__(cls, value, suit):
        """
        Если карта уже есть в пуле — вернуть её.
        Если нет — создать новую, добавить в пул и вернуть.
        """
        key = value + suit
        obj = cls._pool.get(key)
        if obj is None:
            obj = object.__new__(Card)
            cls._pool[key] = obj
            # Обычно инициализация делается в __init__, но здесь — сразу в __new__
            obj.value, obj.suit = value, suit
        return obj

    def __repr__(self):
        return f"<Card: {self.value}{self.suit}>"

# ======= Пример использования =======
def main():
    c1 = Card('9', 'h')    # Создаётся новая карта
    c2 = Card('9', 'h')    # Получаем ссылку на ту же самую карту из пула

    print(c1, c2)          # <Card: 9h> <Card: 9h>
    print(c1 == c2)        # True (значения совпадают)
    print(c1 is c2)        # True (это один и тот же объект в памяти!)

    c1.new_attr = 'temp'   # Добавим новый атрибут

    c3 = Card('9', 'h')    # Получим ту же карту, с теми же атрибутами
    print(hasattr(c3, 'new_attr'))  # True

    Card._pool.clear()     # Очищаем пул (например, завершение игры)
    c4 = Card('9', 'h')    # Теперь снова создаётся новая карта
    print(hasattr(c4, 'new_attr'))  # False

if __name__ == "__main__":
    main()
```

- `Card._pool` — **пул (словарь) уникальных экземпляров** карт. Используется `WeakValueDictionary`, чтобы карты автоматически удалялись из памяти, когда на них больше нет ссылок.
- **Метод `__new__`**:
    - Проверяет, есть ли карта с такими значениями в пуле.
    - Если есть — возвращает существующую.
    - Если нет — создаёт новую, добавляет в пул и возвращает.
- Все карты с одинаковым значением и мастью — **это один и тот же объект** (экономия памяти и быстродействие).

Применение:

Много одинаковых (или похожих) объектов, например:
- Клетки в текстовом редакторе
- Символы, строки, цвета
- Геометрические точки/фигуры в редакторах
- Игровые объекты (например, солдаты, деревья)
