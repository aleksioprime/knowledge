**LEGB** — это правило поиска переменных (области видимости) в Python, которое определяет, где и в каком порядке интерпретатор ищет значение имени (переменной, функции и т. д.) при выполнении кода.  
Название **LEGB** — это аббревиатура по первым буквам четырёх уровней областей видимости:
## L — Local (Локальная)

- Локальная область видимости: переменные, определённые внутри текущей функции.
- Сначала поиск идёт в локальной области видимости текущей функции или лямбда-выражения.

**Пример:**

```python
def func():
    x = 10  # локальная переменная
    print(x)
```
## E — Enclosing (Замыкающая, вложенная)

- Замыкающая область видимости: переменные в окружающих (внешних) функциях, если функция вложена в другую функцию.
- Это область видимости внешних функций для вложенных.

**Пример:**

```python
def outer():
    x = 20  # enclosing (замыкающая) область
    def inner():
        print(x)  # берёт x из enclosing
    inner()
outer()
```
## G — Global (Глобальная)

- Глобальная область видимости: переменные, определённые на уровне модуля (файла).
- Если не найдено в Local и Enclosing, поиск идёт по глобальным переменным модуля.

**Пример:**

```python
x = 30  # глобальная переменная

def func():
    print(x)  # если нет локальной или enclosing, берётся глобальная
func()
```
## B — Built-in (Встроенная)

- Встроенная область видимости: все имена, определённые в стандартной библиотеке Python (`len`, `list`, `print` и др.).
- Самый последний уровень поиска.

**Пример:**

```python
def func():
    print(len([1, 2, 3]))  # len берётся из built-in
func()
```
## Схематически:

1. **Local** — локальные переменные текущей функции
2. **Enclosing** — переменные внешних функций (если есть вложенность)
3. **Global** — переменные модуля
4. **Built-in** — встроенные имена Python
### Пример с пояснением

```python
x = 'global'

def outer():
    x = 'enclosing'
    def inner():
        x = 'local'
        print(x)  # Найдёт 'local'
    inner()
    print(x)      # Найдёт 'enclosing'

outer()
print(x)          # Найдёт 'global'
```

---

**LEGB — ключ к пониманию областей видимости и поиска имён в Python.**  
Это правило помогает избежать ошибок, связанных с "невидимыми" переменными и понять, почему интерпретатор выбирает то или иное значение имени.
