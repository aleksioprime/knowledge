**Type Hinting** (аннотация типов, “подсказка типов”) — это механизм в Python, позволяющий указывать ожидаемые типы переменных, аргументов функций и возвращаемых значений прямо в коде.

### Зачем нужен Type Hinting?

- Для **улучшения читаемости кода** — сразу видно, что функция ожидает и что возвращает.
- Для **подсказок IDE и автодополнения**.
- Для **статического анализа** кода (например, инструментами `mypy`, `pyright`).
- Для генерации документации.

```python
def multiply(x: int, y: int) -> int:
    return x * y
```


Распространённые типы из модуля `typing`

- `int`, `float`, `str`, `bool` — простые типы
- `List[int]`, `Dict[str, float]` — коллекции с типами
- `Tuple[int, str]` — кортежи с типами
- `Optional[str]` — может быть `str` или `None`
- `Union[int, str]` — одно из двух (или больше) типов
- `Any` — любой тип (обычно избегают в явном виде)
- `Callable[[int, int], str]` — функция с типами аргументов и возвращаемого значения

```python
from typing import List, Dict, Tuple, Optional, Union, Callable, Any

def process(data: List[int]) -> int:
    return sum(data)

def find_user(users: Dict[int, str], user_id: int) -> Optional[str]:
    return users.get(user_id)

def handle(val: Union[int, str]) -> str:
    return str(val)

def custom_op(f: Callable[[int, int], int]) -> int:
    return f(2, 3)
```

Пайтон язык с динамической типизацией. Объявляя переменные, мы не обязаны указывать ее тип. Но, чтобы улучить читаемость кода и его поддержку, мы можем дополнительно делать аннотации типов. Аннотации не обрабатываются интерпретатором и никак не влияют на производительность

Аннотации для переменных пишут через двоеточие после идентификатора

```python
price: int = 5
```

Параметры функции аннотируются также, как переменные, а возвращаемое значение указывается после стрелки `->,` и до завершающего двоеточия

```python
def indent_right(s: str, width: int) -> str:
    return " " * (max(0, width - len(s))) + s
```

Если же функция никогда не возвращает управление (например, как sys.exit), следует использовать аннотацию NoReturn:

```python
def forever() -> NoReturn:
    while True:
        pass
```

Для полей класса аннотации должны быть указаны явно при определении класса.

```python
class Book:
    title: str
    author: str

    def __init__(self, title: str, author: str) -> None:
        self.title = title
        self.author = author

b: Book = Book(title='Fahrenheit 451', author='Bradbury')
```
