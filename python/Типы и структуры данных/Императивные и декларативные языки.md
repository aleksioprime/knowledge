Императивные и декларативные языки программирования — это два подхода к описанию того, как должна выполняться задача в компьютере.

**Императивные языки**  

Императивный стиль программирования основан на пошаговых командах, которые явно описывают, что и как нужно сделать для достижения результата. В программах на императивных языках разработчик управляет последовательностью действий: изменяет значения переменных, вызывает функции, использует операторы ветвления и циклы.

Примеры императивных языков: Python, C, Java, JavaScript, Pascal.

В императивном языке основной акцент делается на _алгоритме_: разработчик указывает, **каким образом** надо достичь цели.

**Пример императивного кода (на Python):**

```python
numbers = [1, 2, 3, 4, 5]
squared = []
for n in numbers:
    squared.append(n * n)
```

**Декларативные языки**  

Декларативный стиль программирования фокусируется на описании желаемого результата, а не на пошаговых инструкциях. Программист указывает, **что** должно быть получено, а не **как** этого достичь. Исполнение и алгоритмы остаются на усмотрение интерпретатора или компилятора.

Примеры декларативных языков: SQL, HTML, CSS, Prolog.  

В декларативном стиле часто пишутся запросы к базам данных и шаблоны разметки.

**Пример декларативного кода (SQL):**

```sql
SELECT name FROM users WHERE age > 18;
```

В этом запросе не указывается, каким образом происходит поиск и фильтрация — только сам факт, какой результат нужен.

**Декларативный стиль встречается и в Python**, например, при использовании функций высшего порядка:

```python
numbers = [1, 2, 3, 4, 5]
squared = list(map(lambda n: n * n, numbers))
```

Здесь указывается, что требуется преобразовать каждый элемент списка, но не описывается процесс перебора элементов явно.

**Сравнение:**

- Императивный подход — “как сделать” (процесс).
- Декларативный подход — “что получить” (результат).

Оба подхода часто сочетаются в современных языках и инструментах программирования.
