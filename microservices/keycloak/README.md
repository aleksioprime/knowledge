# Keycloak

**Keycloak** — open-source сервер аутентификации и управления доступом (Identity and Access Management) от Red Hat. Поддерживает OAuth 2.0, OpenID Connect и SAML 2.0.

Ключевые возможности:
- Single Sign-On (SSO) и Single Sign-Out
- Управление пользователями, ролями и группами
- Социальный логин (Google, GitHub, Facebook и др.)
- Federation с LDAP / Active Directory
- 2FA / MFA из коробки
- Realms — изоляция клиентов и пользователей
- Admin UI и Admin REST API

Типичная роль в микросервисной системе: централизованный Identity Provider, который выдаёт JWT-токены для доступа к API.
