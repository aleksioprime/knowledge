# Типы и преобразования

Тип определяет, что представляет собой значение и какие операции с ним возможны. JavaScript может преобразовывать типы автоматически, поэтому важно отличать явное преобразование от неявного и понимать его влияние на сравнения и вычисления.

## Примитивы

В JavaScript семь примитивных типов:

- `string` — строки;
- `number` — числа с плавающей точкой, включая `NaN` и `Infinity`;
- `bigint` — целые числа произвольной точности;
- `boolean` — `true` и `false`;
- `undefined` — значение не задано;
- `null` — явное отсутствие значения;
- `symbol` — уникальный идентификатор.

Все остальные значения — объекты, включая массивы, функции, даты и регулярные выражения.

```js
typeof 'hello' // проверяем тип значения; результат: 'string'
typeof 42 // проверяем тип значения; результат: 'number'
typeof undefined // проверяем тип значения; результат: 'undefined'
typeof (() => {}) // проверяем тип значения; результат: 'function'
typeof null         // 'object' — историческая особенность

Array.isArray([]) // проверяем, является ли значение массивом; результат: true
```

`undefined` обычно означает, что значение не было задано, а `null` разработчик присваивает явно как отсутствие значения. `typeof null === 'object'` — историческая особенность языка; проверяйте его через `value === null`.

## Значение и ссылка

Примитивы присваиваются по значению. Для объектов копируется ссылка:

```js
const original = { count: 1 } // создаём объект и сохраняем ссылку в переменной
const same = original // копируем ссылку на тот же объект, а не сам объект
same.count = 2 // записываем 2 в свойство count

console.log(original.count) // выводим значение в консоль; результат: 2
```

## Сравнение

Строгое равенство `===` сравнивает значения без приведения типов. Нестрогое `==` сначала может преобразовать операнды, поэтому его результат бывает менее очевидным.

```js
0 === false // строго сравниваем число и boolean без преобразования; результат: false
0 == false               // true — произошло приведение типов
Number.isNaN(NaN) // вызываем Number.isNaN(); результат: true
Object.is(NaN, NaN) // вызываем Object.is(); результат: true
{} === {}                // false — разные объекты
```

Используйте `===` и `!==`. Нестрогое сравнение полезно редко и требует знания правил приведения.

## Неявное преобразование типов

JavaScript иногда автоматически преобразует значение к ожидаемому типу. Это называется неявным приведением типов или coercion.

### Оператор `+`

Если хотя бы один операнд после преобразования является строкой, бинарный `+` выполняет конкатенацию. Остальные арифметические операторы обычно преобразуют значения в числа.

```js
1 + '2' // выполняем арифметическую операцию с неявным приведением типов; результат: '12'
'2' + 1 // выполняем арифметическую операцию с неявным приведением типов; результат: '21'
'6' - 2 // выполняем арифметическую операцию с неявным приведением типов; результат: 4
'6' * 2 // выполняем арифметическую операцию с неявным приведением типов; результат: 12
'text' - 1 // выполняем арифметическую операцию с неявным приведением типов; результат: NaN
```

Унарный `+` пытается преобразовать значение в число:

```js
+'42' // явно преобразуем значение в число унарным плюсом или минусом; результат: 42
+'' // явно преобразуем значение в число унарным плюсом или минусом; результат: 0
+true // явно преобразуем значение в число унарным плюсом или минусом; результат: 1
```

В прикладном коде `Number(value)` обычно читается понятнее.

### Логический контекст

Условия, `!`, `&&` и `||` используют truthy/falsy-преобразование:

```js
if ('0') { // проверяем условие и выполняем блок, если оно истинно
  // выполнится: непустая строка является truthy
}

Boolean([]) // вызываем Boolean(); результат: true
Boolean({}) // вызываем Boolean(); результат: true
```

### Нестрогое равенство

Оператор `==` приводит значения по специальному набору правил, из-за чего возможны неожиданные результаты:

```js
'' == 0 // пустая строка преобразуется в число 0; результат: true
false == 0 // boolean false преобразуется в число 0; результат: true
null == undefined // это специальная разрешённая пара нестрогого равенства; результат: true
[] == false // массив превращается в пустую строку, затем обе стороны — в 0; результат: true
```

Поэтому по умолчанию используйте `===` и преобразуйте данные явно:

```js
Number(inputValue) === expectedNumber // вызываем Number()
String(id) === routeId // вызываем String()
Boolean(value) // вызываем Boolean()
```

### Объект в сравнении или арифметике

Когда операции требуется примитив, объект пытается преобразоваться через `Symbol.toPrimitive`, затем через `valueOf()` и `toString()` — порядок зависит от ожидаемого типа.

```js
[1, 2] + [3, 4] // выполняем арифметическую операцию с неявным приведением типов; результат: '1,23,4'
```

Массивы превращаются в строки без квадратных скобок, поэтому подобные выражения трудно читать. Не полагайтесь на неявное преобразование объектов: сначала получите нужное поле или явно вызовите `String()`/`Number()`.

## Логические операторы `||`, `&&` и `??`

Эти операторы возвращают один из операндов, а не обязательно `true` или `false`:

- `a = b || c` — записывает `b`, если оно truthy, иначе `c`;
- `a = b && c` — записывает `b`, если оно falsy, иначе `c`;
- `a = b ?? c` — записывает `c` только тогда, когда `b` равно `null` или `undefined`.

```js
let a // создаём переменную, в которую по очереди запишем результаты выражений

a = 'Alex' || 'Без имени' // первый операнд truthy, поэтому || возвращает 'Alex'
a = '' || 'Без имени'     // 'Без имени'

a = 'Alex' && 42 // первый операнд truthy, поэтому && возвращает второй операнд 42
a = '' && 42 // первый операнд falsy, поэтому && сразу возвращает пустую строку

a = null ?? 10 // null означает отсутствие значения, поэтому ?? возвращает 10
a = 0 ?? 10 // ноль не равен null или undefined, поэтому ?? сохраняет 0
```

Операторы работают слева направо и используют короткое замыкание: правый операнд не вычисляется, если результат уже известен.

```js
isAuthorized && loadProfile() // выполняем побитовую операцию
cachedUser || loadUser() // выполняем побитовую операцию
```

Главное отличие `||` от `??`: оператор `||` заменяет все falsy-значения, включая `0`, `false` и пустую строку, а `??` — только отсутствие значения.

```js
0 || 10 // выполняем побитовую операцию; результат: 10
0 ?? 10 // выбираем правое значение только при null или undefined слева; результат: 0
```

## Truthy и falsy

Falsy-значения: `false`, `0`, `-0`, `0n`, `''`, `null`, `undefined` и `NaN`. Все объекты truthy, включая пустые массивы и объекты.

```js
Boolean([]) // вызываем Boolean(); результат: true
Boolean({}) // вызываем Boolean(); результат: true
```

## Явное преобразование

Явное преобразование показывает намерение разработчика прямо в коде. Для основных примитивов используют функции `String()`, `Number()` и `Boolean()`.

```js
Number('42') // вызываем Number(); результат: 42
Number('') // вызываем Number(); результат: 0
Number('unknown') // вызываем Number(); результат: NaN
String(42) // вызываем String(); результат: '42'
Boolean(0) // вызываем Boolean(); результат: false
parseInt('42px', 10) // вызываем parseInt(); результат: 42
```

Проверять число лучше через `Number.isNaN` и `Number.isFinite`, потому что глобальные `isNaN` и `isFinite` сначала приводят аргумент к числу.

`NaN` имеет тип `number` и не равен самому себе. Поэтому используйте `Number.isNaN(value)`, а не `value === NaN`.

## `parseInt()` и `parseFloat()`

Обе функции читают число с начала строки и останавливаются на первом неподходящем символе:

```js
parseInt('42px', 10) // вызываем parseInt(); результат: 42
parseFloat('3.14rem') // вызываем parseFloat(); результат: 3.14
parseInt('px42', 10)    // NaN: строка не начинается с числа
parseFloat('text') // вызываем parseFloat(); результат: NaN
```

`parseInt()` возвращает целое число. Второй аргумент задаёт систему счисления, и его лучше указывать явно:

```js
parseInt('101', 2) // вызываем parseInt(); результат: 5
parseInt('ff', 16) // вызываем parseInt(); результат: 255
parseInt('42', 10) // вызываем parseInt(); результат: 42
```

`parseFloat()` читает дробное число и не принимает основание системы счисления:

```js
parseFloat('12.5') // вызываем parseFloat(); результат: 12.5
parseFloat('12,5') // 12: десятичный разделитель — точка
```

Отличие от `Number()` в том, что `Number()` требует преобразования всей строки, а `parseInt()` и `parseFloat()` допускают текст после числа:

```js
Number('42px') // вызываем Number(); результат: NaN
parseInt('42px', 10) // вызываем parseInt(); результат: 42

Number('') // вызываем Number(); результат: 0
parseInt('', 10) // вызываем parseInt(); результат: NaN
```

Для усечения уже готового дробного числа используйте `Math.trunc()`, а не `parseInt()`: функции парсинга предназначены прежде всего для строк.

У функций также есть варианты `Number.parseInt()` и `Number.parseFloat()` с тем же поведением.

## Округление чисел

Основные методы объекта `Math`:

| Метод | Результат для `1.8` | Результат для `-1.8` | Правило |
|---|---:|---:|---|
| `Math.round()` | `2` | `-2` | до ближайшего целого |
| `Math.floor()` | `1` | `-2` | вниз, к `-Infinity` |
| `Math.ceil()` | `2` | `-1` | вверх, к `Infinity` |
| `Math.trunc()` | `1` | `-1` | отбрасывает дробную часть |

```js
Math.round(4.4) // вызываем Math.round(); результат: 4
Math.round(4.5) // вызываем Math.round(); результат: 5
Math.floor(4.9) // вызываем Math.floor(); результат: 4
Math.ceil(4.1) // вызываем Math.ceil(); результат: 5
Math.trunc(4.9) // вызываем Math.trunc(); результат: 4
```

При точной середине `Math.round()` выбирает значение в сторону `Infinity`, а не обязательно дальше от нуля:

```js
Math.round(1.5) // вызываем Math.round(); результат: 2
Math.round(-1.5) // вызываем Math.round(); результат: -1
```

Для отрицательных чисел особенно важно различие `floor()` и `trunc()`:

```js
Math.floor(-1.8) // вызываем Math.floor(); результат: -2
Math.trunc(-1.8) // вызываем Math.trunc(); результат: -1
```

### Округление до нескольких знаков

Для математического результата можно использовать множитель:

```js
function roundTo(value, digits) { // объявляем функцию roundTo()
  const factor = 10 ** digits // сохраняем числовое значение в переменной
  return Math.round(value * factor) / factor // возвращаем вызывающему коду значение выражения Math.round(value * factor) / factor
}

roundTo(12.3456, 2) // вызываем roundTo(); результат: 12.35
```

Из-за двоичного представления дробей некоторые значения могут округляться неожиданно:

```js
0.1 + 0.2 // выполняем арифметическую операцию с неявным приведением типов; результат: 0.30000000000000004
```

Для денежных расчётов часто хранят минимальные целые единицы, например копейки, либо используют специализированную decimal-библиотеку.

### `toFixed()`

`toFixed()` удобно использовать для отображения фиксированного количества знаков, но он возвращает строку:

```js
const price = 12.3 // сохраняем числовое значение в переменной

price.toFixed(2) // вызываем price.toFixed(); результат: '12.30'
typeof price.toFixed(2) // проверяем тип значения; результат: 'string'
```

Для форматирования числа пользователю с учётом языка и разделителей используйте `Intl.NumberFormat`:

```js
new Intl.NumberFormat('ru-RU', { // создаём форматтер числа для выбранной локали
  maximumFractionDigits: 2, // задаём свойство maximumFractionDigits
}).format(1234.567) // форматируем число и получаем строку '1 234,57'
```

Не используйте `parseInt()` или побитовые операторы для обычного округления: `parseInt()` предназначен для разбора строк, а побитовые операции ограничивают число 32 битами.

## Строковые `slice()` и `substring()`

Оба метода возвращают часть строки от начального индекса до конечного, не включая конечный индекс. Исходная строка не изменяется: строки в JavaScript неизменяемы.

```js
const value = 'JavaScript' // сохраняем строку в переменной

value.slice(0, 4) // получаем часть значения без изменения оригинала; результат: 'Java'
value.substring(0, 4) // вызываем value.substring(); результат: 'Java'
```

Главное отличие — обработка отрицательных индексов и перепутанных границ.

### `slice(start, end)`

Поддерживает отрицательные индексы, отсчитывая их от конца строки. Если `start` находится правее `end`, возвращается пустая строка.

```js
'JavaScript'.slice(-6) // извлекаем часть строки, поддерживая отрицательные индексы; результат: 'Script'
'JavaScript'.slice(4, 0) // извлекаем часть строки, поддерживая отрицательные индексы; результат: ''
```

### `substring(start, end)`

Отрицательный индекс преобразуется в `0`. Если `start` больше `end`, метод меняет границы местами.

```js
'JavaScript'.substring(-4, 4) // извлекаем часть строки с нормализацией и перестановкой индексов; результат: 'Java'
'JavaScript'.substring(4, 0) // извлекаем часть строки с нормализацией и перестановкой индексов; результат: 'Java'
```

В современном коде обычно удобнее `slice()`: его поведение предсказуемее и одинаково знакомо по строкам и массивам.

Метод `substr(start, length)` принимает длину вместо конечного индекса, но считается устаревшим и не рекомендуется для нового кода.

Не путайте строковый `slice()` с массивами: принцип границ тот же, но для массива возвращается новый массив.

```js
[1, 2, 3, 4].slice(1, 3) // получаем часть значения без изменения оригинала; результат: [2, 3]
```

## Поиск в строке

### Строковый `indexOf()`

Возвращает индекс первого совпадения или `-1`, если совпадения нет. Вторым аргументом можно задать позицию начала поиска.

```js
const text = 'JavaScript' // сохраняем строку в переменной

text.indexOf('Script') // ищем индекс значения; результат: 4
text.indexOf('a') // ищем индекс значения; результат: 1
text.indexOf('a', 2) // ищем индекс значения; результат: 3
text.indexOf('TypeScript') // ищем индекс значения; результат: -1
```

### Строковый `includes()`

Возвращает boolean и подходит, когда индекс не нужен. Второй аргумент также задаёт начальную позицию.

```js
text.includes('Script') // проверяем наличие значения; результат: true
text.includes('script') // проверяем наличие значения; результат: false
text.includes('Java', 1) // проверяем наличие значения; результат: false
```

### `startsWith()` и `endsWith()`

Проверяют начало и конец строки:

```js
text.startsWith('Java') // вызываем text.startsWith(); результат: true
text.endsWith('Script') // вызываем text.endsWith(); результат: true
```

У `startsWith()` второй аргумент задаёт начальную позицию. У `endsWith()` он задаёт длину части строки, в которой выполняется проверка.

```js
text.startsWith('Script', 4) // вызываем text.startsWith(); результат: true
text.endsWith('Java', 4) // вызываем text.endsWith(); результат: true
```

Все эти методы чувствительны к регистру. Для поиска без учёта регистра можно сначала привести обе строки к одному регистру:

```js
text.toLowerCase().includes(query.toLowerCase()) // проверяем наличие значения
```

`includes()`, `startsWith()` и `endsWith()` не принимают регулярное выражение. Для сложного поиска используйте `test()`, `search()` или `match()`.

## Другие методы строк

### `trim()`

Удаляет пробельные символы с начала и конца строки, но не внутри неё. Исходная строка не изменяется.

```js
const value = '  Java Script  ' // сохраняем строку в переменной

value.trim() // удаляем пробелы по краям строки; результат: 'Java Script'
value.trimStart() // вызываем value.trimStart(); результат: 'Java Script  '
value.trimEnd() // вызываем value.trimEnd(); результат: '  Java Script'
```

Частый пример — проверка пользовательского ввода без строк, состоящих только из пробелов:

```js
const name = input.value.trim() // удаляем пробелы по краям строки

if (!name) { // проверяем условие и выполняем блок, если оно истинно
  showError('Введите имя') // вызываем showError()
}
```

### `repeat()`

Возвращает строку, повторённую указанное количество раз:

```js
'ha'.repeat(3) // повторяем строку указанное количество раз; результат: 'hahaha'
'-'.repeat(5) // повторяем строку указанное количество раз; результат: '-----'
```

Количество должно быть неотрицательным конечным числом. Отрицательное значение или `Infinity` приведёт к `RangeError`.

### `split()`

Разбивает строку по разделителю и возвращает массив. Второй аргумент ограничивает количество элементов результата.

```js
'red,green,blue'.split(',') // разделяем строку на массив частей; результат: ['red', 'green', 'blue']
'2026-08-04'.split('-', 2) // разделяем строку на массив частей; результат: ['2026', '08']
'JavaScript'.split('') // разделяем строку на массив частей; результат: ['J', 'a', 'v', 'a', ...]
'JavaScript'.split() // разделяем строку на массив частей; результат: ['JavaScript']
```

Разделителем может быть регулярное выражение:

```js
'one   two\nthree'.split(/\s+/) // разделяем строку на массив частей; результат: ['one', 'two', 'three']
```

Обратная операция для массива — `join()`:

```js
['2026', '08', '04'].join('-') // объединяем элементы массива в строку; результат: '2026-08-04'
```

`split('')` делит строку по UTF-16 code units и может некорректно разделить некоторые эмодзи. Для перебора Unicode code points безопаснее `[...text]`, хотя составные эмодзи могут состоять и из нескольких code points.

## Сравнение строк

`===` проверяет точное совпадение символов и регистра:

```js
'JavaScript' === 'JavaScript' // сравниваем одинаковые последовательности символов; результат: true
'JavaScript' === 'javascript' // регистр первой буквы различается; результат: false
```

Операторы `<` и `>` сравнивают строки лексикографически по значениям UTF-16 code units, а не по правилам естественного языка:

```js
'apple' < 'banana' // сравниваем слева направо; результат: true
'Z' < 'a' // заглавная Z имеет меньший код, чем строчная a; результат: true
'10' < '2' // строки сравниваются посимвольно, поэтому '1' меньше '2'; результат: true
```

Для сортировки пользовательского текста с учётом языка используйте `localeCompare()`:

```js
const names = ['Ёж', 'Алексей', 'Борис'] // создаём массив с начальными элементами

names.toSorted((a, b) => a.localeCompare(b, 'ru')) // создаём отсортированную копию массива
```

`localeCompare()` возвращает отрицательное число, `0` или положительное число. Нельзя рассчитывать, что это будут именно `-1` и `1`.

Для поиска или сравнения без учёта регистра можно передать настройки:

```js
'Москва'.localeCompare('москва', 'ru', { // сравниваем строки с учётом выбранной локали
  sensitivity: 'accent', // задаём свойство sensitivity
})
```

Внешне одинаковые Unicode-строки иногда имеют разное внутреннее представление. Перед техническим сравнением таких данных может потребоваться `normalize()`.

```js
'é'.normalize() === 'e\u0301'.normalize() // нормализуем Unicode и сравниваем эквивалентные записи; результат: true
```

## Boxing и unboxing

При обращении к методу примитива движок временно создаёт объект-обёртку, например `String` или `Number`, а затем снова получает примитив:

```js
'hello'.toUpperCase() // переводим строку в верхний регистр; результат: 'HELLO'
```

Не создавайте обёртки вручную через `new String()` или `new Boolean()`: результатом будет объект, а любой объект является truthy.
