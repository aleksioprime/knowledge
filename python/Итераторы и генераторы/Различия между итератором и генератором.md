### 1. **Создание**

- **Итераторы** обычно реализуются как отдельный класс с методами `__iter__()` и `__next__()`.

```python
class Counter:
	def __init__(self, max):
		self.count = 1
		self.max = max

	def __iter__(self):
		return self

	def __next__(self):
		if self.count > self.max:
			raise StopIteration
		value = self.count
		self.count += 1
		return value
```

- **Генераторы** создаются с помощью функций, содержащих ключевое слово `yield`, либо с помощью генераторных выражений (в круглых скобках).

```python
def counter(max):
	count = 1
	while count <= max:
		yield count
		count += 1
    ```
### 2. **Синтаксис**

- **Итератор** требует реализации двух методов: `__iter__()` и `__next__()`.
- **Генератор** требует только функции с ключевым словом `yield` — синтаксис проще и короче.
### 3. **Память**

- **Оба** работают «лениво» и не хранят все элементы в памяти.
- Однако **генераторы** обычно проще для создания ленивых последовательностей.
### 4. **Применение**

- **Итераторы** удобны, когда нужно реализовать сложное поведение при итерировании или управлять внутренним состоянием.
- **Генераторы** лучше подходят для создания простых потоков данных, фильтрации, обработки больших файлов.
### 5. **Поведение**

- **Генератор** — это разновидность итератора: каждый генератор — итератор, но не каждый итератор — генератор.
- Генератор автоматически реализует методы `__iter__()` и `__next__()`, тогда как для итератора их нужно реализовать вручную.
### 6. **Остановка итерации**

- В **итераторе** окончание последовательности обычно сигнализируется через исключение `StopIteration` в методе `__next__()`.
- В **генераторе** это делается автоматически, когда выполнение доходит до конца функции или встречает оператор `return`.
