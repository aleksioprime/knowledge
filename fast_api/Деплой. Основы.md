## Популярные виды хостинга

**Выделенный сервер** — это физический сервер, предоставляемый в пользование одному клиенту. В отличие от виртуальных серверов (VPS), где ресурсы сервера разделяются между несколькими клиентами, на выделенном сервере все ресурсы (процессор, оперативная память, дисковое пространство, сетевой трафик) полностью подконтрольны одному пользователю.

**Виртуальный сервер (VPS, Virtual Private Server)** — это виртуальная машина, эмулирующая физический сервер. Несколько VPS могут работать на одном физическом сервере, разделяя его ресурсы (процессор, оперативная память, дисковое пространство). Каждый VPS изолирован от других, предоставляя пользователю выделенную среду с собственными ресурсами.

**Облачные сервисы (Cloud services)** — это модель предоставления вычислительных ресурсов, таких как серверы, хранилище данных, программное обеспечение и сети, по требованию через Интернет. Вместо того, чтобы владеть и поддерживать собственную физическую инфраструктуру, пользователи получают доступ к этим ресурсам от поставщика облачных услуг (например, Amazon Web Services (AWS), Microsoft Azure, OpenAI Cloud Platform (GCP)).

## Домены

Домен — это уникальное имя, которое идентифицирует конкретный ресурс в интернете, например, веб-сайт, электронную почту или другой сервис. 

Доменное имя (например, `example.com`) представляет собой удобочитаемую форму IP-адреса (числового адреса, используемого для идентификации компьютеров в сети). 

Доменная система имен (DNS) преобразует доменные имена в соответствующие IP-адреса, что позволяет пользователям легко находить ресурсы в интернете по удобным для запоминания именам.

Уровни доменов представляют собой иерархическую структуру, использующуюся в системе доменных имен (DNS). Доменное имя состоит из нескольких частей, и каждая из них представляет определенный уровень. По порядку от самого верхнего к самому нижнему:

- **Домен верхнего уровня (Top-level domain, TLD):** Это уровень, идущий сразу под корневым доменом. Он обозначает категорию, тип или географическое положение ресурса. Примеры:
    
    - **Генеральные (generic):** `.com` (коммерческий), `.org` (организация), `.net` (сеть), `.info`(информация), `.biz` (бизнес), `.edu` (образование).
    - **Географические (country-code top-level domains, ccTLD):** `.ru` (Россия), `.us` (США), `.uk` (Великобритания), `.fr` (Франция).
    
- **Домен второго уровня (Second-level domain):** Этот уровень содержит имя, выбранное пользователем или организацией для идентификации конкретного ресурса. Например, в `google.com`, `google` — домен второго уровня. Это часть, которую обычно помнят люди.
    
- **Поддомены (Subdomains):** Поддомены представляют собой дополнительные уровни, которые добавляются к домену второго уровня. Например, `mail.google.com`, `www.google.com` — оба являются поддоменами `google.com`. Они используются для организации разных сервисов на одном основном домене.

Проверить привязку доменного имени к вашему серверу можно выполнив команду `ping`.

```sh
ping vst2.ru
```
