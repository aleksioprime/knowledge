В Python функция help() используется для отображения документации по модулям, классам, функциям, ключевым словам и так далее. Если help() не получает параметров, она запускает интерактивную справочную утилиту на консоли.

Функция dir() возвращает допустимый список атрибутов и методов объекта, к которому она вызывается. Поскольку функция предназначена для получения наиболее релевантных данных (вместо отображения полной информации), она ведет себя по-разному с разными объектами:

- Для модулей/библиотек функция dir() возвращает список всех атрибутов, содержащихся в этом модуле.
- Для объектов класса dir() вернет список всех допустимых атрибутов и базовых атрибутов.
- Когда ей не передаются никакие параметры, функция dir() возвращает список атрибутов в текущей области видимости.

Обычно сначала используют `dir()`, чтобы посмотреть, что есть, а потом `help()` — чтобы узнать, как этим пользоваться.

Примеры:

Вот наглядные примеры использования функций `help()` и `dir()` в Python:

**Пример 1. Получение справки по функции:**

```python
help(len)
```

_Выведет описание встроенной функции `len` и правила её использования._

**Пример 2. Получение списка атрибутов и методов объекта:**

```python
lst = [1, 2, 3]
print(dir(lst))
```

_Выведет список всех методов и атрибутов списка, например:_

```
['__add__', '__class__', '__contains__', ... 'append', 'clear', 'copy', ...]
```

**Пример 3. Справка по модулю:**

```python
import math
help(math)
```

_Выведет документацию по модулю `math` и его функциям._

**Пример 4. Список атрибутов модуля:**

```python
import math
print(dir(math))
```

_Покажет имена всех доступных функций и констант в модуле `math`, например:_

```
['__doc__', '__loader__', '__name__', 'acos', 'asin', 'atan', ...]
```

**Пример 5. Использование dir() без аргументов:**

```python
a = 10
b = [1, 2, 3]
print(dir())
```

_Выведет все переменные и функции, определённые в текущей области видимости (например, `['a', 'b']`)._

**Пример 6. Интерактивная справочная утилита:**

```python
help()
```

_Запускает интерактивный справочник, из которого можно узнать о ключевых словах, модулях, получить справку по функциям и т.д._
