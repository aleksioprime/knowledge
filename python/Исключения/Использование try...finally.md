Конструкция `try...finally` применяется для выполнения завершающих действий, которые должны произойти независимо от того, произошло исключение в блоке `try` или нет. Это важно для управления ресурсами, такими как файлы, сетевые соединения или блокировки, которые необходимо корректно освободить или закрыть в любом случае.

Рассмотрим несколько примеров, где использование `try...finally` без `except` оправдано:

**1. Закрытие файлов**

```python
file = open('example.txt', 'r')
try:
    data = file.read()
    # Обработка данных
finally:
    file.close()  # Файл будет закрыт в любом случае
```

**2. Освобождение ресурсов**

```python
resource = acquire_resource()
try:
    use_resource(resource)
    # Работа с ресурсом
finally:
    release_resource(resource)  # Ресурс будет освобожден в любом случае
```

**3. Сброс состояний или завершение транзакций**

```python
from contextlib import contextmanager


@contextmanager
def open_db_connection():
    try:
        connection = db_pool.acquire()
        yield connection
    finally:
        # соединение закроется в любом случае
        connection.close()

with open_db_connection() as connection:
    ...
```

В этих примерах блок `finally` гарантирует выполнение завершающих действий, таких как закрытие файла, освобождение ресурса или завершение транзакции, даже если в блоке `try` возникло исключение. Это предотвращает утечки ресурсов и обеспечивает корректное завершение операций, что особенно важно в программировании, где управление ресурсами и надежность системы играют ключевую роль.
