`@classmethod` и `@staticmethod` в Python - это встроенные декораторы, которые позволяют нам изменить поведение методов в определенной степени. Они отличаются тем, как именно они изменяют поведение этих методов. `@classmethod` - это [[Определение декоратора]], который позволяет вызвать метод, связанный с классом, а не экземпляром класса. Он имеет доступ ко всем атрибутам класса, может изменять состояние класса, что отражается на всех экземплярах класса. `@classmethod` принимает первым аргументом ссылку на класс, а не на экземпляр класса. 

Например, в Python можно использовать его следующим образом:

```python
class MyClass:
	# Статическая переменная (общая для всех экземпляров)
    count = 0 
    
    def __init__(self):
	    # Увеличиваем счетчик при создании объекта
        MyClass.count += 1 
        
    @classmethod
    def instance_count(cls):
        return cls.count

# Вызываем метод без создания объекта
print(MyClass.instance_count()) # 0

a = MyClass() # Создаём первый объект
print(MyClass.instance_count()) # 1

b = MyClass() # Создаём второй объект
print(MyClass.instance_count()) # 2
```

- Когда метод **работает с классом** (`cls`), а не с конкретным объектом.
- Когда нужно **изменять или получать данные класса** (например, счётчик объектов).
- Когда создаются **альтернативные конструкторы** (например, `from_dict`).

Например, счётчик созданных объектов, создание объекта из словаря, создание подклассов из одного метода родителя, создание разных версий объектов, вызывая метод через сам класс

`@staticmethod` - это еще один [[Определение декоратора]], который позволяет вызвать метод, который не имеет доступа ни к атрибутам экземпляра класса, ни к атрибутам класса. Он отделен от объектов класса и работает как обычная функция внутри класса. Например, в Python можно использовать его следующим образом:

```python
class MyClass:
    @staticmethod
    def my_method(x, y):
        return x + y

print(MyClass.my_method(5, 7))
```

В этом примере `my_method` действует как просто пространство имен для функции и не имеет доступа к состоянию класса или конкретного объекта класса, и мы можем вызывать этот метод, не создавая экземпляры класса.

- Когда метод **не использует ни `cls`, ни `self`** (не работает с классом и объектом).
- Когда метод **логически связан** с классом, но **не изменяет его состояние**.
- Когда метод можно было бы сделать **отдельной функцией**, но он **логически относится к классу**.

Например, проверка валидности данных, методы для расчётов в финансовом приложении
