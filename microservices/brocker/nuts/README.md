# NATS

**NATS** — лёгкий, высокопроизводительный cloud-native брокер сообщений с открытым исходным кодом. Разработан для простоты, быстроты и облачных сред (Kubernetes, edge, IoT).

Особенности:
- Очень малый footprint (single binary, < 20 МБ)
- Subject-based маршрутизация (`orders.created`, `orders.*`)
- Поддержка request-reply, pub-sub, queue groups
- **JetStream** — модуль персистентности (как Kafka)
- Кластеризация и leaf-нодов из коробки
- Низкие задержки (микросекунды)
