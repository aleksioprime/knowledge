# Сравнение, проверка типов и копирование

Эти конструкции нужны, когда код ведёт себя неожиданно: список «сам» изменился после копирования, проверка типа не пропускает подкласс, `is` даёт `False` для одинаковых значений, а `or` возвращает не булево значение. Понимание, что происходит с объектами и ссылками, избавляет от таких сюрпризов.

## Минимальный пример

```python run
import copy

task = {"title": "Купить хлеб", "tags": ["дом"]}

alias = task              # копируется ссылка, а не объект
shallow = copy.copy(task)  # новый словарь, но список tags общий
deep = copy.deepcopy(task) # новый словарь и новый список

task["tags"].append("срочно")

print(alias is task)          # True
print(shallow == task)        # True — значения совпадают
print(shallow is task)        # False — но это разные объекты
print(shallow["tags"])        # ['дом', 'срочно'] — общий вложенный список
print(deep["tags"])           # ['дом']
```

## Как это работает

Переменная в Python хранит не значение, а ссылку на объект. Поэтому присваивание не копирует данные, а даёт объекту ещё одно имя; сравнение `==` смотрит на значения, а `is` — на то, один ли это объект. Копирование бывает поверхностным и глубоким: первое создаёт новый внешний контейнер, второе — ещё и копии всего вложенного.

### Операторы `==` и `is`

Оператор `==` сравнивает значения, а `is` — идентичность: указывают ли две переменные на один и тот же объект в памяти.

```python run
a = [1, 2, 3]
b = [1, 2, 3]
print(a == b)  # True
print(a is b)  # False — два разных списка

a = b
print(a == b)  # True
print(a is b)  # True — теперь это один объект
```

### Проверка типов

```python run
print(type(5))         # <class 'int'>
print(type("hello"))   # <class 'str'>

# type() не считает подкласс тем же типом: для True условие type(x) is int ложно
x = 5
if type(x) is int:
    print(x)

# isinstance проверяет, что объект — экземпляр класса или его наследника
print(isinstance(5, int))                 # True
print(isinstance(True, int))              # True (bool — подкласс int)
print(isinstance([1, 2], (list, tuple)))  # True: подходит любой из типов

# Проверка всех элементов списка
x = [1, 2, 3, 4, 5]
if all(isinstance(i, int) for i in x):
    print("Все элементы — числа")

# Пользовательские типы
class A: pass
class B(A): pass

b = B()

print(isinstance(b, A))   # True (B наследует A)

# Утиная типизация (duck typing): важен не тип, а наличие нужного метода
def f(x):
    if hasattr(x, "__len__"):
        print("У объекта есть длина:", len(x))

f([1, 2, 3])  # У объекта есть длина: 3
```

### Присваивание, поверхностная и глубокая копии

```python run
import copy

# Присваивание: b ссылается на тот же объект, что и a
a = [1, [2]]
b = a
b.append(3)
b[1].append(4)
print(a)  # [1, [2, 4], 3]

# Поверхностная копия: копируется только внешний список,
# вложенный список у a и b общий
a = [1, [2]]
b = copy.copy(a)
b.append(3)
b[1].append(4)
print(a)  # [1, [2, 4]]

# Глубокая копия: копируются и вложенные объекты
a = [1, [2]]
b = copy.deepcopy(a)
b.append(3)
b[1].append(4)
print(a)  # [1, [2]]

# Другие способы сделать поверхностную копию списка
b = list(a)
b = a[:]
b = [i for i in a]
b = a.copy()
```

### Операторы `and`, `or`, `not`

`and` и `or` возвращают не `True`/`False`, а один из операндов: `and` — первый ложный (или последний), `or` — первый истинный (или последний). `not` всегда возвращает `bool`.

```python run
print(not {1, 2, 3})  # False
print([] and 1)       # []
print([] or 1)        # 1
```

## Частые ошибки

- Сравнение строк или чисел через `is` → код работает на маленьких числах и коротких строках, но даёт `False` для `1000` или строки с пробелом → сравнивайте значения через `==`, а `is` оставьте для `None`, `True` и `False`.
- Копия через `b = a` → после изменения `b` «портится» и `a`, потому что это один объект → сделайте `a.copy()`, `list(a)` или `copy.deepcopy(a)`, если внутри есть вложенные структуры.
- Поверхностная копия вложенной структуры → внешний список новый, а вложенные списки и словари общие, и изменения просачиваются в оригинал → для вложенных данных используйте `copy.deepcopy`.
- Проверка `type(value) == int` → функция не принимает `bool` и экземпляры подклассов, хотя они ведут себя как `int` → используйте `isinstance(value, int)` или кортеж допустимых типов.
- Значение по умолчанию через `name = value or "гость"` → пустая строка, `0` и пустой список тоже заменяются на значение по умолчанию → если нужен только `None`, пишите `name = value if value is not None else "гость"`.

## Когда не использовать

`copy.deepcopy` — дорогой приём: он обходит всю структуру и создаёт копию каждого объекта. Если данные нужно только прочитать, копия не нужна вообще; если изменяется только верхний уровень, хватит поверхностной копии. Для неизменяемых объектов (кортежи, строки, `frozenset`) копировать нечего — их безопасно передавать по ссылке.

Проверка типов через `isinstance` в начале каждой функции тоже часто лишняя: Python рассчитан на утиную типизацию, и достаточно вызвать нужный метод, а ошибку обработать через `try`/`except`. Явная проверка оправдана на границах программы — при разборе входных данных или в публичном API библиотеки, где важно сообщение об ошибке.
