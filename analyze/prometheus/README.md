# Prometheus

**Prometheus** — open-source система мониторинга и алертинга. Собирает метрики с приложений и инфраструктуры по pull-модели (сам опрашивает endpoints), хранит их во встроенной time-series БД и предоставляет язык запросов PromQL.

Ключевые компоненты:
- **Prometheus Server** — собирает и хранит метрики
- **Exporters** — приложения, выставляющие метрики (`node_exporter`, `postgres_exporter`, FastAPI prometheus middleware)
- **Alertmanager** — обработка и доставка алертов (email, Slack, Telegram)
- **Pushgateway** — для коротких задач, которые не успевают быть scraped

Типы метрик:
- **Counter** — только растёт (число запросов)
- **Gauge** — может расти и падать (память, очередь)
- **Histogram** — распределение значений (latency)
- **Summary** — квантили на стороне клиента
