# NumPy

**NumPy** (Numerical Python) — фундаментальная библиотека для научных вычислений в Python. Добавляет поддержку многомерных массивов (`ndarray`) и предоставляет богатый набор функций для математических, статистических и линейных операций. Используется как основа в pandas, scikit-learn, PyTorch, OpenCV.

Установка:

```sh
pip install numpy
```
