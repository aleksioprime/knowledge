# Portainer

**Portainer** — веб-интерфейс для управления контейнерами в Docker, Docker Swarm, Kubernetes и Nomad. Упрощает администрирование без необходимости запоминать CLI-команды.

Возможности:
- Просмотр контейнеров, образов, томов, сетей
- Запуск, остановка, перезапуск, удаление контейнеров
- Логи и шелл в контейнерах из браузера
- Управление stack-ами (Docker Compose в UI)
- Управление пользователями и правами доступа
- Поддержка нескольких окружений (multi-environment)
