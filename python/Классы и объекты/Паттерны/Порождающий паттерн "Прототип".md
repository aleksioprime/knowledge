**Прототип** — это порождающий паттерн, который позволяет создавать новые объекты не через конструктор, а **клонируя уже существующий объект-прототип**. После клонирования можно изменить (дополнить/переопределить) некоторые свойства клона.

```python
import copy

class Prototype:
    """Класс-прототип, который может создавать свои копии."""

    value = 'default'

    def clone(self, **attrs):
        """
        Клонирует текущий объект и обновляет его атрибуты.

        Args:
            **attrs: именованные параметры, которые будут установлены в клоне.
        Returns:
            Новый объект такого же класса с обновлёнными атрибутами.
        """
        # Создаём новый объект того же класса, что и оригинал
        obj = self.__class__()
        # Копируем все атрибуты оригинального объекта в клон
        obj.__dict__ = copy.deepcopy(self.__dict__)
        # Обновляем атрибуты клона новыми значениями, если переданы
        obj.__dict__.update(attrs)
        return obj

class PrototypeDispatcher:
    """Диспетчер — управляет коллекцией прототипов."""

    def __init__(self):
        # Хранилище для прототипов по имени
        self._objects = {}

    def get_objects(self):
        """Получить все зарегистрированные прототипы."""
        return self._objects

    def register_object(self, name, obj):
        """Зарегистрировать прототип под именем."""
        self._objects[name] = obj

    def unregister_object(self, name):
        """Удалить прототип по имени."""
        if name in self._objects:
            del self._objects[name]

# ======= Пример использования =======
def main():
    # Создаём диспетчер прототипов
    dispatcher = PrototypeDispatcher()
    
    # Создаём объект-прототип по умолчанию
    prototype = Prototype()
    
    # Клонируем с разными параметрами
    a = prototype.clone(value='a-value', category='a')
    b = prototype.clone(value='b-value', is_checked=True)
    d = prototype.clone()  # Без изменений

    # Регистрируем клоны в диспетчере
    dispatcher.register_object('objecta', a)
    dispatcher.register_object('objectb', b)
    dispatcher.register_object('default', d)
    
    # Выводим содержимое диспетчера
    for name, obj in dispatcher.get_objects().items():
        print(f"{name}: value={obj.value}, attrs={obj.__dict__}")

if __name__ == '__main__':
    main()
```

Пояснение:

1. **Класс Prototype** — реализует метод `.clone()`, который создает копию текущего объекта и позволяет сразу изменить/добавить атрибуты.
2. **PrototypeDispatcher** — хранит и управляет разными прототипами (можно зарегистрировать и получить любой клон).
3. **main** — создаёт исходный прототип, на его основе делает разные клоны с уникальными атрибутами и хранит их в диспетчере.
4. На выводе видно, что клоны могут отличаться друг от друга любым набором атрибутов.

Используется:

- Когда создание нового объекта "с нуля" — затратное (например, сложная инициализация, ресурсоёмкие вычисления).
- Когда удобно быстро создавать объекты с похожей (или частично одинаковой) конфигурацией, но с небольшими изменениями.

Преимущества:

- **Быстрое копирование:** если нужен похожий объект — не надо заново писать конструктор, копируем прототип и меняем нужные параметры.
- **Гибкость:** можно хранить набор прототипов с разными конфигурациями и клонировать их при необходимости.
- **Удобство:** легко создавать много похожих объектов с небольшими отличиями.


### Пример: Создание писем по шаблону

```python
import copy

class Email:
    """Класс, представляющий электронное письмо."""
    def __init__(self, subject, body, sender, recipient):
        self.subject = subject
        self.body = body
        self.sender = sender
        self.recipient = recipient

    def clone(self, **attrs):
        """
        Клонирует текущее письмо и обновляет выбранные поля.
        """
        email_copy = copy.deepcopy(self)
        email_copy.__dict__.update(attrs)
        return email_copy

    def __str__(self):
        return f"From: {self.sender}\nTo: {self.recipient}\nSubject: {self.subject}\n\n{self.body}\n"

# ======= Пример использования =======
def main():
    # Исходный шаблон письма
    base_email = Email(
        subject="Собрание отдела",
        body="Уважаемые коллеги!\nПриглашаем вас на собрание отдела в пятницу в 15:00.",
        sender="boss@company.com",
        recipient="employee@company.com"
    )

    # Клонируем шаблон для разных сотрудников, меняя только получателя
    email1 = base_email.clone(recipient="ivanov@company.com")
    email2 = base_email.clone(recipient="petrova@company.com", subject="Важная встреча")

    print("----- Иванову -----")
    print(email1)
    print("----- Петровой -----")
    print(email2)

if __name__ == '__main__':
    main()
```

- **Шаблон:** Создаём объект письма (`base_email`) — это наш прототип.
- **Копирование:** Клонируем его для разных сотрудников, подставляя только изменившиеся поля (например, адрес получателя).
- **Результат:** Всё оформление и тело письма остаются прежними, а нужные поля меняются "на лету".

**Диспетчер** (или менеджер прототипов) — это вспомогательный класс, который:

- **Хранит и организует коллекцию разных прототипов** по ключу (имени, типу, назначению и т.д.)
- **Позволяет получать доступ к нужному прототипу** по ключу, чтобы быстро клонировать нужный шаблон
- **Обеспечивает единое место управления:** можно добавить, заменить, удалить или получить любой прототип

Диспетчер — это как полка с образцами:  Ты подходишь, берёшь нужный шаблон (по имени), делаешь копию, подписываешь и отдаёшь адресату.  Все шаблоны всегда лежат на одном месте — и добавить новый, и заменить старый легко.

```python
class EmailDispatcher:
    def __init__(self):
        self._templates = {}

    def register_template(self, name, template):
        self._templates[name] = template

    def get_template(self, name):
        return self._templates[name]

# ===== Пример =====
base = Email(
    subject="Собрание отдела",
    body="Текст письма...",
    sender="boss@company.com",
    recipient="employee@company.com"
)

vacation = Email(
    subject="Отпуск",
    body="Ваш отпуск одобрен!",
    sender="hr@company.com",
    recipient="employee@company.com"
)

dispatcher = EmailDispatcher()
dispatcher.register_template("meeting", base)
dispatcher.register_template("vacation", vacation)

# Теперь, чтобы отправить письмо по шаблону:
email1 = dispatcher.get_template("meeting").clone(recipient="ivanov@company.com")
email2 = dispatcher.get_template("vacation").clone(recipient="petrova@company.com")

print(email1)
print(email2)
```
