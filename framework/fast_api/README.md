# FastAPI

**FastAPI** — современный асинхронный веб-фреймворк для Python на базе Starlette и Pydantic. Поддерживает type hints, автоматическую генерацию OpenAPI/Swagger-документации, валидацию данных и dependency injection.

Ключевые особенности:
- Полностью асинхронный (async/await)
- Автогенерация документации (Swagger UI, ReDoc)
- Валидация запросов/ответов через Pydantic-модели
- Dependency Injection из коробки
- Высокая производительность (на уровне Node.js / Go)

## Сетевые основы

Каждое TCP/UDP-соединение однозначно определяется пятью параметрами:

- Source IP
- Source Port
- Destination IP
- Destination Port
- Protocol (TCP/UDP)

Сервер слушает фиксированный порт:
- 0.0.0.0:80
- 0.0.0.0:443

Клиенты приходят с разными портами источника
- 192.168.1.10:51820 -> 93.184.216.34:443
- 192.168.1.11:39214 -> 93.184.216.34:443
- 192.168.1.12:60017 -> 93.184.216.34:443

Клиент может открыть примерно 64k уникальных исходящих портов, значит один клиент → максимум ~64k соединений к одному и тому же серверу.

Но сервер может принимать миллионы клиентов, потому что у каждого клиента свой IP + свой набор портов.
