**Алгоритмы работы с числами** — это класс базовых процедур и приёмов, которые часто используются при решении задач на собеседованиях и в реальной практике программирования. Знание этих алгоритмов помогает быстро находить решения для задач, связанных с числами, делимостью, разложением на простые множители, поиском НОД и НОК, простыми числами и арифметикой.
## 1. Нахождение максимума и минимума

В Python для поиска максимального и минимального значения в последовательности достаточно использовать встроенные функции `max()` и `min()`:

```python
nums = [4, 2, 7, 1, 9]
max_val = max(nums)  # 9
min_val = min(nums)  # 1
```
## 2. Сумма и среднее значение

```python
nums = [4, 2, 7, 1, 9]
total = sum(nums)  # 23
average = sum(nums) / len(nums)  # 4.6
```
## 3. Поиск наибольшего общего делителя (НОД, GCD)

**Алгоритм Евклида** — классический и эффективный способ найти НОД двух чисел:

```python
def gcd(a, b):
    while b:
        a, b = b, a % b
    return a

print(gcd(36, 48))  # 12
```
## 4. Поиск наименьшего общего кратного (НОК, LCM)

НОК можно вычислить через НОД:  
`LCM(a, b) = abs(a * b) // GCD(a, b)`

```python
def lcm(a, b):
    return abs(a * b) // gcd(a, b)

print(lcm(12, 18))  # 36
```
## 5. Быстрое возведение в степень (Binary Exponentiation)

Полезно для вычисления больших степеней по модулю.

```python
def fast_pow(a, n):
    result = 1
    while n > 0:
        if n % 2 == 1:
            result *= a
        a *= a
        n //= 2
    return result

print(fast_pow(2, 10))  # 1024
```
## 6. Проверка на простоту числа

Простейший способ:

```python
def is_prime(n):
    if n <= 1:
        return False
    for i in range(2, int(n**0.5)+1):
        if n % i == 0:
            return False
    return True

print(is_prime(17))  # True
```
## 7. Генерация простых чисел (Решето Эратосфена)

Позволяет быстро получить список всех простых чисел до N:

```python
def sieve(n):
    is_prime = [True] * (n + 1)
    is_prime[0] = is_prime[1] = False
    for i in range(2, int(n**0.5) + 1):
        if is_prime[i]:
            for j in range(i * i, n + 1, i):
                is_prime[j] = False
    return [i for i, prime in enumerate(is_prime) if prime]

print(sieve(20))  # [2, 3, 5, 7, 11, 13, 17, 19]
```
## 8. Разложение числа на простые множители

```python
def prime_factors(n):
    factors = []
    d = 2
    while d * d <= n:
        while n % d == 0:
            factors.append(d)
            n //= d
        d += 1
    if n > 1:
        factors.append(n)
    return factors

print(prime_factors(60))  # [2, 2, 3, 5]
```
## 9. Сумма цифр числа

```python
def digit_sum(n):
    return sum(int(d) for d in str(abs(n)))

print(digit_sum(12345))  # 15
```
## 10. Перевод числа в другую систему счисления

**В двоичную:**

```python
print(bin(13))  # '0b1101'
```

**В десятичную из другой системы:**

```python
print(int('1101', 2))  # 13
```
## 11. Проверка числа на палиндром

```python
def is_palindrome(n):
    s = str(n)
    return s == s[::-1]

print(is_palindrome(12321))  # True
```
