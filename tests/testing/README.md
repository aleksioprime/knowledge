# Тестирование

Пирамида тестирования - это модель, описывающая распределение тестов по уровням в зависимости от их детализации и сложности. Так же модель отображает количество тестов в зависимости от уровня в пирамиде.

Пирамида включает три основных уровня:
- Unit-тесты (модульные) — основа надежности (покрывают отдельные функции/классы изолированно).
- Интеграционные тесты — проверка взаимодействия компонентов (проверяют взаимодействие между модулями (например, API и БД), требуют настройки окружения).
- E2E-тесты (сквозные) — имитация работы пользователя (покрывают ключевые сценарии (регистрация, оплата и т.д.)).
