Cтрока – это упорядоченная последовательность символов, которая предназначена для хранения информации в виде простого текста. В Python3 строка по умолчанию имеет кодировку Unicode, что избавляет от проблем работы и отображения символов кириллицы и прочих экзотических кодировок. Строка, это неизменяемый тип данных, т.е. если нужно добавить символов в существующую строку, придется создать новую строку, с новым адресом в памяти:

```python
a = "hello"
id(a) # 2044344987401 
a = "hello world" 
id(a) # 2044334957804
```
### Интерполяция строк

Интерполяция строк в программировании — это процесс вставки значений переменных или выражений в строки.

**Конкатенация с помощью оператора `+`**

Наиболее базовый способ — объединение строк с использованием оператора `+`.

```python
name = "Alice"
age = 30
message = "My name is " + name + " and I am " + str(age) + " years old."
print(message)  # My name is Alice and I am 30 years old.
```

**Метод `.format()`**

Метод `.format()` позволяет вставлять значения в строку, используя фигурные скобки `{}` как плейсхолдеры.

```python
name = "Alice"
age = 30
message = "My name is {} and I am {} years old.".format(name, age)
print(message)  # My name is Alice and I am 30 years old.
```

**Именованные параметры в методе `.format()`**

Можно использовать именованные параметры для повышения читаемости.

```python
message = "My name is {name} and I am {age} years old.".format(name="Alice", age=30)
print(message)  # My name is Alice and I am 30 years old.
```

**F-строки (форматированные строковые литералы)**

F-строки появились в Python 3.6 и являются наиболее удобным и читаемым способом интерполяции строк.

```python
name = "Alice"
age = 30
message = f"My name is {name} and I am {age} years old."
print(message)  # My name is Alice and I am 30 years old.
```

**Шаблонные строки с использованием `Template` из модуля `string`**

Шаблонные строки предоставляют способ интерполяции строк с помощью заменителей.

```python
from string import Template

template = Template("My name is $name and I am $age years old.")
message = template.substitute(name="Alice", age=30)
print(message)  # My name is Alice and I am 30 years old.
```

Оператор `%` также используется для интерполяции строк в Python. Этот метод был одним из первых способов форматирования строк в языке и до сих пор поддерживается, хотя обычно его заменяют более современными методами, такими как f-строки и метод `.format()`.

**Основной синтаксис:**

- `%s` для строковых значений.
- `%d` для целых чисел.
- `%f` для чисел с плавающей запятой.

```python
name = "Alice"
age = 30
height = 1.75
message = "Name: %s, Age: %d, Height: %.2f meters" % (name, age, height)
print(message)  # Name: Alice, Age: 30, Height: 1.75 meters
```
