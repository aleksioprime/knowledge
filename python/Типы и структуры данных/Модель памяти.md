Модель памяти Python определяет, как интерпретатор размещает, использует и освобождает память для объектов и переменных во время выполнения программы. Понимание устройства памяти важно для эффективной работы с переменными, объектами, областями видимости и управления ресурсами.
### Основные области памяти

**1. Куча (Heap)**  

Куча — это основная область памяти, где хранятся все объекты программы: числа, строки, списки, словари, функции, экземпляры классов и другие структуры данных. Все объекты создаются и существуют в куче до тех пор, пока на них имеются ссылки из переменных.  

Особенности кучи:

- Все значения данных размещаются в куче.
- Доступ к объекту осуществляется через ссылку (указатель), а не напрямую.
- Управление памятью на уровне кучи полностью автоматизировано.

**2. Стек вызовов (Call Stack, Стек)**  

Стек — это область памяти, где хранятся локальные переменные, параметры функций и информация о вызовах функций (фреймы стека).  
Особенности стека:

- Для каждого вызова функции создаётся отдельный стековый фрейм, в котором хранятся имена локальных переменных и ссылки на объекты в куче.
- После завершения работы функции соответствующий стековый фрейм уничтожается.

**Таблица:**

|Область памяти|Содержимое|
|---|---|
|Куча (Heap)|Все объекты программы (данные), доступные по ссылкам|
|Стек (Stack)|Локальные переменные, параметры функций, ссылки на объекты из кучи|

### Управление памятью

- **Сборка мусора (Garbage Collection)**  
    Python автоматически освобождает память, которую больше не использует программа. Основной механизм — подсчёт ссылок на объект: когда количество ссылок становится равным нулю, объект удаляется из кучи. Для борьбы с возможными “циклическими ссылками” используется дополнительный garbage collector.
- **Передача переменных по ссылке**  
    Все переменные в Python — это ссылки на объекты в куче. При присваивании или передаче переменной в функцию копируется ссылка, а не сам объект.

### Особенности

- Изменяемые объекты (например, списки, словари) при передаче в функцию позволяют изменять содержимое оригинального объекта.
- Неизменяемые объекты (например, строки, числа, кортежи) нельзя изменить после создания; любые “изменения” создают новый объект в куче.
