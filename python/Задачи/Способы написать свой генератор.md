Генераторы в Python — это **удобный способ создавать последовательности значений лениво**, без хранения всего списка в памяти.

Функция-генератор использует `yield`, чтобы **возвращать значения по одному**.

```python
def my_generator():
    print("Старт генератора")
    yield 1
    print("Следующий шаг")
    yield 2
    print("Последний шаг")
    yield 3

gen = my_generator()
print(next(gen))  # Старт генератора → 1
print(next(gen))  # Следующий шаг → 2
print(next(gen))  # Последний шаг → 3
# print(next(gen))  # ❌ StopIteration (генератор закончился)
```

Генераторное выражение (generator expression)

```python
gen = (x * 2 for x in range(5))
print(next(gen))  # 0
print(next(gen))  # 2
print(next(gen))  # 4
```

Можно создать генератор **через класс**, реализовав `__iter__()` и `__next__()`.

```python
class SquareGen:
    def __init__(self, max_num):
        self.max_num = max_num
        self.num = 0

    def __iter__(self):
        return self  # Генератор должен возвращать себя

    def __next__(self):
        if self.num >= self.max_num:
            raise StopIteration  # Останавливаем генератор
        self.num += 1
        return self.num ** 2  # Возвращаем квадрат числа

gen = SquareGen(3)
print(next(gen))  # 1
print(next(gen))  # 4
print(next(gen))  # 9
# print(next(gen))  # ❌ StopIteration
```
