# ООП в Python

Объектно-ориентированное программирование собирает данные и функции, которые с ними работают, в одном объекте. Заметки идут от устройства класса к принципам ООП и механизмам, которые управляют созданием классов и доступом к атрибутам.

## Содержание

- [Классы, методы и атрибуты](classes.md) — справка по классу, слоты, методы объекта, класса и статические, уровни доступа, атрибуты класса и объекта, декоратор `property`
- [Магические методы](magic_methods.md) — разница между `__new__` и `__init__`, `__str__` и `__repr__`
- [Принципы ООП](principles.md) — наследование и `super()`, композиция и агрегация, инкапсуляция, полиморфизм, абстрактный класс
- [Продвинутые приёмы ООП](advanced.md) — monkey patching, миксины, метаклассы, порядок разрешения методов, дескрипторы
