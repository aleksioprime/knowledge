**Множество (`set`)** — это **неупорядоченная коллекция уникальных элементов**.  
Множества похожи на списки и кортежи, но:  
✅ **Не содержат дубликатов**  
✅ **Быстро выполняют операции поиска (`O(1)`)**  
✅ **Поддерживают математические операции** (пересечение, объединение, разность)

Set как и Словари в питоне представляют собой хеш-таблицы

Соответственно можно положить любой хэшируемый тип данных, а это **все не изменяемые типы данных**

Кортеж (tupl) не может быть ключом в словаре или значением в set, в том случае если в нем изменяемые типы данных

`frozenset` — это **неизменяемое множество** (нельзя добавлять/удалять элементы).

```python
fs = frozenset([1, 2, 3])
# fs.add(4)  # Ошибка! frozenset неизменяем
```
