`__repr__` отвечает за то как объект будет отображаться внутри нашей системы (предназначен **для разработчика**: делает объект максимально информативным для диагностики)

`__str__` отвечает за то как объект будет отображаться для пользователя. Определяет строковое представление объекта. `__str__` по умолчанию, возвращает строковое представление адреса памяти объекта (предназначен **для пользователя**: делает объект удобочитаемым)

Если ты не определишь `__str__`, то при вызове `str(obj)` и `print(obj)` будет использоваться `__repr__`. Если не определён ни тот, ни другой, будет показан адрес в памяти вида `<User object at 0x...>`.

```python
class User:
    def __init__(self, first_name, last_name):
        self.first_name = first_name
        self.last_name = last_name

    def __str__(self):
        return f"__str__ method: {self.first_name} {self.last_name}"

    def __repr__(self):
        return f"__repr__ method: {self.first_name} {self.last_name}"

user = User("Vasya", "Pypkin")

print(str(user))      # вызовет __str__, обычно используемое представление
print(repr(user))     # вызовет __repr__, техническое представление
print(user)           # print вызывает str() -> __str__
users = [user]
print(users)          # список вызывает __repr__ для своих элементов
```

- **`__str__`** — если хочешь, чтобы при выводе объект был удобочитаем (для пользователя).
- **`__repr__`** — если хочешь, чтобы объект было удобно видеть при отладке и в списках.

Обычно `__repr__` стараются делать таким, чтобы по его результату можно было бы восстановить объект (например, `User('Vasya', 'Pypkin')`).
