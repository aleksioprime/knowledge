**Функции высшего порядка** — это такие функции, которые принимают в качестве аргументов другие функции **или** возвращают функции как результат.

Передача функции как аргумента:

```python
def apply(func, value):
    return func(value)

def square(x):
    return x * x

print(apply(square, 5))  # 25
```

Возврат функции:

```python
def make_multiplier(n):
    def multiplier(x):
        return x * n
    return multiplier

times3 = make_multiplier(3)
print(times3(10))  # 30
```

Встроенные функции высшего порядка:

- Функция **`map`** применяет указанную функцию к каждому элементу итерации и возвращает итератор с результатами.

```python
numbers = [1, 2, 3, 4, 5]
squared = map(lambda x: x ** 2, numbers)
print(list(squared))  # [1, 4, 9, 16, 25]
```

- Функция **`filter`** создает итератор, состоящий из тех элементов итерации, для которых указанная функция возвращает истину.

```python
numbers = [1, 2, 3, 4, 5]
evens = filter(lambda x: x % 2 == 0, numbers)
print(list(evens))  # [2, 4]
```

- Функция **`reduce`** из модуля **`functools`** применяет указанную функцию к элементам итерации, сводя её к единому значению.

```python
from functools import reduce

numbers = [1, 2, 3, 4, 5]
sum = reduce(lambda x, y: x + y, numbers)
print(sum)  # 15
```

- Анонимные функции, создаваемые с помощью ключевого слова **`lambda`**, часто используются как аргументы для других функций.

```python
add = lambda x, y: x + y
print(add(2, 3))  # 5
```

- Функция **`sorted`** возвращает новый отсортированный список из элементов любой итерации. Может принимать функцию в качестве аргумента для определения критерия сортировки.

```python
numbers = [5, 2, 3, 1, 4]
sorted_numbers = sorted(numbers, key=lambda x: x)
print(sorted_numbers)  # [1, 2, 3, 4, 5]
```

Дополнительная информация в статье [[Сортировка]]

- Функция **`any`** возвращает **`True`**, если хотя бы один элемент итерации является истиной. Иначе возвращает **`False`**.

```python
numbers = [0, 1, 2, 3]
result = any(numbers)
print(result)  # True
```

- Функция **`all`** возвращает **`True`**, если все элементы итерации являются истинными. Иначе возвращает **`False`**.

```python
numbers = [1, 2, 3, 4]
result = all(numbers)
print(result)  # True
```

- Функция **`zip`** объединяет несколько итераций, возвращая итератор кортежей.

```python
list1 = [1, 2, 3]
list2 = ['a', 'b', 'c']
zipped = zip(list1, list2)
print(list(zipped))  # [(1, 'a'), (2, 'b'), (3, 'c')]
```

- Функция **`enumerate`** добавляет счетчик к итерации и возвращает её в виде объекта **`enumerate`**.

```python
items = ['a', 'b', 'c']
enumerated_items = enumerate(items)
print(list(enumerated_items))  # [(0, 'a'), (1, 'b'), (2, 'c')]
```
