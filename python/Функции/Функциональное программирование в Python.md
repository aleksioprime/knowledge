**Функциональное программирование в Python** — это парадигма, в которой вычисления строятся как композиция функций, а данные чаще всего обрабатываются без явного изменения состояния (мутабельности). Хотя Python изначально не чисто функциональный язык, он предоставляет множество инструментов для поддержки функционального стиля.

## Основные идеи функционального программирования

- **Функции — объекты первого класса:** их можно передавать как аргументы, возвращать из других функций, присваивать переменным.
- **Отсутствие побочных эффектов:** идеальная функция не меняет внешние данные, а только возвращает результат.
- **Иммутабельность данных:** по возможности данные не изменяются, а создаются новые значения.
- **Функции высшего порядка:** функции, принимающие другие функции как параметры или возвращающие их.
- **Композиция функций:** объединение простых функций в более сложные.
## Функции как объекты первого класса

В Python функцию можно присваивать переменной, передавать как аргумент или возвращать из другой функции:

```python
def add(x, y):
    return x + y

f = add
print(f(2, 3))  # 5
```
## Лямбда-функции (анонимные функции)

Краткая запись для определения маленьких функций на месте:

```python
double = lambda x: x * 2
print(double(4))  # 8
```
## Функции высшего порядка

Пример: функция, принимающая другую функцию как аргумент:

```python
def apply(func, value):
    return func(value)

print(apply(lambda x: x ** 2, 5))  # 25
```
## map, filter, reduce

**map:** применяет функцию ко всем элементам последовательности  
**filter:** выбирает элементы, удовлетворяющие условию  
**reduce:** свёртывает последовательность в одно значение (нужен импорт из functools)

```python
numbers = [1, 2, 3, 4, 5]

# map
squared = list(map(lambda x: x**2, numbers))  # [1, 4, 9, 16, 25]

# filter
even = list(filter(lambda x: x % 2 == 0, numbers))  # [2, 4]

# reduce
from functools import reduce
product = reduce(lambda x, y: x * y, numbers)  # 120
```
## Генераторы и выражения-генераторы

Позволяют создавать ленивые последовательности (вычисления по требованию):

```python
squares = (x*x for x in range(10))
for sq in squares:
    print(sq)
```
## Иммутабельность

В функциональном стиле желательно избегать изменения исходных данных:

```python
numbers = [1, 2, 3]
new_numbers = list(map(lambda x: x + 1, numbers))
print(numbers)      # [1, 2, 3]
print(new_numbers)  # [2, 3, 4]
```
## Замыкания (closures)

Функция может возвращать другую функцию, которая “помнит” контекст создания:

```python
def make_adder(n):
    def adder(x):
        return x + n
    return adder

add_10 = make_adder(10)
print(add_10(5))  # 15
```
## Декораторы

Функции, которые принимают другую функцию и возвращают новую функцию с изменённым поведением:

```python
def my_decorator(func):
    def wrapper(*args, **kwargs):
        print("Что-то делаем до вызова")
        result = func(*args, **kwargs)
        print("Что-то делаем после вызова")
        return result
    return wrapper

@my_decorator
def greet(name):
    print(f"Привет, {name}!")

greet("Алиса")
```
## Итоги

- Python поддерживает многие элементы функционального программирования: функции высшего порядка, лямбда-выражения, map/filter/reduce, генераторы, декораторы.
- Функциональный стиль помогает делать код более модульным, выразительным и тестируемым.
- Даже если весь проект не написан в функциональном стиле, отдельные его элементы могут эффективно использовать функциональные приёмы.

**Функциональное программирование** в Python — это современный, удобный и часто применяемый подход для обработки данных, написания компактных и чистых функций и построения гибких архитектур.
