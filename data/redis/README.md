# Redis

**Redis** (REmote DIctionary Server) — in-memory key-value хранилище. Используется как кэш, брокер сообщений, очередь задач, хранилище сессий и счётчиков.

Поддерживаемые структуры данных:
- String, List, Set, Sorted Set (ZSet)
- Hash, Bitmap, HyperLogLog
- Streams, Geospatial
- Pub/Sub

Особенности:
- Чрезвычайно высокая скорость (хранение в RAM)
- Опциональная персистентность (RDB snapshots, AOF)
- Репликация и Redis Cluster
- TTL для ключей (удобно для кэшей)
