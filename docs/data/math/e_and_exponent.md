# Число e, экспонента и натуральный логарифм

## Число e

```
e ≈ 2.71828182845904…
```

Это иррациональное число (бесконечная непериодическая дробь), такая же «фундаментальная константа», как `π`.

### Откуда оно взялось

Представь банк с 100% годовой ставкой. Положили `1₽`, через год получили `2₽`.

А что если начислять проценты не раз в год, а **n раз** (с реинвестом)?

```
после года = (1 + 1/n)^n
```

- 1 раз в год:   `(1 + 1/1)^1   = 2.00000`
- 2 раза:        `(1 + 1/2)^2   = 2.25`
- 12 раз (раз в месяц): `2.61304`
- 365 раз (раз в день): `2.71457`
- бесконечно часто:     `2.71828… = e`

То есть **`e` — это предельный множитель при непрерывном начислении процентов**:

```
e = lim (1 + 1/n)^n   при  n → ∞
```

## Экспонента e^x

Функция `f(x) = e^x` называется **экспонентой**.

```
e^0 = 1
e^1 ≈ 2.718
e^2 ≈ 7.389
e^(-1) ≈ 0.368
```

Это обычная степенная функция, но с основанием `e`. Часто пишут `exp(x)`.

```python
import math
math.exp(1)       # 2.71828…
math.exp(0)       # 1.0
math.exp(-1)      # 0.3679
math.e            # 2.71828…
```

### Почему именно e? Главное свойство

**Производная от `e^x` равна сама себе:**

```
(e^x)' = e^x
```

Это единственная функция с таким свойством. Из-за этого `e` выскакивает везде, где есть процессы роста/убывания, пропорциональные текущему значению:

- размножение бактерий (чем больше бактерий, тем быстрее они делятся)
- радиоактивный распад (чем больше атомов, тем больше распадается)
- зарядка/разрядка конденсатора
- модели в финансах (непрерывное начисление)

### График

- `e^x` стремительно растёт вправо: `e^10 ≈ 22000`, `e^20 ≈ 485 млн`.
- При `x → -∞` стремится к 0, но никогда не равен 0.
- Всегда положительна.

## Натуральный логарифм ln(x)

**Натуральный логарифм** — это логарифм по основанию `e`:

```
ln(x) = log_e(x)
```

Вопрос: «в какую степень возвести `e`, чтобы получить `x`?»

```
ln(1)   = 0           потому что e^0 = 1
ln(e)   = 1           потому что e^1 = e
ln(e^2) = 2
ln(10)  ≈ 2.302
```

Свойства — те же, что у любого логарифма:
```
ln(x · y) = ln(x) + ln(y)
ln(x / y) = ln(x) - ln(y)
ln(x^n)   = n · ln(x)
```

```python
import math
math.log(math.e)     # 1.0    — это ln(e)
math.log(10)         # 2.302  — это ln(10)
math.log(1)          # 0.0
```

Обрати внимание: в Python `math.log(x)` без второго аргумента — это **натуральный** логарифм, а не десятичный.

## Связь e^x и ln(x)

Это **обратные функции**:

```
ln(e^x) = x
e^(ln x) = x
```

То есть если применить экспоненту, а потом натуральный логарифм (или наоборот) — вернёмся к исходному числу.

## Где встречается в работе разработчика

**1. ML / нейросети**

Сигмоида:
```
σ(x) = 1 / (1 + e^(-x))
```
Выдаёт значения в `(0, 1)` — удобно для вероятностей.

Softmax (для классификации):
```
softmax(x_i) = e^(x_i) / Σ e^(x_j)
```

Cross-entropy loss использует `log` (часто натуральный).

**2. Распределение вероятностей**

Нормальное (Гауссово) распределение содержит `e^(-x²/2)`.

Распределение Пуассона, экспоненциальное распределение — везде `e`.

**3. Финансы**

Непрерывное начисление процентов: сумма за время `t` со ставкой `r`:
```
A = P · e^(r·t)
```

**4. Алгоритмы**

`ln(n)` встречается в анализе случайных алгоритмов и хеш-таблиц (например, ожидаемое число коллизий).
