# Степени и логарифмы

## Возведение в степень

Степень — это короткая запись умножения числа само на себя:
```
a^n = a · a · … · a   (n раз)
```

Пример:
```
2^3 = 2 · 2 · 2 = 8
5^2 = 25
10^4 = 10000
```

- `a` — **основание**
- `n` — **показатель степени**

### Свойства степеней

Очень важно помнить эти 5 правил:

```
a^m · a^n = a^(m+n)        →   2^3 · 2^4 = 2^7 = 128
a^m / a^n = a^(m-n)        →   2^5 / 2^2 = 2^3 = 8
(a^m)^n   = a^(m·n)        →   (2^3)^2 = 2^6 = 64
(a·b)^n   = a^n · b^n      →   (2·3)^2 = 4·9 = 36
(a/b)^n   = a^n / b^n
```

### Особые случаи

```
a^0 = 1   для любого a ≠ 0    (договорённость, удобная для формул)
a^1 = a
a^(-n) = 1 / a^n              →   2^(-3) = 1/8
```

### Дробные степени = корни

```
a^(1/n) = ⁿ√a       (корень n-й степени)
a^(m/n) = ⁿ√(a^m)
```

Примеры:
```
9^(1/2)  = √9 = 3
8^(1/3)  = ∛8 = 2
27^(2/3) = ∛(27²) = ∛729 = 9
```

В Python:
```python
2 ** 10        # 1024
9 ** 0.5       # 3.0
pow(8, 1/3)    # 2.0
```

## Логарифм

**Логарифм — это обратная операция к возведению в степень.**

Вопрос: «в какую степень нужно возвести `a`, чтобы получить `b`?»

```
log_a(b) = c    ⟺    a^c = b
```

Примеры:
```
log_2(8)   = 3        потому что 2^3 = 8
log_10(100) = 2       потому что 10^2 = 100
log_5(1)   = 0        потому что 5^0 = 1
log_2(1024) = 10      потому что 2^10 = 1024
```

«Логарифм по основанию `a` от числа `b`».

### Свойства логарифмов

Зеркальные правилам степеней — отсюда и польза:

```
log_a(x · y) = log_a(x) + log_a(y)        ← умножение → сложение
log_a(x / y) = log_a(x) - log_a(y)        ← деление → вычитание
log_a(x^n)   = n · log_a(x)               ← степень → коэффициент
log_a(1)     = 0
log_a(a)     = 1
```

Главная идея: **логарифмы превращают умножение в сложение**. Поэтому до появления калькуляторов их использовали для ручных расчётов.

### Замена основания

```
log_a(b) = log_c(b) / log_c(a)
```

Удобно, чтобы посчитать `log_2(x)` через `log_10` или `ln`:
```python
import math
math.log(8, 2)        # 3.0  — логарифм 8 по основанию 2
math.log10(1000)      # 3.0  — десятичный
math.log(math.e)      # 1.0  — натуральный (ln, основание e)
math.log2(1024)       # 10.0 — двоичный
```

## Где это нужно разработчику

**1. Оценка сложности алгоритмов (Big-O)**

`log₂(n)` — сколько раз можно поделить `n` пополам, пока не получится 1.

```
n = 1024   →   log₂(1024) = 10 шагов
n = 1_000_000  →  ~20 шагов
n = 1_000_000_000  →  ~30 шагов
```

Алгоритмы со сложностью `O(log n)`: бинарный поиск, операции в сбалансированном BST, в куче.
Алгоритмы `O(n log n)`: сортировки слиянием и пирамидальная, быстрая (в среднем).

**2. Биты и числа**

```
log₂(N) = сколько бит нужно для записи числа N
log₂(256) = 8 бит  →  можно хранить 256 значений
log₂(2^32) = 32 бита
```

**3. Шкалы**

Логарифмическая шкала: децибелы (звук), землетрясения (Рихтер), pH. Каждая «единица» = умножение в 10 раз.

**4. ML и статистика**

`log(p)` (log-likelihood) — стабильнее по числам, чем перемножение тысячи вероятностей < 1.
