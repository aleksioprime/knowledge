# Alembic

**Alembic** — инструмент для управления миграциями схемы базы данных в проектах с SQLAlchemy. Позволяет версионировать структуру БД и применять/откатывать изменения.

Основные операции:
- `alembic init` — инициализация
- `alembic revision --autogenerate -m "msg"` — генерация миграции
- `alembic upgrade head` — применить все миграции
- `alembic downgrade -1` — откатить последнюю
- `alembic history` — история миграций
