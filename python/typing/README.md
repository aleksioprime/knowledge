# Типизация и модели данных

Как описывать данные в Python так, чтобы ошибки находились до запуска, а данные из внешнего мира проверялись автоматически.

## Содержание

- [Подсказки типов (type hints)](type_hints.md) — синтаксис, `mypy`, `Literal`, `TypedDict`, `Protocol`, generics
- [dataclasses](dataclasses.md) — классы данных без однообразного кода
- [Pydantic](pydantic.md) — проверка и преобразование данных, настройки приложения

С чего начать: если данные создаёт сам код — `dataclasses`, если приходят снаружи (JSON, формы, переменные окружения) — Pydantic.
