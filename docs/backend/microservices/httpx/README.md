# HTTPX

**HTTPX** — HTTP-клиент для Python. API похож на `requests`, но есть асинхронный режим (`AsyncClient`), поддержка HTTP/2, понятные таймауты и пул соединений. Удобен для запросов между микросервисами.

Как устроены HTTP-запросы и ответы, описано в общем разделе [HTTP](../../web/http/README.md).

## Содержание

- [Основы](basics.md) — запросы, ошибки и таймауты, клиент и пул соединений, параллельные запросы, повторы
- [Пример: simple](examples/simple/README.md) — учебный сервер и скрипты ко всем разделам заметки
- [Пример: fastapi](examples/fastapi/README.md) — сервис постов проверяет категорию в сервисе категорий
