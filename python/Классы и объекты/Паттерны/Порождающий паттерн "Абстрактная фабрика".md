**Абстрактная фабрика** — это паттерн, который позволяет создавать целое семейство связанных объектов, не привязываясь к их конкретным классам.

- Ты не создаёшь объекты напрямую через конструкторы.
- Вместо этого используешь фабрику (класс или функцию), которая "умеет" создавать объекты нужного типа.
- Таким образом, можно легко “переключать” семейства объектов, не меняя основной код

### Пример с GUI (интерфейсами)

Допустим, ты пишешь приложение, которое может работать и под Windows, и под Mac, и под Linux.  
Везде нужны кнопки и окна, но выглядеть они должны “родными” для каждой системы.

- **WindowsWidgetFactory** создаёт Windows-кнопки и Windows-окна.
- **MacWidgetFactory** — Mac-кнопки и Mac-окна.
- **LinuxWidgetFactory** — Linux-кнопки и Linux-окна.

Весь остальной код не знает, как именно создаётся кнопка — он просто вызывает методы фабрики.

```python
class Button:
    def paint(self):
        pass

class WinButton(Button):
    def paint(self):
        print("Windows-style Button")

class MacButton(Button):
    def paint(self):
        print("Mac-style Button")

class GUIFactory:
    def create_button(self):
        pass

class WinFactory(GUIFactory):
    def create_button(self):
        return WinButton()

class MacFactory(GUIFactory):
    def create_button(self):
        return MacButton()

# Клиентский код:
def build_ui(factory):
    btn = factory.create_button()
    btn.paint()

# Используем Windows стиль:
build_ui(WinFactory())  # Windows-style Button
# Используем Mac стиль:
build_ui(MacFactory())  # Mac-style Button
```

### Пример с PetShop

У нас есть магазин животных (**PetShop**), который может "продавать" разные семейства питомцев: например, только котов, только собак, или случайных животных.  Мы **не создаём** животных напрямую внутри магазина.  Вместо этого **PetShop** принимает в конструктор “фабрику животных” — функцию или класс, которая создаёт нужного питомца.

```python
class PetShop:
    """Магазин животных"""
    def __init__(self, animal_factory):
        # animal_factory — это функция/класс, который будет создавать животных
        self.animal_factory = animal_factory

    def show_pet(self):
        """Показать питомца"""
        pet = self.animal_factory()  # Создаём питомца через фабрику
        print(f"У нас есть прекрасный {pet}")
        print(f"Он говорит: {pet.speak()}\n")

class Dog:
    def speak(self):
        return "Гав!"

    def __str__(self):
        return "Собака"

class Cat:
    def speak(self):
        return "Мяу!"

    def __str__(self):
        return "Кот"

# Фабрика, которая возвращает случайное животное
import random
def random_animal():
    return random.choice([Dog, Cat])()

# Примеры использования:

# 1. Магазин только с котами
cat_shop = PetShop(Cat)
cat_shop.show_pet()
# У нас есть прекрасный Кот
# Он говорит: Мяу!

# 2. Магазин только с собаками
dog_shop = PetShop(Dog)
dog_shop.show_pet()
# У нас есть прекрасный Собака
# Он говорит: Гав!

# 3. Магазин с рандомными животными
shop = PetShop(random_animal)
for _ in range(3):
    shop.show_pet()
# Каждый раз может быть либо кот, либо собака
```

Использование:

- **Абстрактная фабрика** — это “конструктор комплектов”: ты выбираешь стиль (или семейство), и получаешь набор согласованных между собой объектов.
- Очень удобно, если нужно поддерживать несколько платформ, стилей или вариантов продукта.
- Главная фишка: можно быстро "переключиться" между семействами объектов без изменения остального кода.
