[[Определение декоратора]] который позволяет превратить метод в свойство, чтобы предоставить управляемым атрибутам возможность и для чтения, и для записи.

```python
class Square: 
	def __init__(self, side): 
		self.side = side 
		
	@property 
	def side(self): 
		return self._side # Возвращает внутреннее значение _side
		
	@side.setter 
	def side(self, value): 
		self._side = float(value) # Преобразует сторону в число с плавающей точкой
		
	@property 
	def area(self): 
		return self.side ** 2 # Вычисляет площадь "на лету"
		
	@area.setter 
	def area(self, value): 
		self.side = value ** 0.5 # Пересчитывает сторону из площади
```

`@property` делает метод **доступным как атрибут** (без `()`), но при этом позволяет добавлять логику обработки данных.

1️. **Контроль за атрибутами** – можно валидировать или конвертировать данные (как `float(value)`).  
2️. **Вычисляемые свойства** – `area` не хранится, а вычисляется "на лету".  
3️. **Автоматическая синхронизация** – изменение `side` автоматически изменяет `area`, и наоборот.
