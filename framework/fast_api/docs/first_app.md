# Первое приложение на FastAPI

Нужно отдать список задач по HTTP: чтобы фронтенд или мобильное приложение могли его получить. FastAPI позволяет описать такой API обычными функциями Python. Адрес задаётся декоратором, а параметры — аргументами функции с подсказками типов. Проверку входных данных, превращение ответа в JSON и документацию FastAPI делает сам.

```bash
pip install fastapi uvicorn
```

## Минимальный пример

```python
# main.py
from fastapi import FastAPI

app = FastAPI(title='Задачник')

tasks = [
    {'id': 1, 'title': 'Купить хлеб', 'done': False},
    {'id': 2, 'title': 'Сдать отчёт', 'done': True},
]


@app.get('/tasks')
def list_tasks(done: bool | None = None):
    if done is None:
        return tasks
    return [task for task in tasks if task['done'] == done]


@app.get('/tasks/{task_id}')
def get_task(task_id: int):
    for task in tasks:
        if task['id'] == task_id:
            return task
```

```bash
uvicorn main:app --reload
```

```bash
curl localhost:8000/tasks?done=true
# [{"id":2,"title":"Сдать отчёт","done":true}]

curl localhost:8000/tasks/2
# {"id":2,"title":"Сдать отчёт","done":true}
```

На http://localhost:8000/docs уже есть интерактивная документация: там видны оба эндпоинта, их параметры, и любой запрос можно отправить кнопкой «Try it out».

## Как это работает

**Декоратор задаёт метод и путь.** `@app.get('/tasks')` — функция отвечает на `GET /tasks`. Есть также `@app.post`, `@app.put`, `@app.patch` и `@app.delete`.

**Аргументы функции — это параметры запроса.** FastAPI смотрит на имя и тип аргумента:

- имя есть в пути (`{task_id}`) — это **параметр пути**;
- простой тип (`int`, `str`, `bool`), которого нет в пути, — **параметр строки запроса** (`?done=true`);
- модель Pydantic — **тело запроса** (об этом в заметке про [схемы](schemas.md)).

**Тип — это ещё и проверка.** `task_id: int` значит, что FastAPI сам превратит строку из URL в число, а если не получится — вернёт ошибку 422 с объяснением:

```bash
curl localhost:8000/tasks/abc
```

```json
{"detail": [{"type": "int_parsing", "loc": ["path", "task_id"], "msg": "Input should be a valid integer, unable to parse string as an integer", "input": "abc"}]}
```

`loc` показывает, где ошибка: в пути, в параметре `task_id`. С `?done=maybe` будет такая же ошибка 422, только про `bool`.

**Ответ превращается в JSON сам.** Словари, списки, модели Pydantic, даты — всё сериализуется автоматически.

**uvicorn — это сервер.** FastAPI описывает приложение, а принимает соединения и передаёт ему запросы ASGI-сервер uvicorn. `main:app` значит «объект `app` из модуля `main`». Флаг `--reload` перезапускает сервер при изменении кода; он нужен только для разработки.

## `def` или `async def`

Оба варианта работают, но по-разному:

- `async def` выполняется в основном цикле событий. Внутри можно и нужно ждать асинхронные операции (`await session.execute(...)`, `await client.get(...)`). Но **блокирующий** вызов (`time.sleep`, `requests.get`, синхронный драйвер БД) остановит весь сервер: пока одна функция ждёт, остальные запросы стоят.
- `def` FastAPI запускает в отдельном потоке из пула. Блокирующий код здесь безопасен, но потоков ограниченное число.

Правило: используете асинхронные библиотеки — пишите `async def`; работаете с обычными синхронными — `def`. Подробнее о том, как устроен цикл событий, — в заметке про [asyncio](../../../python/multitask/async.md).

## Частые ошибки

- **Вернуть `None`, когда объекта нет.** В примере выше `GET /tasks/5` ответит `200` с телом `null`: клиент решит, что всё хорошо. Если объекта нет, нужно вернуть 404 — как это сделать, разобрано в заметке про [ошибки](errors.md).
- **Одинаковые пути с разными параметрами.** `/tasks/{task_id}` объявлен раньше `/tasks/today` — тогда `today` попадёт в `task_id` и вызовет ошибку 422. Конкретные пути объявляйте раньше путей с параметрами.
- **`--reload` в продакшене.** Он следит за файлами и тратит ресурсы. В продакшене запускайте без него, а несколько процессов задавайте через `--workers`.

## Когда не использовать

Если нужен сайт с шаблонами, админкой и формами «из коробки», удобнее Django. FastAPI лучше всего подходит для API, которые читают фронтенд, мобильные приложения и другие сервисы.
