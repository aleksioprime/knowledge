- **Параметр пути:** Это как название блюда в меню. Оно является _обязательной частью_ URL-адреса и указывает, _что именно_ вы хотите получить или изменить. Например, `/menu/pizza` - “pizza” это параметр пути, который говорит, что вы хотите увидеть информацию о пицце. Это как сказать официанту: “Я хочу пиццу!”
- **Параметр запроса:** Это как добавки или особые инструкции к вашему заказу, которые вы указываете после названия блюда. Они _необязательны_ и изменяют способ получения или обработки информации. Например, `/menu/pizza?size=large&extra_cheese=true` - `size=large` и `extra_cheese=true` это параметры запроса. Это как сказать: “Я хочу пиццу, _большую_ и с _дополнительным сыром_!”. В URL они идут после знака вопроса `?` и разделяются амперсандом `&`.
- **Тело запроса:** Это как заполнение формы заказа, где вы указываете _подробную информацию_, которую нельзя передать в URL. Обычно используется при создании или изменении данных. Например, если вы заказываете пиццу онлайн и заполняете форму, указывая адрес доставки, номер телефона и другие детали, это все передается в теле запроса. Это как сказать: “Я хочу пиццу и вот _все детали_, необходимые для ее приготовления и доставки!”. Обычно это JSON или XML.
## Параметры пути

FastAPI позволяет получать данные запроса из URL-адреса конечной точки API через параметр пути или переменную пути, что делает URL-адрес несколько динамичным. Этот параметр содержит значение, которое становится частью URL-адреса, обозначенного фигурными скобками (`{}`). После установки этих параметров пути в URL-адресе FastAPI требует, чтобы эти параметры были объявлены с применением подсказок типов.

```python
@app.get("/hello/{user}")
async def welcome_user(user: str) -> dict:
	return {"user": f'Hello {user}'}
```

![[path.png]]

Также по аналогии мы можем передавать несколько параметров в URL-адресе

```python
@app.get("/hello/{first_name}/{last_name}")
async def welcome_user(first_name: str, last_name: str) -> dict:
	return {"user": f'Hello {first_name} {last_name}'}
```

FastAPI обеспечивает проверку типов, используя аннотации типов.

```python
@app.get("/order/{order_id}")
async def order(order_id: int) -> dict: 
	return {"id": order_id}
```

Все фиксированные пути должны быть объявлены первыми перед URL-адресами динамических конечных точек с параметрами пути:

```python
@app.get("/user/profile")
async def profile() -> dict:
	return {"profile": "View profile user"}

@app.get("/user/{user_name}")
async def user(user_name: str) -> dict:
	return {"user": user_name}
```

## Параметры запроса

Параметр запроса — это пара ключ-значение, предоставляемая после окончания URL- адреса конечной точки, обозначенного вопросительным знаком (`?`). Как и параметр пути, он также содержит данные запроса. Служба API может управлять рядом параметров запроса, разделенных амперсандом (`&`). Как и в параметрах пути, все параметры запроса также объявляются в методе службы.

```python
@app.get("/user")
async def login(username: str, age: int) -> dict:
	return {"user": username, "age": age}
```

![[query.png]]

Иногда  необходимо указать значения по умолчанию для параметров запроса и параметров пути некоторых служб API, чтобы избежать сообщений об ошибках. Установка значений по умолчанию для параметров позволит выполнить метод API с указанием значений параметров или без них. В зависимости от требований, назначенные значения по умолчанию обычно равны `0` для числовых типов, `False` для типов `bool`, пустой строке для строковых типов, пустому списку (`[]`) для типов `List` и пустому словарю (`{}`) для типов `Dict`.

```python
@app.get("/user")
async def login(username: str, age: int = 30) -> dict:
	return {"user": username, "age": age}
```

Таким же образом, если мы укажем значение поля как `None`, то мы сможем объявить `age` как необязательный параметр

```python
@app.get("/user")
async def login(username: str, age: int | None = None) -> dict:
	return {"user": username, "age": age}
```
