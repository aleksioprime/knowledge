# Производные

## Идея простыми словами

**Производная — это скорость изменения функции в точке.**

Представь, что едешь на машине. Функция `s(t)` — пройденный путь в зависимости от времени. Тогда производная `s'(t)` — это **скорость** в момент `t`.

Производная отвечает на вопрос: «**если я чуть-чуть сдвину `x`, насколько изменится `f(x)`?**»

```
f'(x) = lim  ( f(x + Δx) - f(x) ) / Δx       при Δx → 0
```

Геометрически: производная в точке = **тангенс угла наклона касательной** к графику в этой точке.

- Производная положительна → функция растёт.
- Производная отрицательна → функция убывает.
- Производная = 0 → точка экстремума (минимум или максимум).

## Обозначения

Эти записи означают одно и то же:
```
f'(x)     df/dx     d/dx f(x)     Df(x)
```

## Производные основных функций

Запомнить (или иметь под рукой):

```
(C)'       = 0              ← константа
(x)'       = 1
(x^n)'     = n · x^(n-1)    ← главное правило для степеней
(√x)'      = 1 / (2√x)
(1/x)'     = -1/x²
(e^x)'     = e^x            ← e^x особенное: производная сама от себя
(a^x)'     = a^x · ln(a)
(ln x)'    = 1/x
(log_a x)' = 1 / (x · ln a)
(sin x)'   = cos x
(cos x)'   = -sin x
```

## Правила дифференцирования

### 1. Константа выносится

```
(C · f(x))' = C · f'(x)
```
Пример: `(5x³)' = 5 · 3x² = 15x²`.

### 2. Сумма / разность

```
(f + g)' = f' + g'
(f - g)' = f' - g'
```
Пример: `(x² + 3x)' = 2x + 3`.

### 3. Произведение

```
(f · g)' = f' · g + f · g'
```
Пример: `(x · sin x)' = 1 · sin x + x · cos x`.

### 4. Частное

```
(f / g)' = (f' · g - f · g') / g²
```

### 5. Цепное правило (сложная функция)

Это самое важное правило для практики.

```
(f(g(x)))' = f'(g(x)) · g'(x)
```

Идея: производишь «внешнюю», подставляя «внутреннюю», и умножаешь на производную «внутренней».

Примеры:
```
(e^(2x))'    = e^(2x) · 2 = 2e^(2x)
((x² + 1)³)' = 3(x² + 1)² · 2x = 6x(x² + 1)²
(sin(x²))'   = cos(x²) · 2x
```

## Примеры на разогрев

```
f(x) = x² + 3x + 7
f'(x) = 2x + 3

f(x) = 5x⁴ - 2x + 1
f'(x) = 20x³ - 2

f(x) = e^x · x
f'(x) = e^x · x + e^x · 1 = e^x (x + 1)

f(x) = ln(x² + 1)
f'(x) = 1/(x² + 1) · 2x = 2x/(x² + 1)
```

## Поиск экстремумов

Чтобы найти минимум или максимум функции:
1. Найти `f'(x) = 0` → это «подозрительные» точки.
2. Посмотреть, как меняется знак производной вокруг них:
   - `f'` меняется с «+» на «−» → **максимум**.
   - `f'` меняется с «−» на «+» → **минимум**.

Пример. `f(x) = x² - 4x + 5`.
```
f'(x) = 2x - 4 = 0   →   x = 2
```
Слева от 2 производная отрицательна (функция падает), справа — положительна (растёт). Значит, `x = 2` — минимум. `f(2) = 1`.

## Где это используется в IT

**1. Машинное обучение — градиентный спуск**

Обучение нейросетей сводится к минимизации функции потерь (loss). Делается это так:
- считаем градиент (вектор частных производных) loss-функции;
- сдвигаем веса в сторону, **противоположную** градиенту (туда, где loss быстрее всего падает);
- повторяем.

```
w_new = w_old - lr · ∂loss/∂w
```

`backpropagation` в нейросети — это применение цепного правила миллион раз.

**2. Оптимизация**

Поиск минимума / максимума — везде, от логистики до автонастройки гиперпараметров.

**3. Численное дифференцирование**

Если функция сложная, считаем приближённо:
```python
def numerical_derivative(f, x, h=1e-6):
    return (f(x + h) - f(x - h)) / (2 * h)

import math
numerical_derivative(math.sin, 0)  # ≈ 1.0  (производная sin в 0 = cos(0) = 1)
```
