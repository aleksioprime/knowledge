# SQLAlchemy

**SQLAlchemy** — самый популярный Python-инструмент для работы с реляционными базами данных. Состоит из двух уровней:
- **Core** — низкоуровневое SQL-выражение через Python-объекты
- **ORM** — высокоуровневое отображение классов на таблицы

Возможности:
- Декларативное описание моделей
- Сессии и unit-of-work
- Поддержка sync и async (`asyncpg`, `aiomysql`)
- Гибкие связи (один-к-одному, один-ко-многим, многие-ко-многим)
- Кастомные типы данных и события
