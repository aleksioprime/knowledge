[[Различия между итератором и генератором]]
## Генераторы

**Генератор** в Python – это специальный тип функций, который позволяет вам возвращать значение и позже продолжить выполнение функции с того места, где она была остановлена. Это достигается с помощью ключевого слова `yield`.

Главное отличие генератора от обычной функции заключается в том, что генератор возвращает **итерируемый объект**, через который можно пройти только один раз. Это позволяет эффективно работать с данными, не загружая полностью их в память. Генераторы особенно полезны, когда нужно работать с большими объемами данных или когда заранее неизвестно количество элементов.

### Пример генератора

```python
def count_up_to(max):
    count = 1
    while count <= max:
        yield count
        count += 1

counter = count_up_to(5)
for num in counter:
    print(num)
```

> Функция `count_up_to` является генератором. Когда вы вызываете её, она не выполняет свой код сразу. Вместо этого, она возвращает итерируемый объект. Когда вы итерируетесь через этот объект (например, используя цикл for), код внутри функции выполняется до первого `yield`. Значение, которое следует за `yield`, возвращается в цикл. При следующей итерации выполнение функции возобновляется сразу после `yield` и продолжается до следующего `yield`.

Использование генераторов позволяет сэкономить ресурсы, так как значения генерируются по мере необходимости, а не хранятся в памяти.

---

### Как работают генераторы

Генераторные функции создаются с помощью ключевого слова `yield`. Каждый раз, когда вызывается `yield`, выполнение функции приостанавливается и возвращается значение. Вызов следующей итерации возобновляет выполнение функции с того же места.

#### Пример: бесконечный генератор

```python
def infinite_sequence():
    num = 0
    while True:
        yield num
        num += 1

gen = infinite_sequence()
for i in range(5):
    print(next(gen))  # 0, 1, 2, 3, 4
```

---
### Генераторные выражения

Помимо генераторных функций, в Python существуют **генераторные выражения** — сокращённая форма создания генераторов, похожая на list comprehension, но в круглых скобках:

```python
squares = (x**2 for x in range(5))
for sq in squares:
    print(sq)  # 0, 1, 4, 9, 16
```

---
### Основные преимущества генераторов

- **Экономия памяти:** значения вычисляются по мере необходимости, а не хранятся в списке целиком.
- **Ленивая (отложенная) вычисление:** удобно для обработки больших файлов или потоков данных.
- **Простота синтаксиса:** генераторы легко писать и читать, часто это короче, чем создавать собственный итератор.
