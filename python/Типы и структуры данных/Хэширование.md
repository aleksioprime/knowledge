Результат выполнения хеширования. По сути, это случайный набор символов.

**Свойства хэша**

У хэш-функции есть несколько обязательных свойств:

- Хэш всегда уникален для каждого массива информации. Однако иногда случаются так называемые коллизии, когда для разных входных блоков информации вычисляются одинаковые хэш-коды.
- При самом незначительном изменении входной информации ее хэш полностью меняется.
- Хэш-функция необратима и не позволяет восстанавливать исходный массив информации из символьной строки. Это можно сделать, только перебрав все возможные варианты, что при бесконечном количестве информации требует много времени и денег.
- Хэширование позволяет достаточно быстро вычислить нужный хэш для достаточно большого объема информации.
- Алгоритм работы хэш-функции, как правило, делается открытым, чтобы при необходимости можно было оценить ее стойкость к восстановлению начальных данных по выдаваемому хэшу.
- Хэш-функция должна уметь приводить любой объем данных к числу заданной длины.

## Коллизия хэша

**Коллизия хэша** — это ситуация, когда **разные объекты имеют одинаковое хэш-значение**

Python использует **функцию `hash()`** для вычисления **хэш-значений** объектов.

```python
print(hash("hello")) # Например, 1234567890 
print(hash(42)) # Например, 42
```

Если **два разных объекта** возвращают **один и тот же хэш**, это **коллизия**.

```python
print(hash(1))    # 1
print(hash(1.0))  # 1  (коллизия!)
print(hash(True)) # 1  (коллизия!)
```

Для решения коллизий Python использует **метод цепочек (chaining)**:

- Если два ключа **имеют одинаковый хэш**, Python **сохраняет их в виде списка** в одной ячейке.

```python
d = {1: "int", 1.0: "float", True: "bool"}
print(d)  # {1: 'bool'}
```

Почему остался только `'bool'`?
- Python **считает `1`, `1.0` и `True` одинаковыми ключами**, потому что их хэши **совпадают**

Избежание коллизий:
- Использовать **уникальные ключи** в словарях.
- Для хэш-функций использовать **криптографические хэши (SHA256, MD5, SHA3)**:

```python
import hashlib![[rebus.zip]]

print(hashlib.sha256(b"hello").hexdigest())  # Надёжный хэш
```

В **криптографии** хэш-функции проектируют так, чтобы **коллизии были редкими**.

Python использует **метод открытой адресации (Open Addressing)**.

1. Python вычисляет `hash(key)`, чтобы найти индекс в таблице
2. Если место **свободно**, ключ заносится в таблицу.  
3. Если **уже есть другой ключ (коллизия)**, Python ищет **следующую свободную ячейку** (линейное пробирование).  
4. Если много коллизий, Python **расширяет таблицу**.
