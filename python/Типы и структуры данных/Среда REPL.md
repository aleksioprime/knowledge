**REPL** (Read–Eval–Print Loop) — это интерактивная среда выполнения кода, которая работает по циклу:

1. **Read** — читает введённую пользователем строку кода.
2. **Eval** — выполняет (вычисляет) этот код.
3. **Print** — выводит результат вычисления.
4. **Loop** — возвращается к первому шагу, ожидая следующего ввода.
## Где используется REPL?

- **Интерактивная оболочка Python:**  
  Когда вы запускаете в терминале команду

```
python
```

и видите приглашение `>>>` — это и есть REPL.

- **Другие языки программирования:**  
  Почти все современные языки имеют REPL: Node.js (`node`), Ruby (`irb`), Scala (`scala`), Julia и др.

- **IPython, Jupyter Notebook:**  
  Это расширенные REPL-оболочки для Python с дополнительными возможностями.

## Преимущества REPL

- Позволяет быстро проверять фрагменты кода и гипотезы
- Удобен для изучения языка, экспериментов, отладки и демонстраций
- Не требует создавать файл — всё происходит в режиме реального времени
## Пример работы REPL Python

```
$ python
Python 3.12.1 (default, ...)
>>> 2 + 2
4
>>> for i in range(3):
...     print(i)
...
0
1
2
```
