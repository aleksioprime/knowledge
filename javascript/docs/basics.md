# Основы синтаксиса

Эта глава знакомит с конструкциями, из которых собирается обычная программа: переменными, условиями, циклами и операторами. Примеры лучше запускать по одному и заранее пытаться определить результат — так правила запоминаются быстрее.

## Переменные

Переменная связывает имя со значением. В современном коде значение по умолчанию объявляют через `const`, а `let` используют только тогда, когда переменную действительно будут переназначать.

```js
const name = 'Alex' // нельзя переназначить переменную
let count = 0       // значение можно переназначать

count += 1 // изменяем текущее значение
```

По умолчанию используйте `const`, а `let` — когда требуется переназначение. `const` не делает объект неизменяемым:

```js
const user = { name: 'Alex' } // создаём объект и сохраняем ссылку в переменной
user.name = 'Anna' // допустимо
// user = {}       // TypeError
```

`var` имеет область видимости функции, допускает повторное объявление и поднимается иначе, чем `let` и `const`. В современном коде он обычно не нужен.

| Объявление | Область видимости | Повторное объявление | Переназначение |
|---|---|---|---|
| `var` | функция | да | да |
| `let` | блок | нет | да |
| `const` | блок | нет | нет |

## Строгий режим

Директива `'use strict'` включает дополнительные проверки: например, запрещает присваивание необъявленной переменной, а `this` при обычном вызове функции не заменяет на глобальный объект.

```js
'use strict' // включаем строгий режим для этого скрипта

unknownValue = 42 // записываем 42 в переменную unknownValue; результат: ReferenceError
```

ES-модули и код внутри `class` уже выполняются в строгом режиме, поэтому добавлять директиву туда не требуется.

## Условия

Условная конструкция выбирает ветку кода по логическому результату выражения. В круглых скобках значение приводится к boolean, поэтому там может находиться не только явное сравнение.

```js
if (score >= 90) { // проверяем условие и выполняем блок, если оно истинно
  console.log('Отлично') // выводим значение в консоль
} else if (score >= 60) { // если первая проверка не прошла, проверяем следующее условие
  console.log('Зачёт') // выводим значение в консоль
} else { // выполняем ветку, когда предыдущие условия ложны
  console.log('Нужно повторить') // выводим значение в консоль
}

const label = active ? 'Активен' : 'Отключён' // выбираем подпись тернарным оператором
```

Для сравнения обычно используют строгие операторы `===` и `!==`, которые не выполняют неявное приведение типов.

## Циклы

### Обычный `for`

Подходит, когда нужен индекс или известно количество повторений:

```js
for (let index = 0; index < users.length; index += 1) { // перебираем значения в цикле
  console.log(index, users[index]) // выводим значение в консоль
}
```

### `while` и `do...while`

`while` проверяет условие до итерации, поэтому может не выполниться ни разу. `do...while` сначала выполняет тело, а затем проверяет условие.

```js
while (queue.length > 0) { // повторяем блок, пока условие истинно
  process(queue.shift()) // удаляем и получаем первый элемент массива
}

do { // выполняем тело цикла хотя бы один раз
  answer = prompt('Введите yes') // записываем prompt('Введите yes') в переменную answer
} while (answer !== 'yes') // повторяем цикл, пока условие истинно
```

### `for...of`

Перебирает значения iterable-объекта: массива, строки, `Map`, `Set` или другого объекта с `Symbol.iterator`.

```js
for (const user of users) { // перебираем значения в цикле
  console.log(user.name) // выводим значение в консоль
}

for (const letter of 'JavaScript') { // перебираем значения в цикле
  console.log(letter) // выводим значение в консоль
}
```

Если одновременно нужен индекс массива, используйте `entries()`:

```js
for (const [index, user] of users.entries()) { // перебираем значения в цикле
  console.log(index, user.name) // выводим значение в консоль
}
```

### `for...in`

Перебирает строковые перечисляемые ключи объекта, включая унаследованные. Он возвращает ключи, а не значения:

```js
const user = { // создаём объект и сохраняем ссылку в переменной
  name: 'Alex', // задаём свойство name
  role: 'admin', // задаём свойство role
}

for (const key in user) { // перебираем значения в цикле
  console.log(key, user[key]) // выводим значение в консоль
}
```

Для массива `for...in` обычно не используют: он возвращает индексы как строки и может захватить дополнительные свойства.

```js
const colors = ['red', 'green'] // создаём массив с начальными элементами

for (const key in colors) { // перебираем значения в цикле
  console.log(key) // '0', затем '1'
}

for (const color of colors) { // перебираем значения в цикле
  console.log(color) // 'red', затем 'green'
}
```

Для безопасного перебора только собственных свойств обычного объекта удобнее `Object.keys()`, `Object.values()` или `Object.entries()`:

```js
for (const [key, value] of Object.entries(user)) { // получаем массив пар ключ–значение
  console.log(key, value) // выводим значение в консоль
}
```

Коротко:

| Цикл | Что перебирает | Обычно используется для |
|---|---|---|
| `for...of` | значения iterable-объекта | массивы, строки, Map, Set |
| `for...in` | перечисляемые ключи | свойства обычного объекта |

### `break` и `continue`

`break` полностью завершает цикл, а `continue` пропускает оставшуюся часть текущей итерации:

```js
for (const number of numbers) { // перебираем значения в цикле
  if (number < 0) continue // проверяем условие и выполняем блок, если оно истинно
  if (number === 0) break // проверяем условие и выполняем блок, если оно истинно

  console.log(number) // выводим значение в консоль
}
```

Для преобразования массивов часто выразительнее `map`, `filter`, `find`, `some` и `every`. `forEach` не умеет прерываться через `break` и не ожидает асинхронный callback, поэтому для последовательного `await` используйте `for...of`.

## Побитовые операторы

Побитовые операторы работают с отдельными битами числа:

| Оператор | Значение |
|---|---|
| `a & b` | AND: бит равен `1`, если он равен `1` в обоих числах |
| `a \| b` | OR: бит равен `1`, если он равен `1` хотя бы в одном числе |
| `a ^ b` | XOR: бит равен `1`, если биты различаются |
| `~a` | инвертирует биты |
| `a << n` | сдвигает биты влево |
| `a >> n` | сдвигает вправо с сохранением знака |
| `a >>> n` | сдвигает вправо с заполнением нулями |

```js
5 & 3 // выполняем побитовую операцию; результат: 1: 0101 & 0011 = 0001
5 | 3 // выполняем побитовую операцию; результат: 7: 0101 | 0011 = 0111
5 ^ 3 // выполняем побитовую операцию; результат: 6: 0101 ^ 0011 = 0110
5 << 1 // выполняем побитовую операцию; результат: 10
```

Для типа `number` операнды побитовых операций преобразуются в 32-битные целые числа. Поэтому такие операции не подходят для произвольно больших чисел и могут обрезать дробную или старшую часть значения.

### Побитовое сложение

Два целых числа можно сложить без оператора `+`: XOR складывает биты без переноса, а AND со сдвигом вычисляет перенос.

```js
function add(a, b) { // объявляем функцию add()
  while (b !== 0) { // повторяем блок, пока условие истинно
    const carry = (a & b) << 1 // вычисляем перенос для побитового сложения
    a ^= b // выполняем побитовую операцию
    b = carry // записываем carry в переменную b
  }

  return a // возвращаем вызывающему коду значение выражения a
}

add(5, 3) // вызываем add(); результат: 8
```

Этот пример ограничен диапазоном 32-битных знаковых целых чисел. В обычном прикладном коде следует использовать `+`; побитовое сложение чаще встречается как задача на собеседовании.

Проверка чётности без `%`:

```js
const isEven = (number) => (number & 1) === 0 // создаём функцию и сохраняем её в переменной
```

## `switch`

`switch` последовательно сравнивает выражение со значениями `case` без неявного преобразования типов — по правилам строгого равенства, как `===`.

```js
const value = '1' // сохраняем строку в переменной

switch (value) { // сравниваем значение с вариантами case
  case 1: // обрабатываем совпавший вариант
    console.log('Число') // не выполнится
    break // завершаем текущую ветку или цикл
  case '1': // обрабатываем совпавший вариант
    console.log('Строка') // выполнится
    break // завершаем текущую ветку или цикл
}
```

Поэтому строка `'1'` и число `1` относятся к разным веткам. Объекты совпадут только при одинаковой ссылке, а `NaN` не совпадёт даже с `case NaN`.

```js
switch (status) { // сравниваем значение с вариантами case
  case 'pending': // обрабатываем совпавший вариант
    startPolling() // вызываем startPolling()
    break // завершаем текущую ветку или цикл
  case 'done': // обрабатываем совпавший вариант
    showResult() // вызываем showResult()
    break // завершаем текущую ветку или цикл
  default: // обрабатываем случай без совпавшего case
    showUnknownStatus() // вызываем showUnknownStatus()
}
```

Без `break`, `return` или `throw` выполнение продолжится в следующей ветке.
