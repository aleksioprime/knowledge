# Строки и f-строки

Почти любая программа собирает текст: сообщение пользователю, строку отчёта, имя файла, запись в лог. В Python для этого есть f-строки, которые умеют не только подставлять значения, но и выравнивать, округлять и форматировать даты, а также набор методов, покрывающий большинство задач с текстом без регулярных выражений.

## Минимальный пример

Список задач в виде ровной таблицы:

```python
tasks = [
    ('Купить хлеб', 120.5, True),
    ('Сдать отчёт', 0, False),
    ('Записаться к врачу', 1500, False),
]

for title, price, done in tasks:
    mark = '✓' if done else ' '
    print(f'[{mark}] {title:<20} {price:>8.2f} ₽')
```

```text
[✓] Купить хлеб            120.50 ₽
[ ] Сдать отчёт              0.00 ₽
[ ] Записаться к врачу    1500.00 ₽
```

## Как работают f-строки

Внутри `{}` можно написать любое выражение, а после двоеточия — формат:

```text
{значение:выравнивание ширина .точность тип}
```

- `<`, `>`, `^` — по левому краю, по правому, по центру;
- число — ширина поля;
- `.2f` — два знака после запятой;
- `,` — разделитель тысяч, `%` — проценты.

```python
f'{1234567.891:,.2f}'              # '1,234,567.89'
f'{0.256:.1%}'                     # '25.6%'
f'{42:05d}'                        # '00042' — дополнить нулями до 5 знаков
f'{255:x}'                         # 'ff' — шестнадцатеричная запись
f'{date(2026, 11, 1):%d.%m.%Y}'    # '01.11.2026'
```

Для отладки удобен знак `=` — он выводит и выражение, и значение:

```python
name, count = 'Анна', 3
print(f'{name=}, {count=}')  # name='Анна', count=3
```

В старом коде встретятся `'{} из {}'.format(2, 5)` и `'%s из %d' % ('2', 5)`. Результат тот же, но f-строки короче и читаются слева направо. Исключение — [логирование](logging.md): там принят `%`-стиль.

## Частые методы

```python
title = '  Купить Хлеб  '

title.strip()           # 'Купить Хлеб' — убрать пробелы по краям
title.strip().lower()   # 'купить хлеб'
'купить хлеб'.capitalize()  # 'Купить хлеб'
'купить хлеб'.title()       # 'Купить Хлеб'

'дом,покупки,,срочно'.split(',')  # ['дом', 'покупки', '', 'срочно']
'a  b   c'.split()                # ['a', 'b', 'c'] — без аргумента делит по любым пробелам
', '.join(['дом', 'покупки'])     # 'дом, покупки'

'Купить хлеб'.replace('хлеб', 'молоко')     # 'Купить молоко'
'хлеб' in 'Купить хлеб'                     # True
'Купить хлеб'.find('сыр')                   # -1 — не найдено
'report.pdf'.endswith(('.pdf', '.docx'))    # True — можно передать кортеж вариантов

'task-42'.removeprefix('task-')   # '42'
'report.pdf'.removesuffix('.pdf') # 'report'

'42'.isdigit()   # True
'4.2'.isdigit()  # False — точка не цифра

'Купить хлеб'[:6]   # 'Купить'
'Купить хлеб'[-4:]  # 'хлеб'
```

## Строки неизменяемы

Любой метод возвращает **новую** строку, а исходная остаётся прежней:

```python
title = 'купить хлеб'
title.capitalize()
print(title)  # 'купить хлеб' — ничего не изменилось

title = title.capitalize()  # результат нужно сохранить

title[0] = 'К'  # TypeError: 'str' object does not support item assignment
```

Поэтому строку из многих частей собирают через `''.join(parts)`, а не прибавлением в цикле: `+=` каждый раз создаёт новую строку. CPython умеет оптимизировать `+=` в простых случаях, но `join` — надёжный и привычный способ.

## Частые ошибки

- **Забыть сохранить результат.** `title.strip()` без присваивания ничего не меняет.
- **`split(',')` и пустые значения.** Две запятые подряд дают пустую строку в списке. Если пустые не нужны: `[t for t in text.split(',') if t]`.
- **Сравнение без учёта регистра через `lower()`.** Для большинства текстов работает, но для некоторых языков надёжнее `casefold()`: `'Straße'.casefold() == 'STRASSE'.casefold()` — `True`, а с `lower()` — `False`.
- **Длина ≠ количество байт.** `len('ё')` — 1 символ, но в UTF-8 это 2 байта, а эмодзи — 4. Подробнее — в заметке про [Unicode и кодировки](../advanced/unicode.md).
- **Сборка SQL f-строкой.** `f"SELECT * FROM users WHERE name = '{name}'"` открывает дорогу SQL-инъекции. Передавайте значения параметрами драйвера.
