Паттерн Команда применяется для инкапсуляции команд в виде объектов. Например, с его помощью можно построить последовательность команд для отложенного выполнения или создать команды, допускающие отмену.

```python
import os

class MoveFileCommand:
    """
    Класс-команда для перемещения (переименования) файла.
    Можно выполнить (execute) и отменить (undo).
    """
    def __init__(self, src, dest):
        self.src = src    # исходное имя файла
        self.dest = dest  # новое имя файла

    def execute(self):
        """Выполнить команду (переименовать файл src -> dest)."""
        self.rename(self.src, self.dest)

    def undo(self):
        """Отменить команду (переименовать обратно dest -> src)."""
        self.rename(self.dest, self.src)

    def rename(self, src, dest):
        print(f"renaming {src} to {dest}")
        os.rename(src, dest)

# ======= Пример использования =======
def main():
    # Стек команд — можно выстраивать команды в очередь или стек
    command_stack = [
        MoveFileCommand('foo.txt', 'bar.txt'),
        MoveFileCommand('bar.txt', 'baz.txt')
    ]

    # --- Выполнение всех команд ---
    for cmd in command_stack:
        cmd.execute()

    # --- Отмена всех команд в обратном порядке ---
    for cmd in reversed(command_stack):
        cmd.undo()

if __name__ == "__main__":
    main()
```

- Каждая команда (`MoveFileCommand`) — **отдельный объект**, в котором хранится всё необходимое для выполнения и отмены действия.
- Можно создавать список команд, выполнять их позже, по очереди, в любой момент.
- Можно отменить (undo) действия, выполняя команды в обратном порядке.
- Такой подход удобен для реализации истории операций, макросов, систем “отменить/повторить” (например, в редакторах).

Применение:

- Редакторы (Undo/Redo)
- Очереди заданий (jobs)
- GUI: меню и кнопки (отложенное выполнение)
- Логирование и аудирование (записываем, какие команды были запущены)
- Автоматизация сценариев
