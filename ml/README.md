# Machine Learning

Раздел про машинное обучение: классические алгоритмы, нейронные сети, обработка данных, метрики качества и инструменты ML-инженера.

Основные направления:
- **Supervised learning** — обучение с учителем (классификация, регрессия)
- **Unsupervised learning** — без учителя (кластеризация, понижение размерности)
- **Deep Learning** — глубокие нейронные сети (CNN, RNN, Transformers)
- **NLP** — обработка естественного языка
- **MLOps** — продакшен ML-моделей

Ключевые библиотеки:
- `numpy`, `pandas` — работа с данными
- `scikit-learn` — классическое ML
- `pytorch`, `tensorflow` — глубокое обучение
- `transformers`, `langchain` — LLM и NLP
- `mlflow`, `dvc` — отслеживание экспериментов и версионирование
