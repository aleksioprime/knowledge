# HTTP

**HTTP** (Hypertext Transfer Protocol) — прикладной протокол обмена сообщениями между клиентом и сервером. Клиент отправляет запрос, сервер возвращает ответ. Сам HTTP не хранит состояние между запросами; состояние приложения обычно реализуют через cookies, токены и серверные сессии.

## Как проходит запрос

1. Клиент разбирает URL и находит IP-адрес домена через DNS.
2. Устанавливает соединение: TCP для HTTP/1.1 и HTTP/2 либо QUIC для HTTP/3.
3. Для HTTPS выполняет TLS-рукопожатие и проверяет сертификат сервера.
4. Отправляет HTTP-запрос.
5. Сервер или reverse proxy обрабатывает запрос и возвращает ответ.
6. Соединение закрывается либо переиспользуется для следующих запросов.
