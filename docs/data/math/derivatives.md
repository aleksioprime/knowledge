# Производные

Производная нужна, когда важно не само значение функции, а то, как быстро оно меняется: растёт или падает выручка, в какую сторону сдвинуть веса модели, где у функции минимум. Градиентный спуск, обучение нейросетей и любая численная оптимизация строятся на одном вопросе: «если чуть сдвинуть `x`, насколько изменится `f(x)`?»

## Минимальный пример

Производную можно посчитать численно, не зная формулы: взять две близкие точки и поделить изменение функции на изменение аргумента. Для `f(x) = x²` ответ должен совпасть с формулой `2x`, а знак производной подсказывает, в какую сторону идти к минимуму.

```python run
import math

def derivative(f, x, h=1e-6):
    return (f(x + h) - f(x - h)) / (2 * h)

def cost(x):
    return x ** 2 - 4 * x + 5      # минимум в точке x = 2

print(round(derivative(cost, 0), 6))     # -4.0 — слева от минимума функция убывает
print(round(derivative(cost, 2), 6))     # 0.0  — в точке минимума
print(round(derivative(cost, 5), 6))     # 6.0  — справа функция растёт
print(round(derivative(math.sin, 0), 6)) # 1.0  — cos(0)
```

## Как это работает

### Идея простыми словами

**Производная — это скорость изменения функции в точке.**

Представь, что едешь на машине. Функция `s(t)` — пройденный путь в зависимости от времени. Тогда производная `s'(t)` — это **скорость** в момент `t`.

```
f'(x) = lim  ( f(x + Δx) - f(x) ) / Δx       при Δx → 0
```

Геометрически: производная в точке = **тангенс угла наклона касательной** к графику в этой точке.

- Производная положительна → функция растёт.
- Производная отрицательна → функция убывает.
- Производная = 0 → точка экстремума (минимум или максимум) либо перегиб.

### Обозначения

Эти записи означают одно и то же:
```
f'(x)     df/dx     d/dx f(x)     Df(x)
```

### Производные основных функций

Запомнить (или иметь под рукой):

```
(C)'       = 0              ← константа
(x)'       = 1
(x^n)'     = n · x^(n-1)    ← главное правило для степеней
(√x)'      = 1 / (2√x)
(1/x)'     = -1/x²
(e^x)'     = e^x            ← e^x особенное: производная сама от себя
(a^x)'     = a^x · ln(a)
(ln x)'    = 1/x
(log_a x)' = 1 / (x · ln a)
(sin x)'   = cos x
(cos x)'   = -sin x
```

### Правила дифференцирования

**1. Константа выносится**

```
(C · f(x))' = C · f'(x)
```
Пример: `(5x³)' = 5 · 3x² = 15x²`.

**2. Сумма / разность**

```
(f + g)' = f' + g'
(f - g)' = f' - g'
```
Пример: `(x² + 3x)' = 2x + 3`.

**3. Произведение**

```
(f · g)' = f' · g + f · g'
```
Пример: `(x · sin x)' = 1 · sin x + x · cos x`.

**4. Частное**

```
(f / g)' = (f' · g - f · g') / g²
```

**5. Цепное правило (сложная функция)**

Это самое важное правило для практики.

```
(f(g(x)))' = f'(g(x)) · g'(x)
```

Идея: берёшь производную «внешней» функции, подставляя в неё «внутреннюю», и умножаешь на производную «внутренней».

Примеры:
```
(e^(2x))'    = e^(2x) · 2 = 2e^(2x)
((x² + 1)³)' = 3(x² + 1)² · 2x = 6x(x² + 1)²
(sin(x²))'   = cos(x²) · 2x
```

### Примеры на разогрев

```
f(x) = x² + 3x + 7
f'(x) = 2x + 3

f(x) = 5x⁴ - 2x + 1
f'(x) = 20x³ - 2

f(x) = e^x · x
f'(x) = e^x · x + e^x · 1 = e^x (x + 1)

f(x) = ln(x² + 1)
f'(x) = 1/(x² + 1) · 2x = 2x/(x² + 1)
```

### Поиск экстремумов

Чтобы найти минимум или максимум функции:
1. Найти `f'(x) = 0` → это «подозрительные» точки.
2. Посмотреть, как меняется знак производной вокруг них:
   - `f'` меняется с «+» на «−» → **максимум**.
   - `f'` меняется с «−» на «+» → **минимум**.

Пример. `f(x) = x² - 4x + 5`.
```
f'(x) = 2x - 4 = 0   →   x = 2
```
Слева от 2 производная отрицательна (функция падает), справа — положительна (растёт). Значит, `x = 2` — минимум. `f(2) = 1`.

### Где это используется в IT

**1. Машинное обучение — градиентный спуск**

Обучение нейросетей сводится к минимизации функции потерь (loss). Делается это так:
- считаем градиент (вектор частных производных) функции потерь;
- сдвигаем веса в сторону, **противоположную** градиенту (туда, где loss быстрее всего падает);
- повторяем.

```
w_new = w_old - lr · ∂loss/∂w
```

Обратное распространение ошибки (backpropagation) в нейросети — это применение цепного правила миллион раз.

Тот же спуск можно сделать руками на функции из минимального примера: шаг за шагом `x` приходит к минимуму в точке 2.

```python run
def cost(x):
    return x ** 2 - 4 * x + 5

def cost_derivative(x):
    return 2 * x - 4

x = 10.0
learning_rate = 0.1
for step in range(30):
    x = x - learning_rate * cost_derivative(x)

print(round(x, 3))   # 2.01 — почти минимум
```

**2. Оптимизация**

Поиск минимума / максимума — везде, от логистики до автонастройки гиперпараметров.

**3. Численное дифференцирование**

Если функция сложная, считаем приближённо через симметричную разность, как в минимальном примере: `(f(x + h) - f(x - h)) / (2h)`. Симметричная формула точнее односторонней `(f(x + h) - f(x)) / h` при том же `h`.

**4. Анализ сложности и производительности**

Понимание, «как быстро растёт время выполнения с увеличением `n`», — это интуиция из той же области.

## Частые ошибки

- Забыли цепное правило → `(e^(2x))'` записано как `e^(2x)` без множителя 2, а градиент выходит в два раза меньше нужного → после производной внешней функции всегда умножать на производную внутренней.
- Производная произведения записана как произведение производных → `(x · sin x)' = 1 · cos x` вместо `sin x + x · cos x` → применять правило `f'g + fg'`.
- Слишком маленький шаг `h` в численной производной → при `h = 1e-15` разность `f(x + h) - f(x - h)` тонет в ошибке округления `float`, и результат превращается в шум → брать `h` порядка `1e-6`; если нужна точность, использовать аналитическую формулу или автоматическое дифференцирование.
- Нашли точку, где `f'(x) = 0`, и назвали её минимумом → у `f(x) = x³` производная в нуле равна нулю, но это перегиб → проверять смену знака производной или знак второй производной.
- Шаг градиентного спуска слишком большой → значения не сходятся, а раскачиваются и уходят в бесконечность → уменьшить `learning_rate` или следить за тем, что функция потерь падает на каждом шаге.

## Когда не использовать

Производная нужна там, где функция гладкая. Для ступенчатых и разрывных функций (число ошибок классификации, целочисленные метрики, `round`) производная почти везде равна нулю или не существует, и градиентный спуск по ним не работает: берут гладкую замену, например кросс-энтропию вместо доли верных ответов.

Численное дифференцирование — инструмент для проверки и для редких вычислений. В обучении моделей оно слишком медленное: на каждый параметр нужны два вызова функции. Там используют автоматическое дифференцирование, которое встроено в PyTorch и JAX, а символьные производные можно получить через SymPy.
