# Shortener

Учебный сервис коротких ссылок (по аналогии с `bit.ly` или `tinyurl`). Принимает длинный URL и возвращает короткий, при обращении к которому происходит редирект на оригинал.

Структура:
- `app/src/` — исходный код приложения (`main.py`, `service.py`, `database/`, `utils/`)
- `app/tests/` — тесты (`conftest.py`, `test_service.py`)

Стек: FastAPI + SQLAlchemy + PostgreSQL + Pytest.
