**Гонка потоков** (**race condition**) — это ошибка, которая происходит, когда **несколько потоков одновременно изменяют один и тот же ресурс**, и результат зависит от порядка их выполнения. 

```python
import threading

counter = 0  # Общая переменная для всех потоков

def increment():
    global counter
    for _ in range(100000):
        counter += 1  # Изменяем общую переменную

threads = [threading.Thread(target=increment) for _ in range(5)]

for t in threads:
    t.start()

for t in threads:
    t.join()

print(f"Ожидаемый результат: 500000, реальный: {counter}")
```

Ожидаемый результат: 500000, реальный: 387456

Когда **два потока одновременно читают `counter` и увеличивают его**, может произойти следующее:

1. **Поток 1:** читает `counter = 100`
2. **Поток 2:** читает `counter = 100`
3. **Поток 1:** увеличивает `counter` (`100 + 1 = 101`)
4. **Поток 2:** увеличивает `counter` (`100 + 1 = 101`) ❌ **(Поток 2 "потерял" инкремент Потока 1!)**

Таким образом, вместо `102` значение **останется `101`**, а один инкремент **просто исчезнет**! 😱

Чем больше потоков, тем больше ошибок.

Мы можем **заблокировать доступ к `counter`**, чтобы потоки не вмешивались друг в друга.

```python
import threading

counter = 0
lock = threading.Lock()  # 🔒 Создаём блокировку

def increment():
    global counter
    for _ in range(100000):
        with lock:  # Захватываем блокировку
            counter += 1  # Теперь только один поток может менять counter

threads = [threading.Thread(target=increment) for _ in range(5)]

for t in threads:
    t.start()

for t in threads:
    t.join()

print(f"Ожидаемый результат: 500000, реальный: {counter}")
```

Гонка потоков в Python чаще всего **возникает из-за GIL**, который не позволяет потокам работать параллельно с вычислениями. Чтобы реально использовать **многоядерность** и избежать гонки, можно заменить `threading` на `multiprocessing`:

```python
import multiprocessing

counter = multiprocessing.Value('i', 0)  # Общая переменная (тип 'i' = integer)
lock = multiprocessing.Lock()  # 🔒 Блокировка

def increment():
    for _ in range(100000):
        with lock:
            counter.value += 1  # Меняем значение в безопасном режиме

processes = [multiprocessing.Process(target=increment) for _ in range(5)]

for p in processes:
    p.start()

for p in processes:
    p.join()

print(f"Ожидаемый результат: 500000, реальный: {counter.value}")
```

💡 **Теперь процессы работают параллельно на разных ядрах, и гонки потоков не возникает.**
