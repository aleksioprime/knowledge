Абстракция — это один из ключевых принципов объектно-ориентированного программирования (ООП), который заключается в выделении основных, наиболее значимых характеристик объекта и сокрытии его второстепенных деталей. Абстракция позволяет моделировать реальный мир в виде классов и объектов, которые включают только важные для конкретной задачи свойства и методы.

_Абстракция_ гласит, что мы должны выделять важные характеристики объекта. Мысль в том, чтобы мы могли определить минимально необходимый набор этих характеристик для того чтобы можно было решить поставленную задачу.

**Абстрактные классы и методы**

Абстрактный класс — это класс, который нельзя инстанцировать (создавать объекты). Он служит для определения интерфейса, который должны реализовать подклассы. В Python абстрактные классы создаются с использованием модуля `abc`.

- Пример использования абстрактного класса

```python
from abc import ABC, abstractmethod

class Animal(ABC):
	def __init__(self, name):
		self.name = name

	@abstractmethod
	def speak(self):
		pass

class Dog(Animal):
	def speak(self):
		return f"{self.name} говорит: Гав-гав!"

class Cat(Animal):
	def speak(self):
		return f"{self.name} говорит: Мяу!"

# Поскольку Animal является абстрактным классом, его нельзя инстанцировать
# animal = Animal("Животное")  # Это вызовет ошибку TypeError

dog = Dog("Шарик")
cat = Cat("Мурка")

print(dog.speak())  # Шарик говорит: Гав-гав!
print(cat.speak())  # Мурка говорит: Мяу!
```

**Основные моменты абстракции:**

1. **Интерфейсы и реализация**: Абстрактные классы и методы определяют интерфейс, который должен быть реализован подклассами. Это позволяет различным классам реализовывать методы по-разному, но с единым интерфейсом.
2. **Сокрытие деталей**: Абстракция скрывает внутренние детали реализации и предоставляет пользователю только необходимый интерфейс для взаимодействия с объектом.
3. **Упрощение и управление сложностью**: Абстракция упрощает взаимодействие с системой, предоставляя высокоуровневое представление объекта и скрывая сложность внутренней реализации.

### Пример использования абстракции в реальной задаче

Предположим, у нас есть система для обработки платежей. Мы можем создать абстрактный класс `PaymentProcessor`, который определяет интерфейс для обработки платежей, а затем реализовать конкретные классы для разных типов платежей.

```python
from abc import ABC, abstractmethod

class PaymentProcessor(ABC):
	@abstractmethod
	def process_payment(self, amount):
		pass

class CreditCardProcessor(PaymentProcessor):
	def process_payment(self, amount):
		print(f"Обработка платежа кредитной картой на сумму {amount} рублей.")

class PayPalProcessor(PaymentProcessor):
	def process_payment(self, amount):
		print(f"Обработка платежа через PayPal на сумму {amount} рублей.")

def process_customer_payment(processor, amount):
	processor.process_payment(amount)

# Пример использования
credit_card_processor = CreditCardProcessor()
paypal_processor = PayPalProcessor()

process_customer_payment(credit_card_processor, 1000)  # Обработка платежа кредитной картой на сумму 1000 рублей.
process_customer_payment(paypal_processor, 2000)       # Обработка платежа через PayPal на сумму 2000 рублей.
```

В этом примере абстракция позволяет легко добавлять новые способы обработки платежей, не изменяя код, который использует процессоры платежей.
