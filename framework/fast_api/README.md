# FastAPI

**FastAPI** — асинхронный веб-фреймворк для Python, построенный на Starlette и Pydantic. API описывается обычными функциями с подсказками типов, а FastAPI по ним проверяет входные данные, сериализует ответы и строит документацию OpenAPI (Swagger UI на `/docs`).

Заметки идут по порядку: каждая опирается на предыдущие. Примеры взяты из учебного проекта [«Задачник»](../../pet/tasker/README.md) — там весь код собран в работающее приложение с базой данных и тестами.

## Содержание

1. [Первое приложение](docs/first_app.md) — эндпоинты, параметры пути и запроса, uvicorn, `def` и `async def`
2. [Схемы запросов и ответов](docs/schemas.md) — тело запроса, фильтрация ответа, отдельные схемы для создания, обновления и чтения
3. [Зависимости](docs/dependencies.md) — `Depends`, ресурсы с `yield`, цепочки проверок, подмена в тестах
4. [Ошибки и коды ответов](docs/errors.md) — `HTTPException`, свои исключения и обработчики
5. [Структура проекта](docs/structure.md) — роутеры, сервисы, настройки
6. [Авторизация по JWT](docs/auth_jwt.md) — хэширование паролей, выпуск и проверка токенов
