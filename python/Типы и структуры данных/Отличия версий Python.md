### Переход от Python 2 к Python 3

Python 3 был выпущен в 2008 году как не совместимая с Python 2 версия. Главная цель — устранить архитектурные проблемы и неудачные решения, допущенные в Python 2. Официальная поддержка Python 2 завершилась в январе 2020 года.

### Ключевые отличия между Python 2 и Python 3

**Строки и байты**  

В Python 2 строки (`str`) по умолчанию — это байты. В Python 3 строки (`str`) — это Unicode. Для байтов используется отдельный тип `bytes`.

**print как функция**  

В Python 2 `print` — оператор, без скобок:

```python
print "Hello"
```

В Python 3 `print()` — это функция:

```python
print("Hello")
```

**Деление целых чисел**  

В Python 2 деление двух целых (`/`) даёт целое число (например, `3 / 2 == 1`).  
В Python 3 деление всегда возвращает число с плавающей точкой (`3 / 2 == 1.5`). Для целочисленного деления используется `//`.

**Итераторы**  

Многие функции, такие как `range`, `zip`, `map`, `filter`, в Python 2 возвращают списки, в Python 3 — "ленивые" итераторы (generator-like objects).

**xrange и range**  

В Python 2 есть `range` (создаёт список) и `xrange` (ленивый генератор). В Python 3 остался только `range` (работает как `xrange` из Python 2).

**Функция input**

В Python 2 `input()` вычисляет выражение, а для ввода строки используют `raw_input()`.  
В Python 3 только `input()` — всегда возвращает строку.

**Ключи словаря**

В Python 2 методы `dict.keys()`, `dict.values()`, `dict.items()` возвращают списки.  
В Python 3 возвращают "view" объекты (итераторы), которые не занимают лишнюю память и поддерживают ленивую работу.

**Обработка ошибок**  

В Python 3 изменился синтаксис:

```python
# Python 2
except Exception, e:
# Python 3
except Exception as e:
```

**Строки формата**  

В Python 3 появилась современная f-строка:

```python
name = "Alice"
print(f"Hello, {name}!")
```

## Важные нововведения в Python 3.x

### Python 3.4 (2014)

- Встроенный модуль `enum`
- Новый модуль асинхронного программирования `asyncio`
### Python 3.5 (2015)

- Синтаксис `async` и `await`
- Расширенный распаковщик `*` в списках и функциях
### Python 3.6 (2016)

- f-строки (форматированные строки)
- Переменные типа `Underscore` (`_`) в REPL для последнего выражения
- Улучшения синтаксиса аннотаций типов
### Python 3.7 (2018)

- Введение дата-классов (`@dataclass`)
- Постоянный порядок ключей в словаре (`dict`)
- Новый модуль `contextvars` для работы с контекстами
### Python 3.8 (2019)

- Моржовый оператор `:=` (walrus operator)
- Поддержка позиционных только аргументов в функциях
- Улучшения в стандартных библиотеках
### Python 3.9 (2020)

- Объединение и обновление словарей с помощью `|` и `|=`
- Обновление синтаксиса типов коллекций (`list[int]`, `dict[str, int]`)
### Python 3.10 (2021)

- Конструкция структурного сопоставления (pattern matching, `match-case`)
- Улучшение аннотаций типов (PEP 604)
### Python 3.11 (2022)

- Значительное ускорение интерпретатора (оптимизации)
- Улучшенная работа со stack trace и исключениями
### Python 3.12 (2023)

- Новые возможности pattern matching
- Расширенные синтаксические возможности аннотаций типов
- Множество улучшений и оптимизаций стандартной библиотеки
