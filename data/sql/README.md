# SQL: справочник и подготовка к собеседованию

**SQL** (Structured Query Language) — декларативный язык работы с реляционными базами данных. Запрос описывает, **какой** результат нужен, а СУБД выбирает физический способ его получить.

Примеры ориентированы на стандартный SQL и PostgreSQL. Диалект-зависимые особенности отмечены отдельно.
