# Декораторы

Нужно залогировать каждый вызов десяти функций, измерить время их работы или проверить права пользователя перед вызовом. Копировать одинаковые строки в начало и конец каждой функции — плохой путь: код раздувается, а правка расползается по всем местам. Декоратор оборачивает функцию и добавляет действия до и после вызова, не трогая её код. Здесь простой декоратор и декоратор с параметрами — обе конструкции строятся на замыканиях.

## Минимальный пример

```python run
import functools

def log_calls(func):
    @functools.wraps(func)
    def wrapper(*args, **kwargs):
        print(f'вызов {func.__name__}{args}')
        result = func(*args, **kwargs)
        print(f'результат: {result}')
        return result
    return wrapper

@log_calls
def complete_task(title):
    return f'{title}: выполнена'

complete_task('Купить хлеб')
# вызов complete_task('Купить хлеб',)
# результат: Купить хлеб: выполнена
print(complete_task.__name__)  # complete_task
```

## Как это работает

### Простой декоратор

Декоратор (decorator) — функция, которая принимает другую функцию и возвращает её обёртку. Обёртка выполняет дополнительные действия до и после вызова исходной функции, не меняя её код.

Внутри декоратора — замыкание: обёртка `wrapper` помнит исходную функцию `func`, пробрасывает в неё все аргументы и возвращает её результат.

```python run
def decorator(func):
    def wrapper(*args, **kwargs):
        print("BEFORE")
        result = func(*args, **kwargs)
        print("AFTER")
        return result

    return wrapper

@decorator
def say_hi(name):
    print(f"Hi, my name is {name}")
    return 1

say_hi('John')
```

Запись `@decorator` над функцией — то же самое, что `say_hi = decorator(say_hi)` после её объявления. Имя `say_hi` теперь указывает на `wrapper`.

### Декоратор с аргументами

Чтобы передать в декоратор параметры, добавляют ещё один внешний слой: `repeat(n)` принимает аргументы и возвращает сам декоратор.

```python run
def repeat(n):
    def decorator(func):
        def wrapper(*args, **kwargs):
            print("BEFORE")
            result = []
            for _ in range(n):
                r = func(*args, **kwargs)
                result.append(r)
            print("AFTER")
            return result

        return wrapper
    return decorator

@repeat(3)
def say_hi(name):
    print(f"Hi, my name is {name}")
    return 1

say_hi("Alex")
```

## Частые ошибки

- Обёртка не возвращает результат `func(...)` → декорированная функция всегда возвращает `None` → сохранить результат в переменную и вернуть его из `wrapper`.
- Нет `@functools.wraps(func)` → у декорированной функции имя `wrapper`, пустая документация, в логах и трассировках непонятно, что вызвано → ставить `functools.wraps` на обёртку.
- Декоратор с параметрами применён без скобок (`@repeat` вместо `@repeat(3)`) → функция попадает в параметр `n`, а при вызове выходит `TypeError` → не забывать скобки, даже пустые, если декоратор принимает аргументы.
- Обёртка принимает фиксированный набор аргументов (`def wrapper(name)`) → декоратор ломается на функциях с другой сигнатурой → принимать `*args, **kwargs` и передавать их дальше.
- Декоратор делает работу на этапе объявления, а не вызова (например, открывает соединение внутри `decorator`, а не внутри `wrapper`) → действие выполняется один раз при импорте модуля → всё, что должно происходить при каждом вызове, помещать в `wrapper`.

## Когда не использовать

Если поведение нужно добавить одной-двум функциям, декоратор лишний: проще вызвать вспомогательную функцию в начале и в конце. Декоратор окупается, когда одно и то же действие применяется ко многим функциям.

Декоратор плохо подходит, когда обёртка должна знать внутренности функции или менять её логику посередине выполнения — тогда лучше изменить саму функцию или вынести общую часть в отдельную функцию. Для освобождения ресурсов вокруг блока кода, а не вокруг функции, берите [менеджер контекста](context_managers.md).
