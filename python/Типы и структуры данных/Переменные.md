Переменная в Python — это имя (идентификатор), которое ссылается на объект, находящийся в памяти программы. Сама переменная не хранит объект напрямую, а лишь указывает на его местоположение в оперативной памяти. На один и тот же объект может ссылаться несколько переменных; это значит, что разные имена могут указывать на один и тот же объект в памяти.

Когда на объект перестают ссылаться все переменные, выделенная под него память автоматически освобождается сборщиком мусора. В Python этот механизм основан на подсчёте ссылок: как только количество ссылок на объект становится равным нулю, память возвращается системе.
### Как устроены переменные в Python

- Присваивание переменной значения создаёт связь между именем и объектом, который хранится в памяти.
- Если несколько переменных указывают на один объект, они считаются "синонимами" этого объекта:

```python
x = 'some text'
y = x
print(x is y)  # True
```

- Удаление переменной (`del x`) удаляет только имя, но не сам объект. Если остались другие переменные, ссылающиеся на объект, он продолжит существовать.
- Сравнение через `==` проверяет совпадение значений объектов, а через `is` — совпадение самих объектов (их идентичность в памяти):

```python
a = [1, 2]
b = [1, 2]
print(a == b)  # True (значения равны)
print(a is b)  # False (разные объекты)
```

### Модель памяти Python

Python использует две основные области памяти:

- **Heap (Куча)** — область памяти, где хранятся все объекты: списки, кортежи, словари, строки, числа, функции, пользовательские классы и другие данные.

- **Stack (Стек вызовов)** — область памяти, где размещаются локальные переменные и ссылки на объекты. При вызове функции для неё создаётся новый стековый фрейм, который удаляется по завершении функции.

| Часть памяти         | Содержимое                                                        |
| -------------------- | ----------------------------------------------------------------- |
| Heap (Куча)          | Объекты (данные), доступные по ссылке                             |
| Stack (Стек вызовов) | Локальные переменные (имена), которые ссылаются на объекты в куче |

### Стили написания имён переменных

- **snake_case** — для переменных и методов экземпляра
- **UPPER_CASE_SNAKE_CASE** — для констант
- **CamelCase** — для классов
### Особенности

- Все имена в Python ссылаются на объекты по ссылке.
- Некоторые объекты (например, числа, строки, кортежи) являются иммутабельными, поэтому при изменении переменной с таким объектом в действительности создаётся новый объект.
- С помощью оператора `del` можно удалить имя переменной, но не сам объект (если на него ещё есть другие ссылки).

Таким образом, переменные в Python — это ссылки на объекты, а не контейнеры с данными. Такое устройство облегчает работу с памятью, позволяет гибко управлять объектами и реализует удобную модель взаимодействия с данными.
