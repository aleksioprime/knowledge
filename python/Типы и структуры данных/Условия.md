**Условия** — это конструкции языка программирования, которые позволяют выполнять определённые действия в зависимости от истинности или ложности выражения. В Python для этого используются условные операторы `if`, `elif` и `else`. Условные конструкции лежат в основе ветвления кода и позволяют реализовывать разнообразную логику обработки данных, проверки состояния программы и реагирования на различные ситуации.
## Основной синтаксис

```python
if условие:
    # блок кода, выполняемый если условие истинно
elif другое_условие:
    # блок кода, если первое условие ложно, а второе истинно
else:
    # блок кода, если все условия выше ложны
```

**Пример:**

```python
x = 10
if x > 0:
    print("Положительное число")
elif x == 0:
    print("Ноль")
else:
    print("Отрицательное число")
```
## Операторы сравнения

Для составления условий в Python используются операторы сравнения:

- `==` — равно
- `!=` — не равно
- `<` — меньше
- `<=` — меньше или равно
- `>` — больше
- `>=` — больше или равно

**Пример:**

```python
a = 5
b = 3
if a != b:
    print("Значения не равны")
```
## Логические операторы

Для объединения нескольких условий используются логические операторы:

- `and` — логическое И (оба условия должны быть истинны)
- `or` — логическое ИЛИ (хотя бы одно условие истинно)
- `not` — логическое отрицание (инверсия условия)

**Пример:**

```python
x = 5
if x > 0 and x < 10:
    print("x — положительное однозначное число")
```
## Тернарный оператор (условное выражение)

В Python можно записывать условные выражения компактно — с помощью тернарного оператора:

```python
result = "четное" if x % 2 == 0 else "нечетное"
print(result)
```
## Вложенные условия

Один блок `if` может быть вложен в другой:

```python
x = 5
if x > 0:
    if x < 10:
        print("x — положительное однозначное число")
```
## Особенности Python

- Любое значение можно использовать в условии. В качестве **ложных** в Python считаются: `False`, `None`, `0`, пустые строки, списки, кортежи, множества, словари и др.
- Остальные значения считаются истинными.

**Пример:**

```python
lst = []
if not lst:
    print("Список пустой")
```
## Использование условий в сочетании с циклами

Условия часто используются внутри циклов для фильтрации или остановки цикла:

```python
for i in range(10):
    if i % 2 == 0:
        print(i, "— чётное")
```
## Современные конструкции: match-case (Python 3.10+)

С версии Python 3.10 появилась конструкция структурного сопоставления `match-case` для сложных ветвлений и шаблонов:

```python
status = 404
match status:
    case 200:
        print("OK")
    case 404:
        print("Not Found")
    case _:
        print("Unknown status")
```
