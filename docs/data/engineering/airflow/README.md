# Apache Airflow

**Apache Airflow** — платформа для пайплайнов данных: цепочки задач описываются на Python в виде DAG, а Airflow запускает их по расписанию, повторяет упавшие шаги и показывает историю запусков в веб-интерфейсе.

Заметки написаны для Airflow 3. Пример — в папке [example](examples/): DAG, который каждый день забирает задачи из учебного API и сохраняет статистику в PostgreSQL.

## Содержание

1. [Первый DAG](first_dag.md) — задачи на `@task`, планировщик, подключения, повторы, идемпотентная загрузка
2. [XCom, расписание и запуски за прошлые даты](schedule_xcom.md) — передача данных между задачами, логическая дата и её смысл в Airflow 3, cron и Asset, `catchup` и backfill

## Основные понятия

- **DAG** — граф задач и их порядок;
- **Task** — один шаг; в Airflow 3 обычно функция с декоратором `@task` из `airflow.sdk`;
- **Scheduler** — решает, какие запуски пора начать;
- **XCom** — небольшие данные, которые задачи передают друг другу;
- **Connection** — адреса и пароли внешних систем, отдельно от кода;
- **Asset** — данные, обновление которых может запускать другие DAG.
