### Разница между списками и кортежами

Основное различие между списками и кортежами заключается в том, что списки являются изменяемыми, а кортежи — нет. 
Из-за их изменчивости списки занимают больше памяти и менее производительные, чем кортежи
Списки идеальны для ситуаций, где порядок элементов важен и элементы могут изменяться, а также где требуется часто добавлять или удалять элементы.
Кортежи могут использоваться в качестве ключей в словарях, идеальны для представления фиксированных наборов данных (координаты, rgb-цвета и т.д.), полезны для передачи по сети или между функциями, где изменения данных не должны происходить.
### Использование памяти списками

Когда создается список, Python выделяет больше памяти, чем необходимо для хранения текущих элементов. Это делается для того, чтобы уменьшить количество операций по выделению памяти при добавлении новых элементов. При добавлении элементов в список, если выделенной памяти становится недостаточно, Python выделяет новый блок памяти. Таким образом, списки часто имеют некоторую избыточную память
При значительном увеличении списка происходит перераспределение памяти. В процессе этого Python выделяет новый блок памяти большего размера, копирует туда существующие элементы и освобождает старую память. Это может быть дорогой операцией с точки зрения производительности

```python
import sys

# Создаем пустой список и проверяем его размер
empty_list = []
print(sys.getsizeof(empty_list))  # Выводит базовый размер пустого списка

# Добавляем элементы и проверяем размер списка
for i in range(10):
	empty_list.append(i)
	print(f'Length: {len(empty_list)}, Size in bytes: {sys.getsizeof(empty_list)}')
```
### Использование памяти кортежами

Поскольку кортежи неизменяемы, они не нуждаются в дополнительной памяти для управления динамическим изменением размера.

Кортежи хранятся в непрерывных блоках памяти, что может улучшить производительность доступа к их элементам. 

Python интерпретатор может оптимизировать кортежи, особенно если они используются как константы. Например, кортежи могут кэшироваться и повторно использоваться, если они содержат одни и те же элементы
### Работа со списками

Создание списка

```python
my_list = [1, 2, 3, 4, 5]
```

Добавление элементов

```python
my_list.append(6)  # Добавить один элемент в конец списка
my_list.extend([7, 8, 9])  # Добавить несколько элементов в конец списка
my_list.insert(0, 0)  # Вставить элемент на указанную позицию (в начало списка)
```

Удаление элементов

```python
my_list.remove(3)  # Удалить первый элемент с указанным значением
my_list.pop()  # Удалить и вернуть последний элемент
my_list.pop(0)  # Удалить и вернуть элемент на указанной позиции
del my_list[1]  # Удалить элемент по индексу
my_list.clear()  # Удалить все элементы из списка
```

Изменение элементов

```python
my_list[0] = 10  # Изменить значение элемента по индексу
```

Поиск элементов

```python
index = my_list.index(4)  # Найти индекс первого элемента со значением 4
count = my_list.count(2)  # Посчитать количество вхождений элемента со значением 2
```

Сортировка и обратный порядок

```python
my_list.sort()  # Отсортировать список по возрастанию
my_list.sort(reverse=True)  # Отсортировать список по убыванию
my_list.reverse()  # Изменить порядок элементов на обратный
```

Копирование списка

```python
copy_list = my_list.copy()  # Создать поверхностную копию списка
```

Получение длины списка

```python
length = len(my_list)  # Вернуть количество элементов в списке
```

Итерирование по списку

```python
for item in my_list:
	print(item)
```

### Работа с кортежами

Создание кортежа

```python
my_tuple = (1, 2, 3, 4, 5)
single_element_tuple = (1,)  # Создание кортежа с одним элементом
empty_tuple = ()  # Создание пустого кортежа
```

Поиск элементов

```python
index = my_tuple.index(4)  # Найти индекс первого элемента со значением 4
count = my_tuple.count(2)  # Посчитать количество вхождений элемента со значением 2
```

Распаковка кортежа

```python
a, b, c = (1, 2, 3)  # Распаковать кортеж в отдельные переменные
```

Конкатенация и повторение

```python
new_tuple = my_tuple + (6, 7)  # Конкатенация кортежей
repeated_tuple = my_tuple * 2  # Повторение кортежа
```

Преобразование кортежа в список и обратно

```python
list_from_tuple = list(my_tuple)  # Преобразовать кортеж в список
tuple_from_list = tuple(my_list)  # Преобразовать список в кортеж
```

Получение длины кортежа

```python
length = len(my_tuple)  # Вернуть количество элементов в кортеже
```

Итерирование по кортеже

```python
for item in my_tuple:
	print(item)
```
