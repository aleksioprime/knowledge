Оператор pass используется в качестве заполнителя для будущего кода. При выполнении ничего не происходит, но вы избегаете ошибки, если пустой код не разрешен. Пустой код не допускается в циклах, определениях функций, определениях классов или в операторах if.

```python
for i in range(10):
    if i % 2 == 0:
        pass  # Здесь потом появится обработка чётных чисел
    else:
        print(i)
```

Три точки (`...`) в Python — это объект `Ellipsis`.  
В большинстве случаев, когда их пишут в коде в одиночестве, это **ещё одна форма заглушки**. То есть это альтернатива оператору `pass` для временного заполнения тела функции, метода, класса и т.д.

```python
class MyClass:
    ...
```
