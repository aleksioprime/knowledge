## Алгоритмы сортировки
### Пузырьковая сортировка (Bubble Sort)

Пузырьковая сортировка — это простой алгоритм сортировки, который повторно проходит через список, сравнивая соседние элементы и меняя их местами, если они находятся в неправильном порядке. Этот процесс повторяется до тех пор, пока список не будет отсортирован.

**Пример**

```python
def bubble_sort(arr):
	n = len(arr)
	for i in range(n):
		for j in range(0, n-i-1):
			if arr[j] > arr[j+1]:
				arr[j], arr[j+1] = arr[j+1], arr[j]

# Пример использования
arr = [64, 34, 25, 12, 22, 11, 90]
bubble_sort(arr)
print("Отсортированный массив:", arr)
```

- Внешний цикл проходит по всему массиву.
- Внутренний цикл сравнивает каждый элемент с следующим и меняет их местами, если текущий элемент больше следующего.
- На каждом проходе по внутреннему циклу самый большой элемент "всплывает" в конец списка.
- **Преимущества и недостатки**

Преимущества

- Простота реализации.
- Подходит для небольших списков.

Недостатки

- Неэффективен для больших списков, поскольку его среднее и худшее время выполнения составляет O(n^2).
- Многочисленные проходы по списку.
### Сортировка выбором (Selection Sort)

Сортировка выбором разделяет список на две части: отсортированную и неотсортированную. Алгоритм последовательно выбирает минимальный элемент из неотсортированной части и перемещает его в конец отсортированной части.

**Пример**

```python
def selection_sort(arr):
	n = len(arr)
	for i in range(n):
		min_idx = i
		for j in range(i+1, n):
			if arr[j] < arr[min_idx]:
				min_idx = j
		arr[i], arr[min_idx] = arr[min_idx], arr[i]

# Пример использования
arr = [64, 25, 12, 22, 11]
selection_sort(arr)
print("Отсортированный массив:", arr)
```

- Внешний цикл проходит по всему массиву.
- На каждой итерации внутреннего цикла ищется минимальный элемент в неотсортированной части массива.
- После нахождения минимального элемента он меняется местами с первым элементом неотсортированной части.

**Преимущества и недостатки**

Преимущества

- Простота реализации.
- Меньшее количество обменов по сравнению с пузырьковой сортировкой.

Недостатки

- Неэффективен для больших списков, поскольку его время выполнения составляет O(n^2).
- Неустойчивость (не сохраняет относительный порядок равных элементов).

### Сортировка вставками (Insertion Sort)

Сортировка вставками строит окончательную отсортированную последовательность по одному элементу за раз. Алгоритм проходит по каждому элементу и вставляет его в правильное место в уже отсортированной части списка.

**Пример**

```python
def insertion_sort(arr):
	for i in range(1, len(arr)):
		key = arr[i]
		j = i - 1
		while j >= 0 and key < arr[j]:
			arr[j + 1] = arr[j]
			j -= 1
		arr[j + 1] = key

# Пример использования
arr = [12, 11, 13, 5, 6]
insertion_sort(arr)
print("Отсортированный массив:", arr)
```

- Начинаем с первого элемента, предполагая, что он отсортирован.
- Берем следующий элемент и перемещаем его влево до тех пор, пока не найдем правильное место в отсортированной части.
- Повторяем процесс для всех элементов в списке, пока весь список не будет отсортирован.

**Преимущества и недостатки**

Преимущества

- Эффективен для небольших массивов и почти отсортированных данных.
- Простота реализации и понимания.
- Устойчивость (сохраняет относительный порядок равных элементов).

Недостатки

- Неэффективен для больших массивов, поскольку его время выполнения составляет O(n^2).

## Функция sorted

Функция `sorted` в Python используется для сортировки итерабельных объектов (списков, кортежей, строк и других) и возвращает новый отсортированный список.

```python
sorted(iterable, key=None, reverse=False)
```

- **iterable**: обязательный параметр. Это итерируемый объект, который необходимо отсортировать.
- **key**: необязательный параметр. Это функция, которая извлекает ключ для сравнения из каждого элемента. По умолчанию `None`.
- **reverse**: необязательный параметр. Если установлено в `True`, элементы сортируются в обратном порядке. По умолчанию `False`.

Пример использования `key`

```python
# Сортировка списка строк по их длине
words = ["apple", "banana", "cherry"]
sorted_words = sorted(words, key=len)
print(sorted_words)  # ['apple', 'cherry', 'banana']
```

Пример использования `reverse`

```python
# Сортировка списка чисел в обратном порядке
numbers = [3, 1, 4, 1, 5, 9]
sorted_numbers = sorted(numbers, reverse=True)
print(sorted_numbers)  # [9, 5, 4, 3, 1, 1]
```

### Примеры

Сортировка списка чисел

```python
numbers = [4, 1, 7, 3]
sorted_numbers = sorted(numbers)
print(sorted_numbers)  # [1, 3, 4, 7]
```

Сортировка строки

```python
string = "python"
sorted_string = sorted(string)
print(sorted_string)  # ['h', 'n', 'o', 'p', 't', 'y']
```

Сортировка списка кортежей по второму элементу

```python
pairs = [(1, 'one'), (2, 'two'), (3, 'three'), (4, 'four')]
sorted_pairs = sorted(pairs, key=lambda pair: pair[1])
print(sorted_pairs)  # [(4, 'four'), (1, 'one'), (3, 'three'), (2, 'two')]
```

Сортировка списка словарей по значению ключа

```python
students = [
    {'name': 'John', 'age': 15},
    {'name': 'Jane', 'age': 12},
    {'name': 'Dave', 'age': 10}
]
sorted_students = sorted(students, key=lambda student: student['age'])
print(sorted_students)
# [{'name': 'Dave', 'age': 10}, {'name': 'Jane', 'age': 12}, {'name': 'John', 'age': 15}]
```
