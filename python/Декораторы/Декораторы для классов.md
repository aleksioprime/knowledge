**Декораторы классов** — это функции, которые принимают класс как аргумент, изменяют его (или возвращают новый класс) и используются для модификации или обёртывания поведения классов в Python.  

В отличие от функций-декораторов, которые работают с отдельными функциями или методами, декораторы классов применяются ко всему классу целиком. Это мощный инструмент для реализации паттернов, автоматизации типовых операций и улучшения читаемости кода.
### Синтаксис

Декоратор класса объявляется над определением класса с помощью символа `@`, аналогично декораторам функций:

```python
@my_class_decorator
class MyClass:
    ...
```

Здесь `my_class_decorator` — функция, принимающая класс в качестве аргумента и возвращающая (обычно) изменённый класс.
### Простой пример декоратора класса

```python
def add_repr(cls):
    """Добавляет универсальный __repr__ к классу."""
    def __repr__(self):
        return f"<{cls.__name__}({self.__dict__})>"
    cls.__repr__ = __repr__
    return cls

@add_repr
class Person:
    def __init__(self, name, age):
        self.name = name
        self.age = age

p = Person("Alice", 30)
print(p)  # <Person({'name': 'Alice', 'age': 30})>
```
## Пример: регистрация классов

Часто декораторы используют для автосохранения ссылок на классы, например, для создания фабрик или реестров:

```python
registry = {}

def register_class(cls):
    registry[cls.__name__] = cls
    return cls

@register_class
class Cat:
    pass

@register_class
class Dog:
    pass

print(registry)  # {'Cat': <class '__main__.Cat'>, 'Dog': <class '__main__.Dog'>}
```
### Пример: декоратор с аргументами

Как и в случае с функциями, можно создать фабрику декораторов для классов:

```python
def tag(tag_name):
    def decorator(cls):
        cls.tag = tag_name
        return cls
    return decorator

@tag("important")
class Document:
    pass

print(Document.tag)  # important
```
### Пример: обёртывание методов класса

Можно изменять или подменять методы класса:

```python
def uppercase_methods(cls):
    for attr, value in cls.__dict__.items():
        if callable(value) and not attr.startswith("__"):
            setattr(cls, attr, lambda self, *a, func=value, **kw: func(self, *a, **kw).upper())
    return cls

@uppercase_methods
class Messenger:
    def say(self):
        return "hello world"

m = Messenger()
print(m.say())  # HELLO WORLD
```
## Практическое применение декораторов классов

- Автоматизация регистрации/реестра классов.
- Добавление/модификация атрибутов класса.
- Генерация специальных методов (`__repr__`, `__str__`, и др.).
- Проверка соответствия интерфейсу.
- Интеграция с фреймворками (например, Django ORM, Flask, Marshmallow используют декораторы классов для объявлений моделей и схем).
## Стандартные декораторы классов

В стандартной библиотеке есть пример встроенного декоратора класса — `@dataclass` из модуля `dataclasses`, который автоматически добавляет специальные методы к классу данных:

```python
from dataclasses import dataclass

@dataclass
class Point:
    x: int
    y: int
```
