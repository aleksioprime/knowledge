**Аргументы функций** — это значения, которые передаются функции при её вызове. В Python существует несколько видов аргументов, позволяющих гибко управлять входными данными функции. Понимание типов и способов передачи аргументов важно для грамотного проектирования и использования функций.
### Позиционные аргументы

Это обычные аргументы, значения которых передаются функции по порядку (позиции) в определении.

**Пример:**

```python
def multiply(a, b):
    return a * b

print(multiply(2, 3))  # 6
```

Здесь `a` и `b` — позиционные аргументы.
### Именованные аргументы (ключевые)

Можно явно указывать имя аргумента при вызове функции, что повышает читаемость и позволяет менять порядок передачи.

**Пример:**

```python
def introduce(name, age):
    print(f"{name}, {age} лет")

introduce(name="Анна", age=20)
introduce(age=25, name="Олег")
```
### Аргументы по умолчанию

Можно указать значения по умолчанию для аргументов. Если при вызове функции значение не передано, используется значение по умолчанию.

**Пример:**

```python
def greet(name="Гость"):
    print(f"Привет, {name}!")

greet()        # Привет, Гость!
greet("Иван")  # Привет, Иван!
```

### Переменное количество позиционных аргументов (`*args`)

Используя `*args`, функция может принимать любое количество позиционных аргументов. Они собираются в кортеж.

**Пример:**

```python
def total(*args):
    print(args)
    return sum(args)

print(total(1, 2, 3))  # (1, 2, 3) -> 6
```

### Переменное количество именованных аргументов (`**kwargs`)

Используя `**kwargs`, функция принимает произвольное количество именованных аргументов. Они собираются в словарь.

**Пример:**

```python
def info(**kwargs):
    print(kwargs)

info(name="Анна", age=22, city="Москва")
# {'name': 'Анна', 'age': 22, 'city': 'Москва'}
```
### Комбинирование разных видов аргументов

Функция может принимать разные виды аргументов одновременно. Важно соблюдать порядок:

1. Позиционные параметры
2. Аргументы с значением по умолчанию
3. *args
4. **kwargs

**Пример:**

```python
def demo(a, b=0, *args, **kwargs):
    print("a:", a)
    print("b:", b)
    print("args:", args)
    print("kwargs:", kwargs)

demo(1, 2, 3, 4, x=5, y=6)
# a: 1
# b: 2
# args: (3, 4)
# kwargs: {'x': 5, 'y': 6}
```
## Распаковка аргументов

Если у вас есть кортеж или список, вы можете распаковать его при вызове функции с помощью `*`. Для словаря используется `**`.

**Пример:**

```python
def add(a, b, c):
    return a + b + c

nums = (1, 2, 3)
print(add(*nums))  # 6

params = {'a': 4, 'b': 5, 'c': 6}
print(add(**params))  # 15
```
## Ограничения и рекомендации

- Имя после `*` (например, `def f(*, x, y)`) делает параметры только именованными (нельзя передать по позиции).
- Избегайте изменяемых объектов как значения по умолчанию (`def foo(arg=[])`), чтобы не получить неожиданные эффекты.
- Используйте именованные аргументы для повышения читаемости.
