# Elasticsearch

**Elasticsearch** — распределённый поисковый и аналитический движок на базе Apache Lucene. Используется для полнотекстового поиска, лог-аналитики (ELK-стек), мониторинга и хранения временных рядов.

Ключевые концепции:
- Index → Type (устар.) → Document
- Шарды и реплики
- Инвертированный индекс
- Маппинги и анализаторы
- Query DSL (match, term, bool, range, fuzzy и т.д.)
- Aggregations для аналитики

Экосистема ELK: Elasticsearch + Logstash + Kibana.
