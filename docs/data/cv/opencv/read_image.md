# Чтение изображения

Любая обработка картинки начинается с того, чтобы загрузить её в память и понять, что получилось: сколько строк и столбцов, сколько каналов и в каком порядке лежат цвета. OpenCV читает файл сразу в массив NumPy, и дальше с изображением работают как с обычной матрицей.

## Минимальный пример

`cv2.imread` возвращает массив формы `(высота, ширина, каналы)`. Если файл не найден, функция не бросает исключение, а возвращает `None` — это нужно проверять.

```python
import cv2

image = cv2.imread('pixel3x3.png')
if image is None:
    raise FileNotFoundError('pixel3x3.png')

print(image.shape)              # (3, 3, 3) — 3 строки, 3 столбца, 3 канала
print(image.dtype)              # uint8
print(image[0, 2])              # [255 255 255] — белый пиксель, порядок каналов BGR

cv2.imwrite('copy.png', image)  # True — файл записан
```

## Как это работает

### Изображение как массив

Для чтения изображения нужно импортировать библиотеку и прочитать файл в переменную:

```python
import cv2

image = cv2.imread('pixel3x3.png')
print(image)
```

Пример результата:

```
[[[  0   0   0]
  [128 128 128]
  [255 255 255]]

 [[  0   0 255]
  [  0 255   0]
  [255   0   0]]

 [[255 255   0]
  [  0 255 255]
  [255   0 255]]]
```

Этот массив — изображение размером 3×3 пикселя, где каждый пиксель представлен в формате **BGR (Blue, Green, Red)**. Именно в таком порядке читает изображения OpenCV, а не в привычном RGB.

- **Первый уровень массива** — строки изображения.
- **Второй уровень** — столбцы.
- **Третий уровень** — значения цветов (BGR) для каждого пикселя.

Размер массива хранится в свойстве `shape`:

```python
print(image.shape)   # (3, 3, 3)

height, width, channels = image.shape
```

Второй аргумент `imread` задаёт режим чтения: `cv2.IMREAD_GRAYSCALE` даёт одноканальный массив формы `(h, w)`, `cv2.IMREAD_UNCHANGED` сохраняет альфа-канал PNG (4 канала).

```python
gray = cv2.imread('pixel3x3.png', cv2.IMREAD_GRAYSCALE)
print(gray.shape)   # (3, 3)
```

### Отображение

На локальном компьютере изображение показывает окно OpenCV:

```python
import cv2

image = cv2.imread('RGB-image.png')
cv2.imshow('Image', image)   # 'Image' — заголовок окна

cv2.waitKey(0)               # ждёт нажатия любой клавиши; без этого окно закроется сразу
cv2.destroyAllWindows()      # закрывает окна перед завершением скрипта
```

В Colab окна недоступны, вместо `imshow` используется патч:

```python
import cv2
from google.colab.patches import cv2_imshow

image = cv2.imread('RGB-image.png')
cv2_imshow(image)
```

В Colab и Jupyter Notebook можно показать массив через matplotlib. Он ожидает RGB, поэтому перед показом каналы переставляют:

```python
import cv2
from matplotlib import pyplot as plt
%matplotlib inline

image = cv2.imread('RGB-image.png')
plt.imshow(image)            # цвета перепутаны: красное выглядит синим
plt.show()

image_rgb = cv2.cvtColor(image, cv2.COLOR_BGR2RGB)
plt.imshow(image_rgb)        # правильные цвета
plt.show()
```

### Сохранение результатов

```python
cv2.imwrite(filename, image)
```

- `filename` — путь и имя файла. Расширение (`.jpg`, `.png`, `.bmp`) определяет формат сохранённого изображения.
- `image` — массив NumPy с изображением. Ожидается `uint8` в порядке BGR.

Функция возвращает `True`, если файл записан, и `False`, если не удалось (например, нет такой папки).

## Частые ошибки

- Файл не найден или путь с опечаткой → `imread` возвращает `None`, а падает код позже с `AttributeError: 'NoneType' object has no attribute 'shape'` → проверять результат на `None` сразу после чтения.
- Картинка показана через matplotlib без `cvtColor` → цвета инвертированы: лица синие, небо оранжевое → `cv2.cvtColor(image, cv2.COLOR_BGR2RGB)` перед `plt.imshow`.
- `cv2.imshow` без `cv2.waitKey` → окно мелькает и закрывается или остаётся серым → всегда вызывать `waitKey`.
- Запись массива `float64` или `int64` через `imwrite` → чёрная картинка или мусор → привести к `np.uint8` и диапазону 0–255.
- Сохранение в `.jpg` промежуточных результатов → при каждом сохранении теряется качество, точные значения пикселей «плывут» → для промежуточных файлов и масок использовать `.png`.
- Чтение цветного изображения как серого через `IMREAD_GRAYSCALE` и обращение к `image[y, x, 0]` → `IndexError: too many indices` → у серого изображения два индекса.

## Когда не использовать

Если изображение нужно только показать или сохранить в другом формате без вычислений, хватит Pillow (`PIL.Image`): она работает в RGB, понимает EXIF и больше форматов. Для веб-приложения, где картинки приходят байтами из запроса, `imread` с путём не подойдёт — вместо него `cv2.imdecode(np.frombuffer(data, np.uint8), cv2.IMREAD_COLOR)`.

Для обработки сотен тысяч изображений в обучении модели изображения читают загрузчики фреймворков (`torchvision`, `tf.data`), которые умеют работать в несколько потоков.
