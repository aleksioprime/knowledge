Удобный и лаконичный способ создания новых последовательностей (списков, множеств, словарей) из существующих

List Comprehensions (генераторы списков)

```python
# Создание списка квадратов чисел от 0 до 9
squares = [x ** 2 for x in range(10)]
print(squares)  # [0, 1, 4, 9, 16, 25, 36, 49, 64, 81]

# Фильтрация четных чисел из списка
evens = [x for x in range(10) if x % 2 == 0]
print(evens)  # [0, 2, 4, 6, 8]
```

Set Comprehensions (генераторы множеств)

```python
# Создание множества квадратов чисел от 0 до 9
squares_set = {x ** 2 for x in range(10)}
print(squares_set)  # {0, 1, 64, 36, 4, 9, 16, 49, 81, 25}
```

Dictionary Comprehensions (генераторы словарей)

```python
# Создание словаря, где ключами являются числа от 0 до 9, а значениями — их квадраты
squares_dict = {x: x ** 2 for x in range(10)}
print(squares_dict)  # {0: 0, 1: 1, 2: 4, 3: 9, 4: 16, 5: 25, 6: 36, 7: 49, 8: 64, 9: 81}
```

Generator Expressions (генераторные выражения)

Cоздают генераторы, которые вычисляют значения лениво, то есть по мере необходимости

```python
# Создание генератора квадратов чисел от 0 до 9
squares_gen = (x ** 2 for x in range(10))

# Генератор можно итерировать
for square in squares_gen:
	print(square)
```


Comprehensions часто выполняются быстрее, чем эквивалентные циклы `for` из-за оптимизаций, встроенных в интерпретатор Python
