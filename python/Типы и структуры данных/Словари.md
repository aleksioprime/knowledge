В Python словарь (`dict`) реализован как **хеш-таблица (hash table)** с **открытой адресацией**, что позволяет ему обеспечивать быстрый доступ к данным (среднее время поиска, вставки и удаления — `O(1)`).

1. **Использует хеширование** — ключи вычисляют **хеш** через `hash()`, и этот хеш используется для быстрого поиска значения.
2. **Хранит элементы в массиве** — значения (`value`) хранятся в массиве **"по адресу"**, вычисляемому на основе хеша ключа.
3. **Разрешает коллизии** с помощью **метода открытой адресации** — если два ключа имеют одинаковый хеш (коллизия), Python ищет ближайшую свободную ячейку.
4. **Сохраняет порядок добавления (Python 3.7+)** — начиная с Python 3.7, элементы в словаре хранятся **в порядке вставки**.

Пример структуры словаря (`dict`):

| Индекс | Хеш ключа (`key_hash`) | Ключ (`key`) | Значение (`value`) |
| ------ | ---------------------- | ------------ | ------------------ |
| 0      | 3428973                | "apple"      | 5                  |
| 1      | 1094829                | "banana"     | 2                  |
| 2      | 5039283                | "orange"     | 7                  |
| ...    | ...                    | ...          | ...                |
Как Python ищет значение по ключу?

1. Вычисляется хеш ключа: `key_hash = hash(key)`.
2. Берётся индекс в массиве: `index = key_hash % size_of_table`.
3. Проверяется, есть ли в ячейке нужный ключ:
    - Если да → вернуть значение.
    - Если нет → пробуем следующую ячейку (разрешение коллизий).

Оптимизация и особенности

1. **Размер таблицы всегда степень двойки** — это ускоряет вычисление индекса.
2. **При заполнении на 2/3 таблица увеличивается в 2 раза** (динамическое расширение).
3. **Словари компактны** — Python использует специальную оптимизацию для хранения ключей и значений в массивах (dict-key-sharing в CPython).

Если у тебя есть вопросы по внутреннему устройству, можно посмотреть `dict` через `.__dict__` или `sys.getsizeof(d)`. 

## Работа со словарями

**Группировка данных по ключу с помощью .get()**

```python
# создаём пустой словарь
countries = dict()
# вводим первую строку до цикла (можно заменить, использовав оператор-морж)
country = input()
# создаём счётчик номеров строк
str_number = 0
# продолжаем цикл, пока не введена строка «СТОП»
while country != "СТОП":
    # Если страна country есть среди ключей, то get() возвращает список,
    # хранящийся по этому ключу, иначе get() возвращает пустой список.
    # Добавляем в список значение str_number.
    countries[country] = countries.get(country, []) + [str_number]
    # увеличиваем счётчик
    str_number += 1
    # вводим следующую строку
    country = input()
# выводим название страны и полученные списки с новой строки
for countryin countries:
    print(f"{country}: {countries[country]}")
```

**Слияние словарей**

Объединение двух или более словарей в один.

**Вариант 1: Использование оператора `|` (Python 3.9+)**

```python
dict1 = {'a': 1, 'b': 2}
dict2 = {'b': 3, 'c': 4}
merged_dict = dict1 | dict2
print(merged_dict)  # {'a': 1, 'b': 3, 'c': 4}
```

**Вариант 2: Использование метода `update`**

```python
dict1 = {'a': 1, 'b': 2}
dict2 = {'b': 3, 'c': 4}
dict1.update(dict2)
print(dict1)  # {'a': 1, 'b': 3, 'c': 4}
```

**Вариант 3: Использование `ChainMap` из `collections`**

```python
from collections import ChainMap

dict1 = {'a': 1, 'b': 2}
dict2 = {'b': 3, 'c': 4}
merged_dict = dict(ChainMap(dict2, dict1))
print(merged_dict)  # {'a': 1, 'b': 2, 'c': 4}
```

**Обратный словарь (обмен ключей и значений)**

Создание нового словаря, в котором ключи и значения поменяны местами.

```python
original_dict = {'a': 1, 'b': 2, 'c': 3}
inverted_dict = {v: k for k, v in original_dict.items()}
print(inverted_dict)  # {1: 'a', 2: 'b', 3: 'c'}
```

**Фильтрация словаря**

Создание нового словаря, содержащего только те элементы, которые удовлетворяют определенному условию.

```python
original_dict = {'a': 1, 'b': 2, 'c': 3, 'd': 4}
filtered_dict = {k: v for k, v in original_dict.items() if v > 2}
print(filtered_dict)  # {'c': 3, 'd': 4}
```

**Словарь с подсчетом частоты**

Использование **`Counter`** для подсчета количества вхождений элементов.

```python
from collections import Counter

items = ['apple', 'banana', 'apple', 'orange', 'banana', 'apple']
counter = Counter(items)
print(counter)  # Counter({'apple': 3, 'banana': 2, 'orange': 1})
```

```python
from collections import Counter

c = Counter()
for word in ['spam', 'egg', 'spam', 'counter', 'counter', 'counter']:
	c[word] += 1
```

**Объединение значений по ключу**

Объединение значений из двух словарей, где значения являются списками.

```python
dict1 = {'a': [1, 2], 'b': [3, 4]}
dict2 = {'a': [5], 'c': [6]}
merged_dict = {k: dict1.get(k, []) + dict2.get(k, []) for k in set(dict1) | set(dict2)}
print(merged_dict)  # {'a': [1, 2, 5], 'b': [3, 4], 'c': [6]}
```

**Максимальное и минимальное значение в словаре**

Нахождение ключа с максимальным или минимальным значением.

```python
data = {'a': 10, 'b': 5, 'c': 30}
max_key = max(data, key=data.get)
min_key = min(data, key=data.get)
print(f'Max: {max_key} -> {data[max_key]}')  # Max: c -> 30
print(f'Min: {min_key} -> {data[min_key]}')  # Min: b -> 5
```

**Объединение значений словаря по ключам**

Объединение словарей с суммированием значений по одинаковым ключам.

```python
from collections import defaultdict

dicts = [{'a': 1, 'b': 2}, {'a': 2, 'b': 3, 'c': 4}, {'a': 3, 'c': 6}]
combined_dict = defaultdict(int)
for d in dicts:
	for k, v in d.items():
		combined_dict[k] += v

print(dict(combined_dict))  # {'a': 6, 'b': 5, 'c': 10}
```

**Проверка наличия всех ключей**

Проверка, содержит ли словарь все ключи из списка.

```python
required_keys = ['a', 'b']
data = {'a': 1, 'b': 2, 'c': 3}

if all(key in data for key in required_keys):
	print("All keys are present")
else:
	print("Some keys are missing")
```

**Группировка по значению**

Группировка ключей словаря по их значениям.

```python
data = {'a': 1, 'b': 2, 'c': 1, 'd': 2, 'e': 3}
grouped_dict = defaultdict(list)
for key, value in data.items():
	grouped_dict[value].append(key)

print(dict(grouped_dict))  # {1: ['a', 'c'], 2: ['b', 'd'], 3: ['e']}
```

**Удаление элементов из словаря**

Удаление элементов словаря по условию.

```python
data = {'a': 1, 'b': 2, 'c': 3, 'd': 4}
filtered_dict = {k: v for k, v in data.items() if v % 2 == 0}
print(filtered_dict)  # {'b': 2, 'd': 4}
```
