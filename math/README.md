# Математика

Базовая математика, которая часто всплывает в задачах на собеседованиях и в реальной работе разработчика: оценка сложности алгоритмов (логарифмы), вероятности и ML (производные, интегралы), криптография и хеширование (теория чисел).

Подход в конспектах:
- максимально просто, «человеческими» словами;
- с примерами из программирования;
- без академической строгости — главное понимать суть.
