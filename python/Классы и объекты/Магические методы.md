Магическими метода (дандер-методами) называют методы, имена которых начинаются и заканчиваются двойным подчеркиванием. Магические они потому, что почти никогда не вызываются явно. Их вызывают встроенные функции или синтаксические конструкции. 

Например, функция `len()` вызывает метод `__len__()` переданного объекта. Метод `__add__(self, other)` вызывается автоматически при сложении оператором `+`.

- Позволяют **перегружать операторы** (`+`, `==`, `len()` и т. д.).
- Позволяют **контролировать создание, вывод и изменение объектов**.

Перечислим некоторые магические методы:

- `__init__`: инициализатор класса
- `__add__`: сложение с другим объектом
- `__eq__`: проверка на равенство с другим объектом
- `__iter__`: возвращает итератор

```python
class Rectangle:
    def __init__(self, width, height):
        """Конструктор"""
        self.width = width
        self.height = height

    def __str__(self):
        """Возвращает строковое представление для print()"""
        return f"Прямоугольник {self.width}x{self.height}"

    def __len__(self):
        """Возвращает периметр (для len(rect))"""
        return 2 * (self.width + self.height)

    def __eq__(self, other):
        """Сравнивает площади двух прямоугольников"""
        return self.width * self.height == other.width * other.height

# Используем класс
rect1 = Rectangle(4, 5)
rect2 = Rectangle(2, 10)

print(rect1)  # Выведет: Прямоугольник 4x5
print(len(rect1))  # Выведет: 18 (периметр)
print(rect1 == rect2)  # True (оба имеют площадь 20)
```
