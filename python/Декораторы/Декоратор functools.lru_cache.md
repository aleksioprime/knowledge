**@lru_cache** — это встроенный декоратор из модуля `functools`, который реализует кэширование результатов функции по принципу "наименее недавно использованный" (Least Recently Used, LRU).  

Он позволяет значительно ускорить повторные вызовы функции с одинаковыми аргументами, избегая повторных вычислений или обращений к внешним ресурсам (например, API или БД).
### Как работает @lru_cache

- @lru_cache запоминает результаты вычислений функции для каждого уникального набора аргументов.
- Если функция вызывается снова с теми же аргументами — результат возвращается мгновенно из памяти, вычисления не происходят.
- Количество кэшируемых значений ограничивается параметром `maxsize` (по умолчанию 128). Если лимит превышен, самые "старые" результаты удаляются из кэша.
- Работает только с **хешируемыми** аргументами (строки, числа, кортежи, None и др.).
- Не кэширует функции с изменяемыми аргументами (например, списками или словарями).
### Пример использования

```python
from functools import lru_cache

@lru_cache(maxsize=128)
def fib(n):
    """Вычисляет n-е число Фибоначчи с кэшированием."""
    if n < 2:
        return n
    return fib(n - 1) + fib(n - 2)

print(fib(35))  # Рекурсия отработает очень быстро благодаря кэшу!
```
### Важные параметры

- `maxsize`: Максимальное количество уникальных вызовов, которые будут храниться в кэше. Значение по умолчанию — 128. Можно выставить `maxsize=None`, чтобы кэш был неограниченным (но это редко нужно).
- `typed`: Если True — кэш различает аргументы разного типа, например, 1 и 1.0 будут разными ключами.

**Пример:**

```python
@lru_cache(maxsize=32, typed=True)
def example(x):
    return x
```
### Управление кэшем

У кэшируемой функции появляются дополнительные методы:

- `cache_clear()` — очистить кэш вручную.
- `cache_info()` — узнать статистику по кэшу (количество попаданий, промахов, размер и лимит).

**Пример:**

```python
fib.cache_clear()       # Очистка кэша
print(fib.cache_info()) # Выводит CacheInfo(hits=..., misses=..., maxsize=..., currsize=...)
```

## Применение

- Кэширование тяжёлых и часто повторяющихся вычислений (например, факториал, числа Фибоначчи, динамическое программирование).
- Кэширование ответов API, запросов к БД.
- Снижение нагрузки на сеть и внешние ресурсы.
## Ограничения

- Подходит только для "чистых" функций — т.е. тех, которые всегда возвращают одинаковый результат при одинаковых аргументах.
- Не кэширует функции с изменяемыми аргументами.
- Кэш живёт только в рамках текущего процесса (между перезапусками программы кэш сбрасывается).
