Поверхностная копия (shallow copy) — это копия объекта, в которой копируются только верхние уровни структуры, но не вложенные объекты

```python
import copy

original = [[1, 2, 3], [4, 5, 6]]
shallow = copy.copy(original)  # Поверхностная копия

print(original is shallow)  # ❌ False (разные объекты)
print(original[0] is shallow[0])  # ✅ True (ссылаются на один список!)
```

`original` и `shallow` — это **разные списки**, но их вложенные списки (`[1, 2, 3]` и `[4, 5, 6]`) **остались одними и теми же объектами**.

```python
original[0].append(99)
print(original)  # [[1, 2, 3, 99], [4, 5, 6]]
print(shallow)   # [[1, 2, 3, 99], [4, 5, 6]] ❗️ (изменилось тоже!)
```

`original[0]` и `shallow[0]` **указывают на один и тот же список**, поэтому изменения затронули обе копии.

Если нужно **скопировать все вложенные объекты**, используй **глубокую копию (`deepcopy`)**:

```python
import copy

deep = copy.deepcopy(original)

original[0].append(100)
print(original)  # [[1, 2, 3, 99, 100], [4, 5, 6]]
print(deep)      # [[1, 2, 3, 99], [4, 5, 6]] ✅ (не изменилось!)
```

Теперь `deep` не связан с `original`, и изменения не затрагивают копию

В тоге, разница методов:

Глубокая копия `deepcopy()` создает новую и отдельную копию всего объекта или списка со своим уникальным адресом памяти. Это означает, что любые изменения, внесенные вами в новую копию объекта или списка, не будут отражаться в исходной. Этот процесс происходит следующим образом: сначала создается новый список или объект, а затем рекурсивно копируются все элементы из исходного в новый.

Поверхностное копирование `copy()` также создает отдельный новый объект или список, но вместо копирования дочерних элементов в новый объект оно просто копирует ссылки на их адреса памяти. Следовательно, если вы сделаете изменение в исходном объекте, оно будет отражено в скопированном объекте, и наоборот. Короче говоря, обе копии зависят друг от друга.
