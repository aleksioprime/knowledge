# Деструктуризация

Деструктуризация извлекает значения из массивов и свойства из объектов в отдельные переменные.

## Деструктуризация массивов

Переменные сопоставляются с элементами по позиции:

```js
const colors = ['red', 'green', 'blue'] // создаём исходный массив из трёх цветов
const [first, second] = colors // записываем первый элемент в first, а второй — в second

first // смотрим текущее значение first; результат: 'red'
second // смотрим текущее значение second; результат: 'green'
```

Элемент можно пропустить, а оставшиеся значения собрать rest-оператором:

```js
const [first, , third, ...others] = values // пропускаем второй элемент, а элементы после третьего собираем в others
```

Значение по умолчанию используется только для отсутствующего элемента или `undefined`, но не для `null`:

```js
const [first = 10] = [] // элемента нет, поэтому first получает значение по умолчанию 10
const [second = 10] = [undefined] // элемент равен undefined, поэтому second тоже получает 10
const [third = 10] = [null] // null считается заданным значением, поэтому third получает null
```

### Обмен значений

Деструктуризация позволяет поменять значения двух переменных без временной третьей переменной.

```js
let left = 1 // сохраняем числовое значение в переменной
let right = 2 // сохраняем числовое значение в переменной

;[left, right] = [right, left] // деструктурируем массив и присваиваем значения переменным
```

Точка с запятой защищает выражение, если предыдущая строка может соединиться с `[` при автоматической расстановке точек с запятой.

## Деструктуризация объектов

Переменная по умолчанию получает имя свойства:

```js
const user = { // создаём объект, свойства которого будем извлекать
  id: 42, // задаём свойство id
  name: 'Alex', // задаём свойство name
  role: 'admin', // задаём свойство role
}

const { id, name } = user // создаём переменные id и name из одноимённых свойств user
```

Свойство можно переименовать, задать значение по умолчанию и собрать остальные собственные перечисляемые свойства:

```js
const { // начинаем объектный шаблон деструктуризации
  name: displayName, // берём свойство name и записываем его в переменную displayName
  avatar = '/default.png', // используем запасной путь, если avatar отсутствует или равен undefined
  ...userDetails // собираем остальные свойства в новый объект userDetails
} = user // извлекаем перечисленные свойства из объекта user
```

Здесь `name` — ключ объекта, а `displayName` — новая переменная. Переменная `name` не создаётся.

### Вложенная деструктуризация

Шаблон деструктуризации может повторять форму вложенного объекта и извлекать глубокое свойство за одну операцию.

```js
const response = { // создаём вложенную структуру, похожую на ответ сервера
  data: { // задаём свойство data
    profile: { // задаём свойство profile
      city: 'Moscow', // задаём свойство city
    },
  },
}

const { // начинаем разбор объекта response
  data: { // переходим во вложенное свойство data, не создавая переменную data
    profile: { city }, // переходим в profile и создаём переменную city
  },
} = response // извлекаем city из вложенной структуры response
```

Промежуточные переменные `data` и `profile` здесь не создаются. Если вложенного объекта может не быть, безопаснее сначала использовать optional chaining или значение по умолчанию.

### Вычисляемый ключ

Если имя нужного свойства хранится в переменной, его записывают в квадратных скобках прямо внутри шаблона.

```js
const propertyName = 'role' // сохраняем строку в переменной
const { [propertyName]: role } = user // читаем свойство с вычисленным именем и записываем значение в role
```

### Присваивание существующим переменным

При объектной деструктуризации без объявления нужны круглые скобки, иначе `{}` будет воспринят как блок:

```js
let name // заранее объявляем переменную, которой позже присвоим свойство объекта

;({ name } = user) // извлекаем свойство name из user и записываем его в уже объявленную переменную
```

## Параметры функций

Объект можно деструктурировать прямо в параметрах:

```js
function printUser({ name, role = 'user' }) { // объявляем функцию printUser()
  console.log(`${name}: ${role}`) // выводим значение в консоль
}
```

Если весь аргумент необязателен, добавьте значение по умолчанию для объекта:

```js
function createUser({ name = 'Без имени', active = true } = {}) { // объявляем функцию createUser()
  return { name, active } // возвращаем вызывающему коду значение выражения { name, active }
}

createUser() // вызываем функцию без аргумента; значения берутся из пустого объекта по умолчанию
```

## Spread

Spread записывается как `...` и раскрывает значение на отдельные элементы, аргументы или свойства.

### Копирование и объединение массивов

В литерале массива spread раскрывает элементы исходного массива в новый. Так можно сделать поверхностную копию или собрать несколько массивов в один.

```js
const first = [1, 2] // создаём массив с начальными элементами
const second = [3, 4] // создаём массив с начальными элементами

const copy = [...first] // создаём массив с начальными элементами
const combined = [...first, ...second] // создаём массив с начальными элементами
const withMiddle = [0, ...first, 2.5, ...second, 5] // создаём массив с начальными элементами
```

Копия поверхностная: вложенные объекты остаются общими.

Spread часто нагляднее `concat()`, когда элементы добавляются в разные части выражения. При этом `concat()` тоже не изменяет исходные массивы и может принимать одиночные неитерируемые значения.

### Строки и другие iterable-объекты

Spread массива требует iterable-значение. Строка является iterable:

```js
const letters = [...'JavaScript'] // создаём массив с начальными элементами
const unique = [...new Set([1, 1, 2])] // создаём Set для удаления повторов и разворачиваем его обратно в массив
```

Обычный объект не является iterable, поэтому `[...user]` вызовет `TypeError`.

### Аргументы функции

В месте вызова spread превращает элементы массива в отдельные позиционные аргументы функции.

```js
const numbers = [3, 7, 2] // создаём массив с начальными элементами

Math.max(...numbers) // передаём 3, 7 и 2 как отдельные аргументы; результат: 7
```

Очень большой массив не следует раскрывать в аргументы: среда выполнения ограничивает их количество.

### Объекты

Объектный spread раскрывает собственные перечисляемые свойства:

```js
const defaults = { theme: 'light', pageSize: 10 } // создаём объект и сохраняем ссылку в переменной
const settings = { pageSize: 20 } // создаём объект и сохраняем ссылку в переменной

const result = { // создаём объект и сохраняем ссылку в переменной
  ...defaults, // сначала копируем свойства значений по умолчанию
  ...settings, // затем перезаписываем их пользовательскими настройками
  loaded: true, // задаём свойство loaded
}
// { theme: 'light', pageSize: 20, loaded: true }
```

Позднее свойство перезаписывает ранее записанное. Копирование остаётся поверхностным и не сохраняет прототип или исходные property descriptors.

## Rest

Rest выглядит так же — `...`, но выполняет обратную задачу: собирает оставшиеся значения.

### В деструктуризации

Rest внутри шаблона сохраняет часть значений в отдельную коллекцию, чтобы они не потерялись после извлечения первых элементов или свойств.

```js
const [first, ...otherNumbers] = [1, 2, 3] // записываем 1 в first, а [2, 3] — в otherNumbers
const { password, ...publicUser } = user // извлекаем password, а остальные свойства собираем в publicUser
```

Rest должен быть последним элементом шаблона. Объектный rest собирает оставшиеся собственные перечисляемые свойства в новый поверхностный объект.

### В параметрах функции

Rest-параметр собирает все оставшиеся аргументы вызова в настоящий массив.

```js
function sum(...numbers) { // объявляем функцию sum()
  return numbers.reduce((total, number) => total + number, 0) // сворачиваем элементы в одно итоговое значение
}

sum(1, 2, 3) // numbers внутри функции станет массивом [1, 2, 3]; результат: 6
```

Rest-параметр:

- собирает любое количество оставшихся аргументов;
- является настоящим массивом;
- должен быть последним параметром;
- может быть только один;
- не допускает запятую после себя.

Он обычно удобнее псевдомассива `arguments`, особенно в стрелочных функциях, у которых собственного `arguments` нет.
