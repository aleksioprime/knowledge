# Kubernetes

**Kubernetes (K8s)** — система оркестрации контейнеризованных приложений. Автоматизирует развёртывание, масштабирование, балансировку нагрузки, обновления и самовосстановление приложений в кластере из множества машин.

Базовые объекты:
- **Pod** — минимальная единица развёртывания (один или несколько контейнеров)
- **Deployment** — декларативное управление набором подов
- **ReplicaSet** — обеспечивает нужное число подов
- **Service** — стабильный сетевой endpoint для подов
- **Ingress** — HTTP/HTTPS-маршрутизация снаружи в сервисы
- **ConfigMap / Secret** — конфигурация и секреты
- **Namespace** — логическая изоляция ресурсов
- **PersistentVolume / PVC** — постоянное хранилище

Инструменты экосистемы: `kubectl`, Helm, Kustomize, ArgoCD, k9s.
