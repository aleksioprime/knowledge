# ClickHouse

**ClickHouse** — колоночная СУБД для OLAP-нагрузок, разработанная в Яндексе. Оптимизирована для аналитических запросов по огромным объёмам данных и обеспечивает скорость в десятки/сотни раз выше традиционных строковых СУБД на агрегациях.

Особенности:
- Колоночное хранение данных
- Очень высокая скорость SELECT по миллиардам строк
- Векторизация и SIMD-инструкции
- Поддержка SQL (с расширениями)
- Движки таблиц (MergeTree, ReplicatedMergeTree, Distributed и др.)
- Репликация и шардирование
