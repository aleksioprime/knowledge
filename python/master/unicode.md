# Байты и Unicode

Текст в программе — это строка (`str`), а на диске и в сети — байты (`bytes`). Чтобы перейти от одного к другому, строку кодируют, а байты декодируют. Разберёмся, как устроены байты и что такое кодировка.

## Байты

Объект `bytes` — это последовательность целых чисел от 0 до 255, каждое занимает один байт. При выводе Python показывает такие байты символами или в шестнадцатеричном виде.

Байты неизменяемы (immutable): поменять элемент на месте нельзя.

```python run
b = b'abc'
b[0] = 65  # TypeError: 'bytes' object does not support item assignment
```

Если байты нужно менять, есть массив байтов (`bytearray`). Он изменяемый (mutable).

```python run
ba = bytearray(b'abc')
ba[0] = 65  # 65 — код символа 'A'
print(ba)  # bytearray(b'Abc')
```

## Кодирование и декодирование

Стандарт Unicode чётко разделяет два понятия:

- **Кодовая позиция** (code point) — идентификатор символа, число от 0 до 1 114 111. В стандарте его записывают 4–6 шестнадцатеричными цифрами с префиксом `U+`, например `U+00E9` для `é`.
- **Байтовое представление** — последовательность из одного или нескольких байтов, которая получается, когда к кодовой позиции применяют конкретную кодировку.

Кодировка (encoding) — это алгоритм, который переводит кодовые позиции Unicode в байты и обратно. Один и тот же символ в разных кодировках может иметь разное байтовое представление.

При выводе `bytes` байт, соответствующий печатному ASCII-символу (коды 32–126), показывается самим символом. Остальные байты выводятся как escape-последовательность `\xHH`, где `HH` — две шестнадцатеричные цифры.

```python run
s = 'café'
print(f"Text = {s}, len(s) = {len(s)}, type(s) = {type(s)}")

b = s.encode('utf8')  # str -> bytes
print(f"Bytes = {b}, len(b) = {len(b)}, type(b) = {type(b)}")

c = b.decode('utf8')  # bytes -> str
print(f"Decoded = {c}, len(c) = {len(c)}, type(c) = {type(c)}")
```

В строке четыре символа, а в байтах — пять: в UTF-8 символ `é` занимает два байта (`\xc3\xa9`).
