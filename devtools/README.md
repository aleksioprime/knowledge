# DevTools

Инструменты разработчика: контейнеризация, контроль версий, менеджеры окружений и зависимостей, линтеры и форматтеры, автоматизация рабочих процессов.

## Содержание

### Версионирование и инфраструктура
- [Docker](docker/README.md) — контейнеризация приложений
- [Git](git/README.md) — система контроля версий

### Управление Python и зависимостями
- [pyenv](pyenv/README.md) — менеджер версий Python
- [Poetry](poetry/README.md) — менеджер зависимостей и пакетов
- [uv](uv/README.md) — быстрый менеджер пакетов на Rust
- [pipx](pipx/README.md) — изолированный запуск Python CLI-утилит

### Качество кода
- [Линтеры и форматтеры](linter/README.md) — обзор инструментов и настройка стека ruff/mypy/pre-commit
- [Код-ревью](code_review/README.md) — на что смотреть, как писать комментарии, что делает автор, чек-лист

### Работа в команде
- [Работа над проектом в команде](teamwork/README.md) — декомпозиция по фичам, описание задачи, оценка сроков диапазоном, Scrum и Kanban, диаграмма Ганта, показ результата и защита архитектуры

### Автоматизация и окружение
- [Task Runners](task_runners/README.md) — Make, Just, Taskfile (единый интерфейс для команд проекта)
- [Управление окружением](env_management/README.md) — direnv, mise (авто-активация переменных и venv)
