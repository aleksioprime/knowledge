**Проблемы с аргументами и переменными в функциях** — это типичные ситуации, с которыми сталкиваются многие разработчики на Python, особенно в начале. Они связаны с особенностями передачи переменных, использованием изменяемых (мутабельных) и неизменяемых (иммутабельных) типов, а также с областью видимости и поведением аргументов по умолчанию. Ниже рассмотрены основные проблемы, их причины и способы решения.
### 1. Изменяемые аргументы по умолчанию

**Проблема:**  
Если в определении функции используется изменяемый объект (например, список или словарь) в качестве значения по умолчанию, этот объект сохраняется между вызовами функции.

**Пример:**

```python
def add_item(item, items=[]):
    items.append(item)
    return items

print(add_item(1))  # [1]
print(add_item(2))  # [1, 2] — неожиданно!
```

**Почему это плохо:**  
Список `items` один и тот же для всех вызовов функции, если не указать явно другой список.

**Решение:**

```python
def add_item(item, items=None):
    if items is None:
        items = []
    items.append(item)
    return items
```
### 2. Передача переменных по ссылке и значению

В Python все переменные — это ссылки на объекты. При передаче аргументов в функцию копируется сама ссылка, а не объект.

- Если объект **изменяемый** (список, словарь и др.), его можно изменить внутри функции.
- Если объект **неизменяемый** (число, строка, кортеж), любые "изменения" создают новый объект.

**Пример:**

```python
def modify_list(lst):
    lst.append(100)

nums = [1, 2, 3]
modify_list(nums)
print(nums)  # [1, 2, 3, 100] — исходный список изменён!

def modify_int(x):
    x = x + 1
    return x

a = 5
modify_int(a)
print(a)  # 5 — исходное число не изменилось
```
### 3. Локальные и глобальные переменные

Всё, что объявлено внутри функции, — локальное и не влияет на глобальные переменные с тем же именем (если не использовать ключевые слова `global` или `nonlocal`).

**Пример:**

```python
x = 10

def foo():
    x = 20  # это новая локальная переменная x
    print(x)

foo()      # 20
print(x)   # 10 — глобальная переменная не изменилась
```

Чтобы изменить глобальную переменную внутри функции, нужно явно объявить её глобальной:

```python
x = 10

def bar():
    global x
    x = 99

bar()
print(x)  # 99
```
### 4. Вложенные функции и область видимости

Вложенные функции могут видеть переменные из внешней (но не глобальной) области видимости, но чтобы изменить их, используют ключевое слово `nonlocal`.

**Пример:**

```python
def outer():
    count = 0
    def inner():
        nonlocal count
        count += 1
        print(count)
    inner()
    inner()

outer()
# Вывод: 1 2
```
### 5. Ошибки с распаковкой аргументов

**Частая проблема:** несоответствие числа аргументов или неправильное использование распаковки.

```python
def add(a, b):
    return a + b

nums = [1, 2, 3]
# print(add(*nums))  # Ошибка: слишком много аргументов
```

**Решение:**  
Проверяйте количество элементов при распаковке или используйте только нужное количество:

```python
print(add(*nums[:2]))  # 3
```
### 6. Аргументы только для ключевых слов и позиционные-only

В новых версиях Python можно объявлять параметры, которые можно передавать только по имени (`*`), или только по позиции (`/`). Ошибки часто возникают, если не соблюдать порядок передачи аргументов.

**Пример:**

```python
def func(a, b, *, c):
    print(a, b, c)

# func(1, 2, 3)  # Ошибка: c должен быть передан по имени!
func(1, 2, c=3)  # OK
```
### Рекомендации

- Никогда не используйте изменяемые значения по умолчанию в аргументах функций.
- Помните, что изменяемые объекты могут быть изменены внутри функции, даже если функция возвращает None.
- Следите за областями видимости переменных.
- Всегда явно указывайте, какие переменные глобальные или nonlocal, если их нужно изменить внутри функции.
- Проверяйте количество и порядок аргументов при распаковке.
- Используйте именованные аргументы для повышения читаемости и предотвращения ошибок.
