# Computer Vision

Компьютерное зрение — направление, в котором алгоритмы анализируют изображения и видео: детекция объектов, распознавание лиц, классификация, сегментация, OCR. На уровне инструментов раздел сосредоточен на двух библиотеках: NumPy (фундамент для всех вычислений) и OpenCV (классический CV).

## Содержание

- [NumPy](numpy/README.md) — массивы и математика
- [OpenCV](opencv/README.md) — обработка изображений и видео
