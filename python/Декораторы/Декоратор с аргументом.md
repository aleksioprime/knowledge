**Декоратор с аргументом** — это шаблон, при котором декоратор может принимать дополнительные параметры, влияющие на его поведение. Для этого требуется три уровня вложенности функций:

1. **Внешняя функция** — принимает аргумент декоратора.
2. **Средняя функция** — собственно декоратор, принимает функцию, которую нужно обернуть.
3. **Внутренняя функция** (`wrapper`) — выполняет обёртывание, вызывает исходную функцию, добавляет нужную логику (например, замер времени).

```python
from datetime import datetime

def timeit(label):
    """Декоратор с аргументом, измеряющий время выполнения"""
    def outer(func):
        def wrapper(*args, **kwargs):
            print(f"[{label}] Запускаем {func.__name__}...")
            start = datetime.now()
            result = func(*args, **kwargs)  # Запускаем декорируемую функцию
            elapsed = datetime.now() - start
            print(f"[{label}] Время выполнения: {elapsed}")
            return result  # Возвращаем результат
        return wrapper
    return outer

# Используем декоратор с аргументом
@timeit("Test")
def gener(n):
    """Генерирует список чисел от 0 до n-1"""
    return [x for x in range(n)]

l1 = gener(10000)  # Декоратор замерит время выполнения

# [Test] Запускаем gener... 
# [Test] Время выполнения: 0:00:00.001234
```

Как это работает:

- `timeit("Test")` создаёт **декоратор с аргументом**.
- `outer(func)` принимает саму **функцию** и создаёт `wrapper`.
- `wrapper(*args, **kwargs)` выполняет:
    - Засекает время `start`.
    - Вызывает декорируемую функцию `func(*args, **kwargs)`.
    - Вычисляет разницу во времени.
    - **Выводит время выполнения** с меткой.
    - **Возвращает результат `func()`**, чтобы функция работала правильно.
