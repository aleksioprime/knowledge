# S3 (Object Storage)

**Amazon S3** (Simple Storage Service) — объектное облачное хранилище от AWS, ставшее де-факто стандартом. Совместимые реализации: MinIO, Ceph, Yandex Object Storage, VK Cloud Storage и др.

Основные концепции:
- **Bucket** — контейнер для объектов
- **Object** — файл + метаданные + уникальный ключ
- **Region** — географическое расположение бакета
- Версионирование, lifecycle-политики, репликация
- Презайн-URL (временные ссылки на скачивание/загрузку)
- Уровни хранения (Standard, IA, Glacier и т.д.)

Python-клиенты: `boto3`, `aioboto3`, `minio`.
