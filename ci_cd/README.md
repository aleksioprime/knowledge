# CI/CD

CI/CD — это подход в разработке программного обеспечения, который автоматизирует процессы сборки, тестирования и доставки кода, делая их быстрее и надежнее.

### CI: Continuous Integration (Непрерывная интеграция)

Разработчики «сливают» свой код в общий репозиторий, каждый коммит автоматически запускает сборку и тесты. Если что-то ломается, команда узнает об этом в течение минут.

### CD: Continuous Delivery/Deployment (Непрерывная доставка/развертывание)

Это подход, автоматизирующий процесс вывода кода в продакшен. В Continuous Delivery код после прохождения автоматических проверок в CI готов к развертыванию, но требует ручного подтверждения (например, нажатия кнопки). В Continuous Deployment новая версия кода автоматически разворачивается на сервере без дополнительных действий.
