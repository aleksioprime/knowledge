# Функции в Python

Как функции видят переменные и принимают аргументы, и во что они превращаются дальше: замыкания, декораторы, итераторы, генераторы, корутины и менеджеры контекста.

## Содержание

- [Области видимости и замыкания](scopes.md) — правило LEGB, `global` и `nonlocal`, функции, запоминающие переменные
- [Аргументы и функции как значения](arguments.md) — передача объектов, значения по умолчанию, `*args` и `**kwargs`, лямбды, `map` и `filter`
- [Декораторы](decorators.md) — обёртка вокруг функции, декораторы с параметрами
- [Итераторы и генераторы](iterators_generators.md) — протокол итерации, свой итератор, `yield`, `yield from`, генераторные выражения
- [Корутины на генераторах](coroutines.md) — `send`, `throw` и `close`, пример с расчётом вклада
- [Менеджеры контекста](context_managers.md) — `with`, `__enter__` и `__exit__`, декоратор `@contextmanager`
- [Модули collections и itertools](extra.md) — готовые контейнеры и функции для работы с итераторами
