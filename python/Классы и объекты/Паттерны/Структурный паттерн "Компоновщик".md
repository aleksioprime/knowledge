Паттерн Компоновщик позволяет единообразно обрабатывать объекты, образующие иерархию, вне зависимости от того, содержат они другие объекты или нет. Такие объекты называют составными.

В классическом решении составные объекты - как отдельные, так и коллекции - имеют один и тот же базовый класс. У составных и несоставных объектов обычно одни и те же основные методы, но составные объекты добавляют методы для поддержки добавления, удаления и перебора дочерних объектов.

Этот паттерн часто применяется в программах рисования, например Inkscape, для поддержки группировки и разгруппировки. Его полезность в таких ситуациях объясняется тем, что подлежащие группировке или разгруппировке компоненты могут быть как одиночными (например прямоугольник) так и состаными (например, рожица, составленная из нескольких разных фигур)

```python
# Базовый компонент: общий интерфейс для всех графических объектов
class Graphic:
    def render(self):
        raise NotImplementedError("You should implement this.")

# Составной объект (композит) — может содержать другие графические объекты
class CompositeGraphic(Graphic):
    def __init__(self):
        self.graphics = []  # Список вложенных объектов (как простых, так и составных)

    def render(self):
        # Для группы вызываем render у каждого вложенного объекта
        for graphic in self.graphics:
            graphic.render()

    def add(self, graphic):
        # Добавляем графический объект в составную группу
        self.graphics.append(graphic)

    def remove(self, graphic):
        # Удаляем объект из группы
        self.graphics.remove(graphic)

# Листовой (простой) объект — отдельная фигура
class Ellipse(Graphic):
    def __init__(self, name):
        self.name = name

    def render(self):
        # Просто выводим свою форму
        print("Ellipse:", self.name)

# ======= Пример использования Composite =======
if __name__ == '__main__':
    # Создаем несколько простых объектов (листья)
    ellipse1 = Ellipse("1")
    ellipse2 = Ellipse("2")
    ellipse3 = Ellipse("3")
    ellipse4 = Ellipse("4")

    # Создаем две группы, куда добавляем эллипсы
    graphic1 = CompositeGraphic()
    graphic1.add(ellipse1)
    graphic1.add(ellipse2)
    graphic1.add(ellipse3)

    graphic2 = CompositeGraphic()
    graphic2.add(ellipse4)

    # Главная группа, объединяющая другие группы
    graphic = CompositeGraphic()
    graphic.add(graphic1)
    graphic.add(graphic2)

    # Теперь можно вызвать render для всей структуры, и он отработает рекурсивно
    graphic.render()

    # OUTPUT:
    # Ellipse: 1
    # Ellipse: 2
    # Ellipse: 3
    # Ellipse: 4
```

- **Graphic** — общий интерфейс (базовый класс) для всех компонентов.
- **Ellipse** — простой компонент (лист).
- **CompositeGraphic** — составной компонент (группа), который может содержать любые объекты Graphic (и простые, и составные!).
- Вся система строится как дерево: группы могут содержать другие группы или отдельные элементы.

- Можно **одинаково обращаться** к отдельным объектам и их группам.
- Например, вызвать `render()` у любого объекта, не задумываясь, сколько внутри ещё объектов — всё обработается автоматически.
