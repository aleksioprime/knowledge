- **Мутабельные (mutable) объекты** — их содержимое можно изменять после создания.  
- **Иммутабельные (immutable) объекты** — содержимое изменить нельзя, любые операции создают новый объект.

**Иммутабельные:**

- `int`, `float`, `complex` (числа)
- `str` (строки)
- `tuple` (кортежи)
- `frozenset` (замороженные множества)
- `bytes`

**Мутабельные:**

- `list` (списки)
- `dict` (словари)
- `set` (множества)
- `bytearray`
- экземпляры собственных классов (по умолчанию)

### Как это проявляется на практике

**1. Пример с list (мутабельный):**

```python
a = [1, 2, 3]
b = a
b.append(4)
print(a)  # [1, 2, 3, 4]
```
`b` и `a` ссылаются на один и тот же объект в памяти — изменили `b`, изменился и `a`.

**2. Пример с int (иммутабельный):**

```python
a = 5
b = a
b += 1
print(a)  # 5
```

Здесь `b += 1` создает новый объект, `a` остается прежним.
### Почему это важно?

- **Мутабельные объекты** могут изменяться «по месту». Это удобно, но может привести к неявным ошибкам, если, например, два имени (переменные) ссылаются на один и тот же объект.
- **Иммутабельные объекты** гарантируют, что никто не может неожиданно изменить их содержимое. Это важно для безопасности, упрощения кода и для использования в качестве ключей словаря, элементов множества.
### Типичные подводные камни

1. **Мутабельные значения по умолчанию в аргументах функции:**

```python
def foo(arg=[]):
	arg.append(1)
	print(arg)
foo()  # [1]
foo()  # [1, 1]
```

Список сохраняет изменения между вызовами! Лучше так:

```python
def foo(arg=None):
    if arg is None:
        arg = []
```

2. **Копирование объектов:**

- `list1 = list2` — обе переменные указывают на один список (мутабельный).
- `list1 = list2.copy()` или `copy.deepcopy(list2)` — новая копия.
### Иммутабельность и хешируемость

- **Только иммутабельные объекты могут быть ключами в dict и элементами в set**, потому что их хеш-значение не меняется за время жизни.
- Например, список нельзя использовать как ключ, а кортеж можно, если все его элементы — тоже иммутабельны.

### **Работа GC (Garbage Collector)**

- Мутабельные объекты могут образовывать циклы ссылок, из-за чего используются дополнительные механизмы GC (например, списки, содержащие ссылки на другие списки).
- Иммутабельные объекты не создают циклы.

```python
import sys
a = (1, 2, 3)
b = [1, 2, 3]
print(sys.getsizeof(a))  # Размер в памяти, кортеж фиксированный
print(sys.getsizeof(b))  # Размер в памяти, список может увеличиваться
```
