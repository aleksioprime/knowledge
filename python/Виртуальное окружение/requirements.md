В контексте Python - это список зависимостей, то есть внешних библиотек и пакетов, которые необходимы для работы проекта. Обычно эти зависимости перечисляются в файле под названием `requirements.txt`. Этот файл содержит все пакеты, которые должны быть установлены для того, чтобы проект работал корректно

Создание списка зависимостей проекта с уже установленными пакетами в окружении:
```sh
pip freeze > requirements.txt
```

Установка пакетов в новом окружении из подготовленного списка зависимостей проекта:
```
pip install -r requirements.txt
```

Можно просто создать файл `requirements.txt` и вручную записать в него зависимости:
```txt
flask==2.2.5
sqlalchemy>=1.4.0,<2.0
pandas
```

🔹 Поддерживаются разные варианты записи:
- `package==1.0.0` – строго заданная версия.
- `package>=1.0.0` – минимальная версия.
- `package<=2.0.0` – максимальная версия.
- `package` – установит последнюю доступную версию.
