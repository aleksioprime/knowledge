# Основы Python

Что происходит «под капотом» у обычного кода на Python и как устроены повседневные конструкции языка: от интерпретатора и памяти до исключений и `match`.

## Содержание

- [Интерпретатор, GIL и сборщик мусора](interpreter.md) — байт-код и виртуальная машина, подсчёт ссылок и сборка мусора, GIL
- [Память: выделение, устройство list и dict, интернирование](memory.md) — стек и куча, PyMalloc, переаллокация, устройство списка и словаря, интернирование
- [Сравнение, проверка типов и копирование](comparison_and_copies.md) — `==` и `is`, `type` и `isinstance`, присваивание и копии, операторы `and`, `or`, `not`
- [Генераторы коллекций и перебор](iteration.md) — comprehensions, `range`, `enumerate`, `zip`
- [Обработка исключений](exceptions.md) — `try`/`except`/`else`/`finally`, повторный выброс, группы исключений, свои типы ошибок
- [Сопоставление с образцом (match-case)](match_case.md) — оператор `match` и образцы `case`
