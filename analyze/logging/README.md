# Централизованное логирование

Пока сервис один, логи можно читать в консоли или файле. Когда сервисов несколько и каждый запущен в нескольких копиях, искать ошибку по файлам на разных серверах уже невозможно. Логи собирают в одно хранилище и ищут по ним через веб-интерфейс.

Как писать логи в самом приложении — уровни, логгеры, обработчики, форматы — описано в заметке [Логирование в Python](../../python/extra/logging.md).

Типовые стеки:

- **Loki + Grafana** — лёгкий вариант: Loki хранит логи, Grafana показывает и ищет по меткам;
- **ELK** — Elasticsearch + Logstash + Kibana: мощный полнотекстовый поиск, но тяжелее в эксплуатации.
